## Ch.5 方法論（核心章）✅

- 5.1 總架構：分層漏斗（決定性生成 → SM 篩選 → HFSS 批次 → 公證）＋迭代閉環（真值回灌/規則回饋/冠軍變錨點）。
- 5.2 批次假設迴圈：每批=判準預註冊的對照實驗（探索臂/利用臂/規則檢驗臂/對照臂）；與 BO 的差異＝
  每批夾帶因果探針,搜尋同時生產知識。〔R8-R10 的臂設計當範例〕
- 5.3 算子庫（可製造性內建）：perturb_repair/symmetrize/perturb_blocks(知情編輯)/occlude(歸因探針)/
  公差算子；決定性 seed → 全鏈可重現。〔dedust.py 檔頭地圖〕
- 5.4 SM 生命週期：離線預訓（harvest）→ 週期重錨（過採樣+重放防遺忘+certified 優先去重防毒）→
  分區有效性（作戰區 0.36dB/爛區 5.75——「什麼時候信 SM」的誠實答案）→ 超參網格證明資料主導。
- 5.5 規則管線：相關性(analysis-01) → 可證偽預測 → 因果批次 → 過關升級算子/先驗、不過淘汰。
  正例（對稱化 4/4）與反例（補洞死刑）俱全——**先驗是被審判的,不是被相信的**。
- 5.6 與 HL 框架的對映表（吸收反饋=bug→回歸測試;壓縮歷史=rounds→design_priors）。
