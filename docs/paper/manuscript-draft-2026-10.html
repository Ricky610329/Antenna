摘要—像素化天線與濾波器的反向設計需在昂貴的全波評估與大量幾何候選之間分配計算資源。每次完成的模擬同時提供設計性能與代理學習的標籤，因而可將資料取得與後續候選選擇組成持續回饋的流程。本文提出多策略批次代理學習框架：由結構操作、親本重組及取樣建立候選，以前向代理模型與探索配額選取一批圖形，再將有效電磁響應與相容歷史資料共同用於模型更新。AI agent 在研究者設定的目標與判準下協助形成探索變體，擴充可供選擇的策略來源；emforge 則提供共用求解與資料服務，支援各策略管理自己的提交與更新節奏。本文整理框架機制、濾波器代理模型的具體實作，以及天線與濾波器的模擬案例。天線代表在指定採樣下取得 +0.77 dB 帶內最差餘裕及 +0.50 dB 方向圖窗口餘裕；濾波器在固定幾何條件下累積改善 3.51 dB，最終最差餘裕為 −2.39 dB。兩案例呈現多來源探索、資料利用與設計進展，並據此討論代理更新、資料覆蓋與物理驗證的關係。

關鍵詞—電磁反向設計；批次代理學習；多策略探索；AI agent；天線；濾波器。

I. 引言

全波電磁模擬提供天線及濾波器設計所需的響應，但逐一評估大量像素圖形需要可觀的求解成本。前向代理模型（surrogate model, SM）由已知圖形—響應配對學習幾何與性能的關係，使較大的候選池能先經快速預測，再選取有限的候選交由 HFSS 評估。機器學習輔助天線幾何最佳化與射頻設計已展示此類模型在設計流程中的作用。[1], [2]

搜尋也決定模型接下來學到什麼。沿目前高分設計的鄰域持續探索，可取得局部改善所需的資料；引入其他結構與起點，則有機會擴充已觀察的設計空間。當一批候選的全波響應可被累積並共同用於更新時，候選來源、選樣配額與更新時機便成為相互關聯的方法選擇。本文關注如何將這些選擇整理成可持續執行的學習流程。

模擬資料已被用於學習逆向設計的生成分布，以及批次主動學習的工程回歸模型。[3], [4] 天線領域的 PSADEA 結合並行模擬、代理建模與演化搜尋，並以實際耗時及求解次數分別比較設計進展。[5] 本研究承接實驗室以代理網路近似 HFSS 響應，以及自適應排程、連通性損失與資料重用的工作，進一步將候選探索、批次資料取得與模型更新組織為可分別配置的模塊。[6], [7]

框架由多種策略供應候選，透過 SM 預測與探索配額分配求解預算，再以累積的相容資料更新模型。大型語言模型驅動的研究代理（AI agent）參與探索規則的提出、實作與調整，提供拓展策略來源的途徑。為支援不同策略的批量及回饋需求，emforge 將共通的提交、排程、回收與重用工作整合為服務，模型與更新節奏則保留在策略端。

本文的工作是建立上述學習與探索機制、給出可重現的選樣及代理訓練配置，並以兩類元件的研究案例與獨立執行服務驗證檢查其運作。天線與濾波器共用資料取得及回饋的分工，各自保留物理響應與設計判準。第 II 節定義問題，第 III 節說明方法，第 IV 節呈現 emforge 及資料供應規劃，第 V 節整合兩應用與服務驗證，第 VI、VII 節討論結果並作結。

II. 兩類設計問題與共同表示

A. 圖形、幾何與求解條件

設計變數為 x ∈ {0,1}25×25 的金屬像素圖形，名義設計區域為 5 mm × 5 mm，像素節距 0.2 mm，基板採厚度 0.508 mm 的 RO4003C。天線模型具有一個饋入端，輸出反射及輻射響應；濾波器模型具有兩個饋入端，評估 S11、S22 及 S21。兩者共享候選資料結構與批次執行方式，但求解模型、響應物理量及評分函式均分開定義。

二值圖形經幾何建構 Gp(x) 轉成金屬結構。為形成具有有限面積的對角連接，代表設計在指定接點加入旋轉 45° 的正方形金屬橋。天線與濾波器代表的橋邊長分別為 0.10 與 0.075 mm，像素金屬邊長均為 0.21 mm、節距為 0.2 mm，使相鄰像素具有 0.01 mm 重疊並聯集金屬。濾波器以 p01 識別此像素幾何版本。橋尺寸、像素尺寸與元件設定共同構成每次評估的幾何條件。

頻率響應使用 Fast sweep 在 24–32 GHz、間距 0.5 GHz 的 17 個保存值。研究中常用設定為 28 GHz 自適應求解，MaxDeltaS = 0.02、MaximumPasses = 6、MinimumPasses = 5、MinimumConvergedPasses = 5。代表設計的逐案完整求解設定尚未封存，結果以其原始保存響應為準；較嚴格網格設定的敏感度與收斂驗證需求於第 VI-C 節討論。

B. 天線：帶內性能與角度覆蓋

令 Ωa = {26.5, 27, …, 29.5} GHz。反射需滿足 S11 ≤ −10 dB，正向實現增益需滿足 Gr ≥ 4 dBi；Gr 為 HFSS 在 θ = φ = 0 輸出的 dB(RealizedGainTotal)，包含失配損耗。帶內餘裕定義為

(1)mS = −10 − maxf∈Ωₐ S11(f),　mG = minf∈Ωₐ Gr(f) − 4,
wa = min(mS, mG).

方向圖另取 28 GHz、φ = 0° 與 90° 兩切面的 dB(GainTotal)，記為 Gφ(θ)。此量取自 LastAdaptive，與上述正向實現增益的報表定義不同。角度覆蓋要求每個切面在 |θ| ≤ 45° 的實際採樣點不低於自身正向值 3 dB，故

(2)rφ = min|θ|≤45°[Gφ(θ) − Gφ(0) + 3],　rmin = min(r0°, r90°).

wa ≥ 0 與 rmin ≥ 0 分別表示帶內頻率判準與兩切面的角度窗口通過。角度網格間距為 2°，窗口中的最外採樣為 ±44°；本判準適用於指定頻率與切面的已保存採樣點。帶外正向增益另依低、高頻側記錄。

C. 濾波器：反射、通帶與阻帶

濾波器規格分成三組離散頻點：反射 Ωr = {26.5, 27, …, 29.5} GHz；S21 通帶 Ωp = {25.5, 26, …, 30.5} GHz；阻帶 Ωs = {24, 24.5, 25, 31, 31.5, 32} GHz。四項餘裕及總評分為

(3)m1 = −10 − maxf∈Ωᵣ S11(f),　m2 = −10 − maxf∈Ωᵣ S22(f),
m3 = minf∈Ωₚ S21(f) + 3,　m4 = −15 − maxf∈Ωₛ S21(f),
wd = min(m1, m2, m3, m4).

四項餘裕均非負表示指定採樣點的全部濾波器規格通過。通帶 S21 採下限判準，阻帶 S21 與反射採上限判準，各自使用對應頻點集合。wd 表示最限制此濾波器設計的規格餘裕，後續候選選擇及結果比較均依此定義。

III. 多策略批次代理學習

A. 以電磁資料回饋候選選擇

框架以相容的歷史圖形—響應資料及 SM 為起點。策略建立候選池，選樣模組利用模型預測與探索配額組成待模擬集合，HFSS 回傳有效響應。這些資料一方面用於選擇親本及保留設計，另一方面在策略設定的更新時機納入代理訓練，再影響後續候選選擇。本文的批次指成組取得電磁標籤；模型訓練使用的 minibatch 另由訓練配置決定。

圖 1呈現候選、模擬資料與 SM 的共同循環。上方模塊將探索規則轉換為經全波評估的資料；下方回饋路徑讓累積資料進入模型更新。策略形成決定可探索哪些圖形，模型與配額則共同決定哪些圖形實際取得標籤。

B. 策略多樣性與批次組成

候選來源包括親本的局部像素變異、金屬組件調整、不同親本的重組，以及對稱隨機取樣。局部操作保留已知設計的部分結構，組件與親本操作提供其他組合，取樣規則則拓展探索位置。不同來源可使用相同的圖形表示與物理評分，進入共用候選與資料流程。

本研究使用 Claude Code 作為語言模型研究助理，協助閱讀模擬結果、提出結構假設與實作探索變體。研究者設定物理限制、目標、資源範圍與採納判準；形成的新策略經有限配額試驗後，依 HFSS 結果保留、調整或停止。規則與配置由程式版本記錄，具備相應欄位的批次另保存親本、候選來源與模型資訊。AI agent 在此參與策略來源的拓展與修訂，採用的規則可重複產生候選集合。

批次選樣結合三種用途：性能導向配額偏向預測較好的設計；模型分歧配額取得不同 SM 判斷不一致的候選；其他探索配額保留指定來源進入全波評估的機會。分歧以模型預測的標準差表示，是選樣依據之一，其與真實預測誤差的關係由後續 HFSS 響應檢查。候選來源與選樣配額共同決定下一批學習資料的分布。

C. 前向代理模型與累積訓練

SM 以像素圖形預測元件響應及設計指標，讓一次全波評估產生的資料可供後續多次候選比較使用。天線的模型任務涉及反射、增益及方向圖，濾波器則涉及 S11、S21、S22；模型依各自的響應定義與幾何條件訓練。以下以濾波器的完整批次實作說明代理訓練及選樣之間的介面。

濾波器 SM 接收 25×25 二值圖形，展平為 625 維輸入，共同回歸三條 17 點 S 參數及六項輔助餘裕。三條響應提供頻譜資訊，餘裕輸出則直接供排序使用。六項輔助量記為 a₁…a₆：前四項以固定參考門檻編碼，與式 (3) 的關係為 (m₁,m₂,m₃,m₄) = (a₁+2,a₂+2,a₃,a₄+5)；另兩項為 S11、S22 在 {24,24.5,25,25.5,26,30,30.5,31,31.5,32} GHz 的最小值相對 −1.25 dB 的餘裕，作為額外回歸目標。選樣時取換算後四項餘裕的最小值。

D. 資料累積與策略管理的更新時機

令 Dk 為第 k 次更新時已有的相容資料，ΔDk 為下一次更新前取得的有效且唯一的新圖形—響應配對。資料與模型的回饋關係寫為

(4)Dk+1 = Dk ∪ ΔDk,　θk+1 ← Train(Dk+1).

Train 包含資料劃分、訓練與評估，模型參數由訓練子集更新，保留資料用於檢查預測表現。資料依圖形身分及相容的幾何、求解條件整理；有效求解但未達設計規格的候選，也提供可用的學習標籤。結果重用可支援選樣與親本查詢，重複結果不增加唯一新標籤數。

提交批量 B 決定一次送入求解流程的候選數，模型更新則由策略依資料需求與計算成本安排。策略可先累積多個提交批的結果再更新，亦可採用較短的回饋間隔。本文以固定批數間隔 r 說明一個具體配置；當每批皆取得 B 筆有效且唯一新結果時，一次更新新增 rB 筆標籤。較長間隔可在固定資料量下減少重訓次數，較短間隔則使新資訊較早參與後續選樣。

E. 濾波器的候選選樣與更新配置

一個已實作的濾波器策略每次建立目標大小為 6,000 的候選池，名義來源為 60% 親本局部鄰域、20% 親本重組及 20% 對稱隨機圖形。三個 SM 各自預測輔助餘裕，將前四項換算為式 (3) 的規格餘裕，取其最小值作為該模型的預測 wd，再計算三個預測值的均值 μ 與標準差 σ。

一次選送 B = 90 筆，依序組成不重複的三部分：36 筆依 μ−σ 排序；27 筆從 μ 不低於第 60 百分位的候選中選取 σ 較高者；27 筆優先由對稱隨機候選抽取，不足時從剩餘候選隨機補足。第三部分的抽取不依 SM 分數排序。這些配額將性能搜尋、分歧探索與來源拓展轉為明確的求解預算。

該配置每完成 r = 3 個提交循環，重新整理已回收的相容資料，呼叫三個模型的重訓與評估並記錄檢查結果，再繼續後續選樣；各次訓練完成及權重使用狀態由執行紀錄確認。若三批均取得 90 筆有效且唯一新結果，一次更新可增加 270 筆標籤；模型訓練同時使用相容的既有資料。這組參數作為方法的具體實例，各策略仍可採用自己的批量及更新間隔。

IV. emforge：學習流程的執行支援

A. 策略端與共用服務的分工

持續探索需要反覆提交圖形、追蹤模擬狀態、回收響應並整理資料。emforge 將這些共通工作集中為服務，使候選方法的調整可沿用既有求解流程。策略端保留候選規則、模型及自身進度，決定何時提交、等待資料或更新模型；平台處理評估條件核對、結果重用、佇列與派工。

圖 2將系統分為策略程序、工作與資料服務，以及 HFSS workers。獨立策略程序透過介面提出候選及查詢結果；平台返回已有的相容響應，或將新增求解交由 worker 執行，完成後保存原始輸出與工作狀態。

此分工支援不同策略各自管理資料取得及模型更新。某策略等待自己的結果或進行模型訓練時，其他已提交工作仍可由可用 worker 處理。實際執行另受入口形式、佇列、優先序與可用資源影響；平台的輕量候選入口由 runtime 同步呼叫，獨立 hosted 算法則自行保存執行狀態。

B. 評估一致性、重用與平行工作

平台以設定檔（profile）識別元件幾何與求解條件，將圖形身分與評估條件共同用於查詢和重用。不同橋尺寸或幾何版本的結果各自保存，原始響應回收後再依天線或濾波器規格計算指標。新增求解提供新標籤，既有結果重用延續先前的計算價值，確認重測則檢查指定設計的重複求解一致性。

提交量與同時求解數分別由策略及執行資源決定。每個 worker 認領一份工作集合並逐筆評估，多份可獨立認領的工作可並行處理。因此，批次完成時間取決於工作切分、排隊、各筆求解及重試，不能僅由提交量除以機器數決定。例如，第 III-E 節的研究 runner 將 90 筆候選分成三份工作，等待三份都結束後才繼續該策略；此等待條件屬於策略本身。

C. 成本計量與每週資料供應

學習流程的成本包含候選產生與 SM 推論、資料取得、資料整理，以及模型訓練與評估。資料取得應計入排隊、模型建立、求解、重試與結果傳回；確認重測另行記錄。比較完整探索方法時，也需記錄初始模型訓練，以及研究者與 agent 參與策略形成的成本。各階段可能重疊，完整經過時間應以共同起訖與實際時間戳記計量。

V. 天線、濾波器與執行服務驗證

A. 案例配置與驗證範圍

天線與濾波器案例使用各自的歷史搜尋紀錄及原始 HFSS 響應，依第 II 節的幾何與指標解讀。代表設計的幾何、頻率響應與方向圖採同一案例的保存資料；其他探索案例依其原有幾何條件分別報告。完整 SM 搜尋與重訓流程實作於 Antenna 研究系統，emforge 另完成共用服務部署驗證，完整 SM 策略尚未移植至該部署。

交付集包含 25 個天線與 14 個濾波器，39 個設計均完成 HFSS 重新求解，其中 37 筆評分與原存值一致，其餘 2 筆差異不超過 0.08 dB。平台功能驗收另在指定濾波器設定下完成 10 筆 HFSS 工作，包含 4 筆新增樣本與 6 筆重測，均首次成功；同圖在三台機器的完整響應最大差異為 1.907 × 10−6 dB，衍生指標一致。這些結果支持指定部署下的提交、回收與跨機執行一致性，元件規格完成度則由各自響應判斷。

C. 濾波器：多來源搜尋與批次回饋

濾波器代理的既有紀錄提供一項模型層面的觀察：以 2,326 筆相容橋接資料建立的模型，在當次保留集上記錄 Spearman ρ 約 +0.57，預測前 30 筆中有 17 筆位於真值前 10%。此檢查使用六項輔助餘裕的最小值，呈現該模型對此分數的排序能力；與式 (3) 的四項設計分數分別解讀。資料池隨探索擴充，這項紀錄作為當次模型檢查，不組成固定保留集上的學習曲線。

濾波器沿用候選、選樣及資料回饋的分工，改以反射、通帶與阻帶餘裕決定設計品質。一組起點分析中，15 筆由歷史圖形均勻抽取並加標準橋的候選，最佳餘裕為 −9.53 dB；由既有資料選出的 A_11 起點，在相同橋接條件下為 −5.90 dB，其鄰域局部操作進一步取得 −3.82 dB。這些結果描述資料選種及局部探索的連續用途，各階段使用的歷史資料與候選預算不同。

固定 p01 與 0.075 mm 菱形橋下，最佳紀錄候選為 smp073_d_040。圖 6呈現其設計區、67 座橋及兩個饋入連接位置；橋接金屬包含在全波求解幾何內。

圖 7呈現同一設計的反射與傳輸。S11、S22 的規格餘裕分別為 +1.97、+2.31 dB；S21 通帶與阻帶餘裕分別為 −2.39、−2.17 dB。反射規格在指定採樣通過，傳輸的頻帶邊緣仍有缺口。

在 90 筆混合選樣的持續執行紀錄中，性能導向候選 smp050_L_011 取得 −2.43 dB，模型分歧候選 smp073_d_040 取得 −2.39 dB，均經確認重測後納入設計紀錄。兩種選樣來源都產生了改善候選，提供代理參與選樣的實際案例；各來源及重訓頻率的獨立效益仍需相同預算下的比較。

六個未達點為通帶的 25.5、30、30.5 GHz，以及阻帶的 25、31、31.5 GHz。最差通帶點在 25.5 GHz，S21 = −5.39 dB；最差阻帶點在 25 GHz，S21 = −12.83 dB。固定幾何條件下的最佳紀錄由 −5.90 推進至 −2.39 dB，累積改善 3.51 dB，最終整體餘裕由通帶限制。此進展由多種候選操作累積形成。

另有一個批次回饋案例每次選送 9 個候選，結合累積資料重訓，在 135 筆 HFSS 搜尋樣本中將最佳餘裕由 −3.15 改善至 −3.14 dB，另完成 2 次確認重測。此案例採用不同於第 III-E 節的配置，其結果呈現批次回饋的實際執行及有限改善幅度。兩者分別提供已執行案例與具體方法配置，模型更新的效果仍需與每次新增資料及模型評估共同判讀。

VI. 討論

A. 多策略探索如何連到學習資料

兩類元件共享候選—響應—模型的介面，探索規則與物理目標則可分別調整。天線案例顯示不同選拔方式在通過數及最佳餘裕上呈現不同結果；濾波器案例顯示歷史資料選種、局部操作與批次回饋可各自參與搜尋。這些觀察支持將探索來源、候選選樣與模型更新分開配置，以便判斷每個環節如何形成新增資料。

AI agent 參與策略的形成與修訂，其多樣性角色可沿三個層次檢查：採用了哪些規則，產生的圖形相差多少，以及所得響應覆蓋哪些區域。天線組件移植案例表明，較大的幾何差異仍可能對應相近響應。因而，評估 agent 參與的探索組合時，應追蹤具體策略及候選來源，再由有效新資料與物理結果檢查其作用。

B. 學習表現與設計進展的連接

批次資料回饋提供重新估計幾何—響應關係的機會，其價值取決於新增資料的分布與模型更新後的表現。可分別以唯一新響應量衡量資料取得，以保留資料的誤差與排序能力衡量 SM，以最佳餘裕及達標成本衡量設計結果。濾波器的 135 筆回饋案例只有 0.01 dB 最佳餘裕改善，說明流程完成與設計推進程度需要分別報告。

實作中的模型檢查使用六項輔助餘裕的最小值，而搜尋以換算後四項規格餘裕的最小值選樣，兩者的評分口徑不同。現有檢查結果因而描述相應輔助分數的排序表現，不能直接充當式 (3) 搜尋分數的評估。現有案例也尚未將策略來源、代理更新與批量的作用分離。要量化學習環節，可先整理相同評估資料上的更新前後誤差及候選排序，再於固定初始資料、幾何與總求解預算下比較更新規則。不同策略組合則應固定其他條件後比較。模型更新會重新整理資料池，保留集需固定或採前瞻新資料，才能使跨次評估有一致對象。

執行方面，現有濾波器 runner 會呼叫重訓及評估，但不以訓練回傳狀態或評估品質阻擋後續選樣；各次更新是否完成、實際使用哪組權重，需依當次紀錄判定。搜尋效率可分別用最佳餘裕對新增 HFSS 求解數，以及對實際經過時間的曲線評估。前者檢查標籤使用效率，後者納入候選計算、求解、訓練及策略形成成本；PSADEA 亦採用兩種尺度呈現進展。[5]

C. 幾何、求解可靠性與物理驗證

代理學習與候選評分依賴電磁標籤的條件一致性。既有天線網格敏感度實驗中，18 組選定案例由 S0（MaxDeltaS = 0.02、MaximumPasses = 6、MinimumConvergedPasses = 5）改為 S1（0.005、20、3）後，反射谷頻移絕對值中位數為 0.985 GHz，最差餘裕差異絕對值中位數為 0.81 dB。此選樣包含高差異案例，三個原通過候選在 S1 下轉為未通過，提示最終設計需要個別檢查收斂。HFSS 自適應網格說明及多精度代理研究提供相關評估背景。[8], [9]

加入橋接也改變幾何與響應。0.10 mm 橋的 3,318 筆成功配對中，帶內餘裕變化中位數為 −0.07 dB；此統計適用於既有選樣及求解條件，個別代表仍需依實際橋接幾何評估。本文天線代表通過指定頻率及兩切面的採樣判準，濾波器代表仍有六個傳輸採樣點未達規格。更密的頻率與角度檢查、代表設計的完整模型及收斂封存，以及製造後的 S 參數、增益與方向圖量測，構成後續物理驗證內容。

VII. 結論

本文建立用於天線與濾波器設計的多策略批次代理學習框架，將探索規則、模型選樣、全波資料取得及累積訓練連成共同流程。AI agent 協助形成與調整探索變體，emforge 提供共用求解與資料服務，策略端保有模型及更新節奏的控制。

天線代表取得 +0.77 dB 帶內餘裕及 +0.50 dB 方向圖窗口餘裕；濾波器在固定幾何條件下累積改善 3.51 dB，最終最差餘裕為 −2.39 dB。兩案例提供候選探索與資料回饋的實作經驗，平台驗證則支持指定部署的執行一致性。後續工作將以一致的模型評估及受控搜尋比較量化學習效果，並完成代表元件的收斂與量測驗證。
