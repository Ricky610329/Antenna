## 敘事重點（公允版）

- **學長的方法本身能產生完全合規的設計**（圖 4-4 = t07_top +0.35、oracle F0 +0.44，都撐過我方嚴格重測）——別把學長講差。
- 差別不在電性，而在 **可製造性**（學長解含粉塵碎片）與 **可系統化衍生／找變異**（碎片承重，動一下就崩）。我方貢獻＝在同一套規格下，把合規的好電性變成**可製造、可微擾演化**的設計（現任 margin 王 m23b4_030 +0.49、三標全過、可製造）。
- 對比圖產生指令：`python -m script.figs.champ_compare --plain --new m23b4_030_r3_001 --old t07_top --out <path>`（`--plain`＝結構差很大的前後對比，兩 pattern 都純底圖）。
- ⚠ 已知修正：`design_priors.md` §一.1 原「F2 錨點 −6.44」係誤植——**+6.2 dB 是 10-5-10 對稱化對「F2 散亂投影家族」的救援量**（round-09 §4：F1 +2.8／F2 +6.2），非 F2 絕對值（F2 本身 −1.42／池 −0.01）。已於 2026-07-14 加註修正。
