## 三、不帶（連同它們解決的問題一起重新設計）

| 不帶什麼 | 行數 | 理由 |
|---|---|---|
| `select_*` 家族 | ~4,000 | R22–R54 的歷史沉積，60+ 個子命令各自硬編錨組與臂配額。**同樣的機制在 `select_smpool` 是 150 行的乾淨版**。⚠ 但要**挖它們的分類法**（取樣政策 × 變異規則的清單），見架構草案 §5.1 |
| `antenna/training.py` 線上迴圈 | 1,281 | 梯度端到端已降格為工具箱一員（C-09）。新系統若要局部精修，重寫比移植便宜 |
| `antenna/models/generators.py` | 231 | 同上 |
| `surrogates.py` 的 `train_one_data*` | — | 單筆過擬合到收斂＝已知反模式 |
| `sm_reanchor.py` | 903 | 多軌 SM + 影子模型 + rad 頭的治理體系。新系統初期不需要這麼複雜；`sm_dual.py` 的輪邊界全重訓已涵蓋基本需求 |
| `DualNet` 的**權重** | — | 新域必須重訓（C-07：域外比隨機差）。架構抄、權重不抄 |
| 所有具體數字 | — | 40/30/30 配額、`w_margin=12.0`、`ρ≥0.40`、`n_sites<17`、`buffer≥0.3`、`Hamming≥150`——**全是本域調出來的**。帶走的是「有這個旋鈕」，不是旋鈕的值 |

## 四、技術債（重寫時一併解掉，不要複製）

| 債 | 現況 | 影響 |
|---|---|---|
| **埠/域分派散在 11 處** | 模擬器選型、掃頻預設、白名單、指標 if/else、manifest 域判定（寫死二元）、17 處 `PORT_SPECS[port]["labels"]`… | 加第三個域要改 11 個地方；2026-08-31 的埠數事故就是這個債的實犯 |
| **記錄檔 schema 不一致** | `records.json` 用 `axis`、`records_dual.json` 用 `key`；`history` 早期結構化、後期自由文字；`certified` 是自由文字塞了日期/店名/血統鏈 | 機器讀不了，只能人讀。多策略下會更亂 |
| **完全沒有 schema 定義** | 無 jsonschema／dataclass／TypedDict，全靠慣例，真相散在 docstring | 新人接手只能逐檔讀註解 |
| **manifest 是輸入清單又是預測記帳簿** | `sm_screen`／`select_smpool` 會回寫欄位進去 | 雙重角色，不小心會覆寫 |
| **`run()` 沒有任何測試** | `tests/test_dedust.py` 只測純函式；`_MockSim` 服務的是 `training.py` 不是 `run()` | **三台正式機的命脈沒有網**。重構前必須先補特徵化測試 |
| 版本欄位漂移 | `sm_dual` 的 margin 軸數 v4 起是六軸，但 CSV 表頭仍寫死四欄 | 輸出欄數對不上 |
