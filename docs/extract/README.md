## 標籤方案

`claims.md` 每列七欄。**「證據」與「狀態」必須分開兩欄**，不可合併：一條可以是「A 級證據但已過時」
（前提消失，例如 25×25 幾何換代前的量測），也可以是「無實驗但現行」（例如「換模型會得到同一份帳」）。
合成一欄會把最需要小心的那類藏起來。

**證據等級**（沿用專案既有三級證據制，但**重新判級**，不抄結論）：

| 級 | 意義 |
|---|---|
| `A` | 因果級——有對照臂／預註冊判準／重複量測 |
| `B` | 相關級——多批一致但無對照 |
| `C` | 單例級——單批或單次觀察 |
| `N` | 負結果 |
| `–` | 無實驗（純論證） |

**狀態**：`✅現行` ／ `⛔已證偽` ／ `↩已撤回→<取代者>` ／ `❓未驗證` ／ `🕰已過時（前提消失）`

**域**：`通用` ／ `天線` ／ `dual` ／ `HFSS` ／ `NAS` ／ `harness`

**移植**：`帶走` ／ `重寫` ／ `留下` ／ `待決`

## 紀律

1. **每條都要有可回溯出處**（`round-NN §N` ／ `檔案:行號` ／ `decisions.md` 節標題）。抽查要對得回去。
2. **有對照的才算數**——對照臂數字優先（R71 的 hc 臂、`_smpool_pick` 的 c 臂、R34 Tier 三標率）。
3. **單次 vs 公證要標明**（專案既有紀律：未公證值一律標「單次」）。
4. **不引用 `methodology.md`／`MILESTONES.md`／`divergences.md` 的結論當證據**（三份都停更於七月底），
   只可引用其**方法論框架**（例如三級證據制）。
5. **結構與數字分開帶**：`40/30/30`、`w_margin=12.0`、`ρ≥0.40` 是本域調出來的；帶走的是「有這三個臂」
   的結構，不是那三個數字。
