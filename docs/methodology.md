# 研究方法：在方法級比較不可行的條件下進行天線逆向設計

> 碩士論文方法論章底稿。本章描述本研究採用的研究作業方式：它要解決什麼問題、由哪些機制構成、
> 有什麼證據顯示它有效、邊界在哪裡。
>
> **閱讀順序**：§1 問題與度規 → §2 這個問題的雜訊尺度（本章的樞紐）→ §3 之後是方法本體。

## §1　問題設定與評價度規

### 1.1 設計問題

本研究的對象是一個**像素化微帶貼片天線**：輻射體所在的金屬層被離散成 25 × 25 = 625 個
正方形像素，每個像素只有「有金屬」與「沒有金屬」兩種狀態。一個**候選設計**（下稱 pattern）
就是一張 25 × 25 的二元圖，設計空間大小為 2⁶²⁵。

| 項目 | 設定 |
|---|---|
| 目標頻段 | 5G NR n257，26.5 – 29.5 GHz（中心 28 GHz） |
| 基板 | RO4003C，厚度 0.508 mm |
| 輻射體區域 | 5 mm × 5 mm，離散為 25 × 25 像素（每像素 0.2 mm） |
| 激勵 | 單埠，集總埠（lumped port）；饋入點上方疊一塊固定金屬遮罩確保能量注入 |
| 求解 | Ansys HFSS，離散掃頻（discrete sweep）逐點硬解 24 – 32 GHz 共 17 點（間隔 0.5 GHz） |
| 方向圖 | 於 28 GHz 取 φ = 0° 與 φ = 90° 兩個主切面，θ 解析度 2° |
| 單筆成本 | 中位 160 秒（n = 2,123 筆實測） |

**設計變數只有 625 個位元，沒有連續參數**。這一點決定了後面所有事：搜尋空間是離散的、
高維的，而每一次評估都要付出約兩分半的全波模擬。

### 1.2 三個硬性判準與一個收益軸

一個候選要被視為**合格解**，必須同時通過三道硬性判準（下稱**三標**）：

| # | 判準 | 通過條件 | 連續分數 |
|---|---|---|---|
| 1 | **帶內** | 通帶內每個頻點 S11 ≤ −10 dB 且 Gain ≥ +4 dB | **`worst_margin`**：帶內每個頻點對兩條規格的餘裕，取**最差那一點**。正值＝全帶達標 |
| 2 | **方向圖** | 主波束 ±45° 窗內每個角度不低於「波束峰值 − 3 dB」 | **`rad_window_margin`**：窗內最低點對該門檻的餘裕；兩個切面取較差者 |
| 3 | **可製造** | 所有金屬碎片 ≥ 4 像素、零 1–3 像素粉塵 | （二元判定，無連續分數） |

三標全部是**硬閘門，彼此不可交換**——任一項不過即出局。

**帶外選擇性不是第三個判準，而是通過三標之後的收益軸。** 帶外的要求與帶內相反：不匹配、
不輻射。分數取遠帶外（通帶兩側各 4 個頻點）的「最高增益 − 最深 S11」，稱為**帶外洩漏**
（`oob_bad`），越低越乾淨。選批時把三者壓成單一純量：先罰未過線者，過線之後只比帶外。

> **對「最高增益 − 最深 S11」這個定義的說明**：兩者確實是不同性質的量，相減沒有直接的物理
> 意義。它是一個**工程上的複合惡度指標**——帶外要乾淨，需要同時「不匹配」（S11 淺）與
> 「不輻射」（增益低）；把兩者的最壞值相加（S11 為負，相減即相加）得到一個單調的惡度分數，
> 用於候選之間的排序。它不宣稱是一個物理量，只宣稱是一個**排序用的複合指標**。

### 1.3 價值軸的四次演進

本研究的目標函數不是一開始就固定的。它改過四次，每一次都留下紀錄：

| # | 時期 | 價值軸 | 改動理由 |
|---|---|---|---|
| 1 | 初期 | 三標達標數量 | 合格解稀少，先求有 |
| 2 | 中期 | 三標＝硬閘門，**過線後帶內餘裕的邊際價值 ≈ 0** | 三標解累積到上千筆後，繼續刷帶內餘裕不再帶來設計上的選擇權 |
| 3 | 中後期 | **收益軸改為帶外洩漏**（字典序：①三標 ②帶外升冪） | 帶外選擇性是尚未被壓制的維度，且與實際佈署干擾直接相關 |
| 4 | 後期 | **帶外拆成低頻側／高頻側獨立記帳**（`usable_lo`／`usable_hi`） | 總帳型的推進被發現主要來自高頻側；低頻側長期紋絲不動，合併記帳會把真正的牆蓋掉 |

第 4 次改動同時定義了三個衍生紀錄軸——它們都是**在合格解之中**取帶外極值：

- `usable_oob`＝滿足 `worst_margin ≥ +0.15` ∧ `rad_window_margin ≥ 0` 的解之中，帶外洩漏的最小值
- `usable_lo` / `usable_hi`＝同樣條件下，低頻側／高頻側各自的帶外極值

（`worst_margin ≥ +0.15` 而非 ≥ 0 的緩衝，來自製造缺陷存活率是餘裕的函數這項實測。）

**把改軸的歷程寫出來，是為了讓讀者能判斷各時期的數字之間是否可比**——不同時期的「最佳」
指的不是同一件事。

### 1.4 本節的限制

- 三標中的「可製造」是幾何判定（碎片尺寸），**不是製程判定**。它排除了明顯無法蝕刻的結構，
  但沒有涵蓋公差、對位、鍍層等實際製程因素。
- 方向圖只在 28 GHz 單一頻點、兩個主切面上評估，未涵蓋全頻帶與全立體角。
- ±45° 窗與 3 dB 底線是與指導教授討論後訂定的工作規格，**不是來自外部標準**。

## §2　這個問題的雜訊尺度：為什麼方法級比較做不起來

本章其餘所有設計都是為了回答一個問題：**當「換一個方法、跑一次、比誰好」這件事在統計上做
不起來時，還能怎麼做研究？** 本節說明為什麼它做不起來。

### 2.1 同方法、同預算的結果離散度

本實驗室前一項工作留下 41 條完整的優化軌跡（同一套線上學習方法、同一組超參數、僅隨機種子
與初始解不同）。把這 41 條軌跡在相同的模擬預算切開，觀察「此刻各軌跡最好成績」的分布：

| 模擬預算（次全波模擬） | 仍在進行的軌跡數 | 中位 (dB) | **跨軌跡標準差 (dB)** |
|---|---|---|---|
| 100 | 36 | −4.3 | 1.3 |
| 250 | 34 | −3.6 | 1.7 |
| 500 | 24 | −2.1 | 1.5 |

**同一套方法、同一預算，結果可以相差 3–4 dB（約 ±2σ）。**

### 2.2 這個離散度的後果

在 σ ≈ 1.5 dB 的雜訊水位下，若要以 α = 0.05、檢定力 0.8 確認一項價值 1 dB 的方法改良，
每個對照組需要

> n ≈ 2σ²(z₀.₀₂₅ + z₀.₂)² / Δ² = 2(1.5)²(1.96 + 0.84)² / 1² ≈ 35 條軌跡

也就是每組三十多條 500 次模擬的軌跡；價值 0.5 dB 的改良則需要約 140 條。一條 500 次模擬的
軌跡是一到兩天的機器時間，**兩組對照就是數個月**。

**這不是實驗不夠仔細，是訊號本身小於雜訊。** 本章之後的每一項設計——批次化驗證、決定性
生成、公證制度、以效率而非單批因果評估探索型介入——都是在這個約束下的選擇。

### 2.3 本節的限制（本章最重要的一段自我約束）

這一節是全章的地基，它有三個必須攤開的弱點：

1. **「同方法」的前提並不嚴格。** 這 41 條軌跡橫跨一段時間，期間方法本身有過調整。
   因此表中的 σ **混入了部分方法差異**，是「同方法離散度」的上界，不是純值。
   這個方向對本節的論證是保守的（真實 σ 只會更小、需要的樣本數更少），但仍應標明。
2. **存活軌跡數從 36 掉到 24，存在倖存者偏差。** 長預算那一列是被篩選留下的子集，
   若軌跡的中止與其表現相關，該列的離散度會被系統性扭曲。本研究**未能排除**這一點。
3. **這個 σ 量自本研究已不再作為主力的線上學習路線。** 把它外推到現行的批次驗證路線，
   是一個**未經直接驗證的假設**。本研究採信它的理由是：兩者共用同一個設計空間、同一個
   模擬器與同一把度規，雜訊的主要來源（崎嶇的解空間地形）不隨搜尋方式改變。

第 3 點也帶出一個本研究必須正面承認的推論：**在 σ ≈ 1.5 dB 之下，本研究自己的紀錄推進
（0.2–0.3 dB 量級）同樣無法宣稱是方法的功勞而非抽樣運氣。** 本研究對此的處理不是聲稱已經
解決，而是：紀錄一律以重複量測認證其**可重複性**（§6.3），並在效果歸因上改用跨輪次的
效率趨勢而非單批因果（§4.4）。這是**繞過**，不是解決。

## §3　方法論總覽

### 3.1 三個角色與一層制度

![研究迴圈與三層時間尺度](assets/methodology_loop.png)

本研究的日常運轉由三個角色與一層制度構成：

| 角色 | 負責 | 明確不負責 |
|---|---|---|
| **研究者**（人） | 決定價值軸與戰略方向、分配資源、行使否決權、判定一項推進「有沒有意義」 | 不逐批下達指令、不手動挑選候選 |
| **代理人**（LLM agent，下稱代理人） | 起草假設與判準、分析批次結果、更新帳目、提出下一輪 | 不決定「什麼算數」 |
| **驗證機具** | 決定性地生成候選、零模擬成本預篩、計算指標、產生圖表 | 不做研究判斷 |
| **制度** | 界定「什麼算數」：判準預註冊、紀錄級宣稱須經重複量測認證、結論唯讀 | — |

全波模擬器不列為角色：它只產生真值，不參與任何決策。

**「制度」這一層的性質必須說清楚，否則它會被誤讀成一個獨立的裁決者。** 制度的載體是專案內
的規範文件與分析程式，兩者研究者與代理人都有寫入權。它的約束力不來自技術上的不可修改，而來自
三個性質：**規則在使用前就被寫下**（判準在批次發出前定稿）、**修改留痕**（結論以唯讀方式
累積，更正以標註方式就地補記，原文保留）、**判定邏輯在程式碼裡而非在對話裡**（門檻與規則
以程式實作，而非每次由代理人臨場判斷）。這使繞過制度成為一件**會留下紀錄的事**，而不是一件
不可能的事。本研究不宣稱後者。

### 3.2 三層時間尺度

| 層 | 週期 | 單位 | 產物 |
|---|---|---|---|
| **批次** | 數小時 | 一次對照實驗（30–75 個候選） | 分析、認證、模型重錨、下一批發出 |
| **輪次** | 1–2 天，**上限 3 個批次** | **一個假設** | 一份輪次紀錄 |
| **期** | 1–2 週 | 一個戰略段落 | 里程碑紀錄 |

「輪次＝一個假設」是本研究的一條紀律：第三個批次分析完就必須結束該輪，不再追加。
其作用是**強迫在資料累積到足以事後合理化任何結論之前結束該假設**，避免輪次退化成資料容器。

批次的判讀與發出由「結果到齊」事件觸發，而非由研究者的作息觸發，因此迭代週期的下限由模擬
耗時決定，不由人的可用時段決定。（以版本紀錄時間戳觀察，單日五次判讀均勻分布於 24 小時內。）

### 3.3 為什麼是批次而不是線上迴圈

前一代的研究採用**線上學習迴圈**：每一次迭代生成一個候選、送模擬、用回來的真值即時更新
代理模型，然後反向傳播。本研究改為**批次驗證**：一次生成數十個候選、集中送模擬，
模型的更新改到批次結束後離線進行。

改動的理由是產能，而產能的差距來自**架構而非常數因子**：

- 線上迴圈的每一次迭代**只產生一筆**真值，且該次迭代的絕大部分時間花在模型訓練上
  ——在前一代最後一次組態的實測中，全波模擬僅佔單次迭代時間的不到一成，
  整體產出約 **37 筆真值／天**。
- 批次驗證把訓練移出迴圈之後，模擬機的時間**全部**用於產生真值，
  單機約 **540 筆／天**（由 160 秒／筆換算），三機並行約 1,600 筆／天。

差距約 15 倍，但**它不是「拿掉某個開銷」得來的**——線上迴圈即使把訓練成本完全消除，
每次迭代仍只產一筆，仍受序列相依限制。批次化改變的是「一次能問幾個問題」。

### 3.4 本節的限制

- 上表的角色分工是**設計意圖**。實際運作中，研究者也會直接指定實驗設計與調整具體參數
  （見 §8 的案例），「不逐批下達指令」是一條趨勢而非嚴格邊界。
- 產能對比的兩端來自不同時期的組態量測，兩者的模擬設定與模型設定並不完全一致；
  15 倍應被理解為**量級**而非精確倍率。線上迴圈那一端的階段耗時剖析**沒有留存原始輸出**
  （見附錄 C）。

## §4　假設的生命週期

### 4.1 假設從哪裡來

本研究把研究問題的成熟度分成三級，只有通過閘門的才會消耗模擬預算：

```
  隨手記錄的觀察與半熟想法
        │  需要寫出「什麼情況下才值得做」
        ▼
  候選清單（每條含：做什麼、為什麼、觸發條件）
        │  觸發條件成立
        ▼
  正式輪次（假設 → 實驗 → 結論）
```

關鍵在**觸發條件**：候選清單上的每一條都必須事先寫明「在什麼情況下才開這一輪」。
這使開輪的依據是條件成立，而不是當下的直覺。

### 4.2 判準預註冊

每一輪的判準——什麼算成功、什麼算失敗、達到什麼條件就收手——必須在**第一個批次發出之前**
寫定。發出後若要修訂，**只能在任何結果回來之前**，且必須留下修訂註記（日期、理由，以及
「本次修訂發生在結果之前」的聲明）。

配套是**結論唯讀**：一輪收檔後不回改結論；日後發現錯誤，以標註方式就地補記，保留原文。

理由很直接：**事後調整判準，等於把探索性分析包裝成確認性結論**。在 §2 那樣的雜訊水位下，
一個事後選定的切分方式幾乎總能找到「顯著」的差異。預註冊是本研究對抗這件事的主要手段。

### 4.3 停滯的處理

主指標連續三個批次沒有推進時，本研究採取一套固定的升級程序，而非繼續投入：
①先驗證是判準或工具的問題；②若不是，改變候選分布而非調整參數；③若仍無效，以窮舉方式
確認是否已達該路線的上限；④帶著完整帳目升級給研究者裁決。

兩條紀律寫在程序裡：**不因慣性續投批次**、**不調降門檻製造進度**（紀錄門檻只因通過認證
而改變）。

### 4.4 兩種介入，兩種判法

這是本研究在評估自己的改良時採取的核心分流：

| 介入類型 | 特徵 | 判法 |
|---|---|---|
| **定向型** | 能明確指出「這一批的好結果就是這個介入直接挑出來的」 | 短視窗因果判定（例如連續兩批命中率低於門檻即收掉該實驗分支） |
| **擴散型** | 改變的是候選的**分布**，而非直接挑選某個候選 | **不做單批因果判定**；改看跨輪次的探索效率趨勢，需累積五輪以上才具判別力 |

理由是 §2：對擴散型介入而言，單批結果與該介入之間不存在可辨識的因果連結，
硬要歸因就是在雜訊裡讀故事。

**必須誠實指出的是：這是一個規避策略。** 本研究至今**沒有對任何擴散型介入做出統計顯著的
因果證據**，只有跨輪次的趨勢觀察。

### 4.5 本節的限制

- 三個批次的樣本量對多數判準而言偏小，因此判準被迫設得粗（命中率門檻、連續兩批規則）。
  代價是靈敏度低：小的真實效果會被判成無效。
- 預註冊約束的是判準，**不約束判準的品質**。一個事前寫死但設計不良的判準，仍然會產生
  一個看起來嚴謹的錯誤結論。
- 三級升格的中間層在實務上會積壓：候選清單累積了相當數量長期未觸發也未淘汰的條目，
  而「明確標記被否決的想法」這條規範**實際上從未被執行**——被否決的想法散落在各輪次紀錄的
  判定裡，沒有集中索引。本節描述的是制度設計，不是完全落實的現況。

## §5　證據分級與歸因

### 5.1 三級證據制

本研究把每一條設計規則標上證據等級，**只有 A 級才允許寫進候選生成器**：

| 級 | 定義 | 正例 | 反例 |
|---|---|---|---|
| **A 因果級** | 做出可證偽的預測 → 送全波模擬 → 預測命中 | 部分鏡射對稱化是「救援算子」：對散亂結構有效、對已優化結構有害。此方向性預測在一組四筆的檢驗中全數命中 | — |
| **B 相關級** | 大樣本相關性，**未通過因果檢驗**，只作為假設 | 「大主件、少組件、少細碎」與好成績相關 | 由它推出的「填補內部空洞可改善增益」在因果檢驗中四筆全負，該操作因此被移出算子清單 |
| **C 單例級** | 個案觀察，待推廣 | 全連通結構的三標通過率為 0%——但樣本僅 38 筆且集中在低金屬量區間，因此標為「**未探索區**」而非「已證實無效」 | — |

這個閘門的價值在於**它會否決自己人**：B 級的統計特徵看起來很有說服力，但轉成編輯算子就
失效——如果沒有這道關，它會被當成設計準則寫進生成器。

### 5.2 歸因方法

| 方法 | 做法 | 產出 |
|---|---|---|
| **承重分析** | 將 pattern 切成 5 × 5 共 25 塊，每塊輪流清空後重新模擬，記錄分數掉幅 | 該設計的空間重要度圖 |
| **消融與尺寸掃描** | 逐一移除金屬組件；對組件做 ±N 圈的形態學縮放 | 各組件的貢獻量與尺寸敏感度 |
| **雙向因果** | 對同一個結構同時做「移除」與「加上」兩個方向的介入 | 見 §9.2 的案例與其侷限 |
| **血統追溯** | 每個候選記錄其親代、改造步驟與亂數種子 | 任一結果都能回溯至起點 |
| **公差掃描** | 邊緣侵蝕／膨脹與隨機缺陷注入 | 缺陷存活率——餘裕相近時，穩健性才是製造判準 |

### 5.3 模型準度的量測制度

本研究的代理模型不用於取代真值，只用於**零成本預篩**與**指出值得探索的區域**。
評估它的兩個設計值得單獨說明，因為兩者都是為了防止「模型看起來變好，其實只是考卷變簡單」：

- **分層 held-out**：按樣本與優勢結構家族的距離分為近／中／遠三帶，各自回報誤差。
  若只看整體誤差，模型在熟悉區域的改善會蓋掉它在陌生區域仍然不準的事實。
- **凍結基準集**：首次評估時把當下的 held-out 集合凍結存檔，之後每一版都在同一份上評分。
  沒有它，每次重訓換一份 held-out，數字會因為「考卷變了」而漂移。

### 5.4 本節的限制

- **A 級的判定依據是小樣本命中（如四筆全中）。** 在 §2 的雜訊水位下，這種小樣本命中有實質
  的偽陽性風險。本研究以「須重複出現才升級」作為補償，但**沒有形式化的統計門檻**。
  這條約束適用於本章所有 A 級結論，包括 §9.2。
- 承重分析的結果**不可跨設計套用**：一張圖只屬於一個 pattern，換一個結構就要重新量。
  其跨家族的普適性只在兩個家族上檢驗過。
- 本研究的設計先驗可能帶有採樣偏差：「大主件、少組件」之所以看起來是好結構的特徵，
  部分原因可能是本研究在那個區域挖得最深。

## §6　誠信保證：為什麼可以相信這些數字

一個由代理人長時間自主運轉、研究者只在關鍵點介入的流程，最大的風險不是進度慢，
而是**產出看起來很好的假數字**。本節的七道防線為此存在。

### 6.1 判準預註冊（見 §4.2）

### 6.2 生成與量測的決定性

- **候選生成完全決定性**：所有隨機皆由明確的亂數種子驅動，種子隨候選清單落檔；
  各生成器的種子域互不重疊。同一份輸入必得同一批候選。
- **全波模擬在同一組態下是決定性的**：同一設計、同一模擬設定、同一網格種子重複求解，
  跨機器可得位元級相同的結果（曾以 41 次跨機重複量測驗證）。

這兩點是重複量測能夠成為認證手段的前提——但它們的**適用範圍必須說清楚**，見下一節。

### 6.3 紀錄級宣稱須經重複量測認證

任何「破紀錄」的宣稱，都必須把該設計以相同配方重新送入模擬**兩次**；
原測與兩次重測在挑戰指標上一致（差 ≤ 0.03 dB）才予採信。未經認證的數字一律標注「單次」，
不進入結論。

**這與 §6.2 的決定性並不矛盾，但兩者的關係常被誤解，必須交代清楚。**
若模擬在同一組態下是決定性的，重測就是恆等操作、不可能發現任何問題。重測之所以有價值，
是因為它檢驗的**不是同一組態下的重複性，而是跨組態的一致性**。實際攔下的問題有三類：

| 類型 | 實例 | 性質 |
|---|---|---|
| **萃取管線缺陷** | 一筆宣稱 +0.48 dB 的紀錄，八次重測全數給出 −0.06 dB。根因是指標萃取時以「頻點索引」而非「頻率值」對位，在頻點數不同的批次間錯位 | 這一類**不是靠認證規則直接抓到的**，而是重測結果的高度一致與原測衝突，反過來暴露了管線缺陷 |
| **求解器的多穩態** | 一筆設計在重複量測中收斂到兩個不同的穩定值（0.20 與 0.32，各出現數次，其餘指標則完全一致） | 自適應網格的路徑相依。**這是 §6.2「決定性」的真實例外**，其存在意味著「同一組態」的定義比預期更嚴格 |
| **邊際數值的修正** | 兩筆分別宣稱 +0.53 與 +0.43 的候選，重測後定為 +0.44 與 +0.35 | 落差 0.08–0.09 dB **超過 0.03 dB 的一致性門檻**，因此按規則兩者皆**未通過認證**；修正後的值取自重測的一致結果，並以該值進榜 |

因此準確的說法是：**這道關攔下了兩筆假象與兩筆數值下修**，而非「四筆假象」。
前兩類若沒有這道關，會直接以紀錄身分進入結論。

### 6.4 單一真相源

紀錄與門檻以一份**機器可讀的檔案**為唯一權威，所有分析工具的門檻都從該檔讀取，
不憑記憶、不人工抄寫。散文式的名鑑與報告是它的衍生物，會落後。

這不是潔癖：在本研究的運轉週期下，散文版與機器版之間出現數個版本的落差是**常態**。
指定真相源的目的，是讓落差成為一個可以被機械檢出的狀態，而不是一個要靠人記得的事。

### 6.5 查重

每一批候選在發出前都要與**全部歷史批次**交叉比對，重複即不發出（蓄意的重複量測除外）。
後端另有一道健檢，把非蓄意的重複單獨報成警報。

### 6.6 狀態對帳

在數個高風險時點（接手、更換模型、長時間自主運轉後、宣稱破紀錄前）強制執行三方一致性檢查：
版本控制、資料儲存、紀錄帳目。原則是「不信工具回報，信原始狀態」，任一項不一致即停止。

其動機是：在長時間無人監督的自動運轉中，狀態不一致具有**累積性**——一次未落地的寫入若未被
察覺，後續所有操作都建立在錯誤的基準上，且錯得越久越難回溯。

### 6.7 量測管線的凍結基準

所有結構性的程式修改都必須通過三組凍結基準的逐位元比對，以確保量測管線在研究期間
**未發生無聲變動**。這是上述所有數字可跨時期比較的前提。

### 6.8 本節的限制

- **認證只驗重複性，不驗正確性。** 若萃取管線有系統性偏差，三次重測會一致地錯。
  §6.3 第一類問題正是靠「一致但與原測衝突」被反向發現的，不是被認證規則直接攔下的。
- **決定性是實測結論，不是保證。** §6.3 的多穩態案例即為反例。更換求解器版本或模擬設定
  之後必須重新驗證。
- 七個紀錄軸中有一個仍是**單次量測**的基線，尚未補認證，該檔案已標注。
- 對帳是事件驅動的，不是持續的；兩次對帳之間的漂移仍依賴人的察覺。
- **制度的可修改性沒有技術上的保障**（見 §3.1）。門檻與規則都在研究者與代理人可寫的檔案裡，
  本研究依靠的是「修改會留痕」，不是「修改不可能」。

## §7　驗證機具：研究成本花在哪裡

在以全波模擬為真值的逆向設計中，研究成本幾乎完全由模擬預算決定。在這個成本結構下，
進度的瓶頸不在演算法本身，而在**從提出一個假設，到取得足以判定該假設的證據之間的摩擦**：
候選必須能被系統化且可重複地生成、明顯的壞解必須能在送模擬前被廉價濾除、結果必須能被自動
彙整到同一把度規上、每一筆結果必須能回溯到產生它的參數。

本研究因此把絕大部分工程投入放在這一層機具，而非核心的生成器與代理模型：
以程式碼規模衡量，**驗證機具約為核心演算法的 1.8 倍**，而核心演算法在整個研究期間幾乎未
修改。這個投入配置本身即是一項方法論主張——當方法級的統計比較不可行（§2），
產出速率取決於單一假設的驗證成本，降低該成本的邊際報酬高於改良演算法。

機具依其在迴圈中的角色分為三類：**候選生成**（依既定規則與種子，決定性產出一批待測結構
及其參數清單）、**前置篩選**（跨全部歷史的重複性檢查，以及以代理模型進行的零模擬成本預篩）、
**執行與彙整**（模擬派工、失效重試與跨機接管、指標計算與帳目更新）。介面與實作位置見附錄 B。

三條產線並行運作，分別對應不同的探索策略：**局部爬升**（以現有解為錨、單像素鄰域的隨機
搜尋，插隊優先）、**批次對照**（本章 §4 描述的假設驗證主線）、**閒置自產**（佇列見底時
自動產生低優先候選，有正式工作時立即讓位）。三者的資源配比依產出率動態調整，但批次對照
不歸零——它是教材資料與凍結對照組的唯一來源。

### 7.1 本節的限制

- 「1.8 倍」是**未扣除歷史死碼**的口徑。機具是逐輪長出來的，其中相當比例是特定輪次專用、
  已不再呼叫（保留供重現）。因此這個比例度量的是「累積投入」，不能直接讀成「當前有效機具
  的規模」。
- 工具之間存在隱性依賴，沒有依賴關係圖。

## §8　人與自動化的分工

### 8.1 決策權的實際分佈

![決策權分配與原則級定案的歸屬](assets/methodology_authority.png)

在本研究的原則級定案紀錄中，約四分之三由研究者署名，代理人署名者僅個位數。
但**這個比例衡量的是「原則級決策」的歸屬，不是總體控制權**——代理人每天做出的數十個
戰術性判斷不會進入該紀錄。

### 8.2 三種可觀察的協作形態

**形態一：人給方向與注意力，機器把它變成可證偽的命題——結果常被細化或反轉。**

| 研究者的原始觀察 | 量化之後 | 結果 |
|---|---|---|
| 「金屬組件的尺寸分布很不平均」 | 組件尺寸與三標的相關分析 | **細化**：關鍵不是尺寸離散度，而是金屬總量在主件與附屬件之間的分配 |
| 「試試看組件數量的階梯，3 塊、5 塊、7 塊都試」 | 以組件數為唯一變因的對照批 | **兌現**：產生了當時最佳的新結構 |
| 「這個方向圖的某個切面很不平衡」（目視） | 三筆合格解的波束偏斜量化 | **細化**：偏斜是家族性的（−2.7 至 −2.9 dB），不是個體缺陷 |
| 「想辦法減少對角線接觸」 | 三個批次的對角清潔階梯 | **反轉**：清潔全數失敗，對角接觸反而是該方向唯一已知的有效機制 |

四例中兩例被細化、一例被反轉、僅一例直接兌現。**人的價值在於指出值得看的方向，
而非給出結論。**

**形態二：從提案到落地的週期可量化。** 本研究記錄到單日內三項提案全數落地的案例，
以及一項模型訓練資料策略的提案在 24 小時內完成從構想到上線的案例。最短的一次戰略轉向
到成果達陣是 36 小時。

**形態三：保留給人的判斷有四類**——一項推進的「意義」判定、一個結論的**適用範圍**修正、
資源力度、模型的上線裁決。其餘可以下放。

### 8.3 弱模型化，以及它對「代理人貢獻」的反噬

本研究刻意把所有可形式化的判定邏輯（門檻、收臂規則、記帳順序）寫進分析工具的程式碼，
代理人的流程文件只保留清單與分支。這樣做的理由是可重現性：**模型會換版、會漂移，
但程式碼裡的判準不會。**

**但這個設計對本研究的貢獻主張構成一個真實的張力，必須正面處理**：如果判斷都下沉到程式碼，
那麼代理人還剩下什麼？

本研究的回答是：下沉的是**判定**，不是**提問**。程式碼能回答「這批有沒有達到預註冊的門檻」，
不能回答「下一個該問什麼」「這個異常值得不值得追」「這個結論的適用範圍到哪裡」。§8.2 的
四個案例中，量化設計、反轉的識別、家族性的判定，都發生在程式碼之外。

**這個回答的證據強度必須誠實標明：它是一個論證，不是一個實驗結果。**
本研究**沒有做過「更換執行模型、重跑同一輪」的對照**，因此「換一個模型會得到同一份帳」
目前是設計意圖，不是已驗證的性質。

### 8.4 本節的限制

- §8.2 的形態是**回溯整理**出來的，沒有對照組（沒有「純人」或「純自動」跑同一段時間），
  因此只能作為形態描述，不能作為效果證明。
- 署名統計只涵蓋被寫成正式條目的決策。
- 提案兌現週期的案例為選擇性報告，未統計未兌現的提案。

## §9　這套方法產出了什麼

### 9.1 負結果是一等產物

判準預註冊制度的直接後果，是「沒過」也會被完整記帳。本研究累積的負結果涵蓋
方法、結構與流程三類，以下為代表：

| 類型 | 負結果 |
|---|---|
| 方法假設被自己的資料否證 | 「代理模型的訓練量是瓶頸」——連續三輪實驗否證。訓練量修好之後，泛化與搜尋成績都未跟上 |
| 破紀錄不等於假設成立 | 一次線上學習的最佳紀錄出現時，該輪主假設所依賴的機制**根本沒有啟動**；紀錄來自探索而非該機制。此事被記錄為「紀錄成立、假設未驗證」 |
| 因果檢驗殺掉相關性規則 | 「填補內部空洞可改善增益」四筆全負，該操作被移出算子清單 |
| 路線被窮舉判死 | 數條結構路線（碎片家族深掘、理論模板生成、事後清潔可製造化）在累積數十至數百筆後判定無效 |
| 制度自身失效 | 一項為鼓勵探索而設計的配額調整機制，實際運轉中從未真正改變過配額，被誠實記為「形同虛設」 |
| 離線指標與實戰表現背離 | 一個離線誤差全面領先的代理模型，在實際選批中的命中率反而較低，促使本研究改以線上選拔表現作為模型上線判準 |

**負結果的價值不在數量，而在它們是被預註冊的判準判死的**——這是判準預註冊制度有在運作的
唯一外部可查證據。

### 9.2 一項結構敏感度觀察及其未解的歧義

前一代工作以「消除幾何上的斷裂結構」為目標設計了一個連通性損失，並在其結論中留下一個
例外：該損失不應破壞「對電磁性能具實質貢獻的獨立金屬集群」。**本研究把這個例外量化，
但沒有能夠解釋它。**

兩個方向的介入都會使性能崩潰：

- **移除**：在五個結構家族中，移除小尺寸金屬碎片導致四個家族的帶內餘裕下降 5–17 dB。
- **加上**：以單像素橋接把獨立金屬件連到主件（材料只增不減），同樣使性能劣化。

一個直覺的讀法是「小懸浮件是分散式共振的一部分，動不得」。**但本研究必須指出，
這個讀法無法從現有證據推出。** 本研究另有一項獨立觀察：這一類解對任意方向的單像素擾動
都極度敏感（一組 16 個微擾中，合格者為 0）。**「解位於極尖銳的局部最優」這個更簡約的
假設，可以同時解釋上述兩個方向的崩潰，而不需要訴諸任何特定的電磁機制。**

要區分兩者，需要的是本研究**沒有**的證據：表面電流分布、近場、模態分解，或移除前後的
諧振頻率位移。因此本研究只主張可觀察的部分：

> **在本研究涵蓋的結構家族中，小尺寸金屬件對性能的貢獻不可忽略，且該類解對單像素擾動
> 極度敏感。** 其機制（分散式共振 vs. 尖銳局部最優）尚未區辨。

即使在這個較弱的形式下，它仍有明確的工程後果：**可製造性必須內建在候選生成階段，
而不能以事後清潔達成**。這一點在後續三個獨立實驗中重複得到確認——但需注意，
三次確認**都在同一個結構家族內**，其普遍性未經檢驗。

## §10　與前一代工作及外部文獻的關係

### 10.1 承續關係

本工作是同一條研究線的第四代：前三代分別建立了可微代理模型的線上學習框架、雙尺度正規化與
二階段變異機制、以及自適應循環策略與連通性損失。**前三代的貢獻都在演算法層。**

本研究**未修改**前一代的三項核心機制（自適應循環策略、圖譜連通度損失、動態損失過濾），
它們仍在使用中。本研究移除的是其中一項附屬機制（訓練停滯時的權重回退），理由有三：
該規則是貪婪的，會使探索性結構失去成為新據點的機會；退回舊的生成器卻搭配當下已變動的
代理模型在原理上不一致；且原實作有兩個缺陷使其實際近乎無作用。

本節**不引用前一代的量化結果**。理由是兩者的分數定義不同（其分數為複合損失，本研究為
以 dB 為單位的餘裕），放在一起比較不成立。唯一成立的橋樑是用本研究的度規重測其設計。

### 10.2 用同一把度規重測前一代的成果

| 對象 | 原始紀錄值（前一代設定） | 本研究重測值（現行設定、同一度規） | 三標 |
|---|---|---|---|
| 前一代論文的展示成果 | +0.09 | **+0.35（帶內達標）** | ✗（含 13 個 4 像素以下碎片，不可製造） |
| 前一代歷史資料中的最佳解 | +0.38 | **+0.44（帶內達標）** | ✗（碎片型） |

結論必須精確表述：**前一代的方法能夠產生帶內完全達標的設計，問題不在帶內電性。**
若以本研究的三標衡量，這些設計並不合格——但方向圖與可製造性都不在當年的優化目標之內，
因此這**不構成對前一代的評價**，只說明兩者的「合格」定義不同。

（前一代歷史資料中 18 筆帶內達標解，經本研究以現行設定重測後存活 8 筆。）

**這組數字同時暴露了一個必須承認的問題**：同一設計在兩代設定下相差 0.26 dB。
這說明「同一把度規」保證的是**指標定義相同**，不保證**跨設定可比**。
跨代的比較唯一成立的方式就是重測——這也正是本研究採取的做法。

### 10.3 外部文獻中的位置

同領域最具指標性的對照是一個以像素化逆設計為主軸的系列工作。核心差異在**資料量假設**：

| | 該路線 | 本研究 |
|---|---|---|
| 範式 | 離線攤提：一次付清 10⁵–10⁶ 次模擬，把代理模型或策略網路訓練到全域準確，之後每個新設計分鐘級攤提 | 少樣本、真值在迴圈內：以既有資料池為起點分布，全波模擬持續作為真值 |
| 自動化主體 | 強化學習策略網路 | 大型語言模型編排工具 |
| 人的位置 | 事前約束＋事後挑選 | 迭代迴圈內共同調度 |

三條必須劃清的界線：兩者的「agent」**是不同的東西**，不可混同；該路線的人機協作比本研究
主張的更淺，但其近年的回顧文章已將人機協作明列為發展方向；該路線在晶片實測上證明了
像素化結構與傳統結構可以性能等價，這一點**支持「非直觀結構不必然次優」的一般命題，
但不構成對本研究特定結構的背書**。

**novelty 主張與其邊界**：「由人與 LLM 代理人在迭代迴圈中共同調度工具箱」這一形式，
在**像素化天線逆向設計這一支文獻中**未見先例。本研究**不主張**它在更廣的範圍
（LLM 驅動的自動化科學實驗、人在迴圈的最佳化）中沒有先例——那需要一次本研究尚未進行的
系統性文獻檢索。

## §11　可重現性、貢獻定位與效度邊界

### 11.1 可重現性

- **流程可重現**：判準、門檻、記帳順序與生成種子都在程式碼與規範文件中；
  更換執行者（人或模型）照同一份流程執行，會得到同一組判準與同一份帳目。
  **此性質未經對照實驗驗證**（§8.3）。
- **過程不可複製**：模型會換版、行為會漂移；「假設從哪裡來」與「判讀時注意到什麼」
  這兩件事不可重現。

誠實的表述是：**這套方法保證的是結論的可稽核性，不是過程的可複製性。**
且「可稽核」本身有已知缺口，見附錄 C。

### 11.2 貢獻定位

本研究的貢獻分佈在四個層次，份量不等：

| 層次 | 貢獻 | 強度 |
|---|---|---|
| **研究作業方法** | 判準預註冊、重複量測認證、兩種介入兩種判法、三級證據制、負結果記帳 | 主要貢獻。有制度攔下錯誤結論的實證（§6.3、§5.1） |
| **系統與產能** | 資料生成與模型訓練解耦，產能提升約一個量級 | 使能條件。是前者得以運作的前提，本身不是研究貢獻 |
| **判準擴充** | 將方向圖納入損失並升格為硬性判準 | 演算法層的一項擴充，改變了「合格」的定義 |
| **結構觀察** | 小尺寸金屬件的不可忽略性與擾動敏感性（機制未區辨） | 最弱的一項。見 §9.2 的自我限制 |

### 11.3 效度威脅

**量測效度**
1. **模擬 ≠ 量測。** 全部結論建立在一組從未經實物驗證的模擬設定上，實體製造與遠場量測
   尚未進行。這是本研究最主要的效度限制。
2. 同一設計在不同世代的模擬設定下相差 0.26 dB（§10.2）；跨設定的數值不可直接比較。
3. 求解器存在多穩態情形（§6.3），「決定性」的適用範圍比預期窄。

**統計效度**

4. σ ≈ 1.5 dB 的量測有「同方法」前提不嚴格與倖存者偏差兩個弱點，且外推到現行路線未經驗證（§2.3）。
5. 在該雜訊水位下，**本研究自身的紀錄推進同樣無法歸因於方法而非運氣**。認證只證明結果可重複
   量到，不證明方法使它出現。
6. A 級證據的判定依據是小樣本命中，有偽陽性風險，無形式化統計門檻（§5.4）。
7. 擴散型介入至今沒有統計顯著的因果證據，只有跨輪趨勢（§4.4）。

**外部效度**

8. **單一規格**（單埠、n257、28 GHz、單一基板、25 × 25 解析度）。跨規格泛用性未經檢驗；
   前一代曾在不調參的情況下移植到雙埠濾波器任務，本研究**沒有**做對應的驗證。
9. **族群侷限**：多數合格解集中在少數結構家族，約八成落在單一優勢家族內。
   §9.2 的三次確認全部在同一家族內完成。
10. 承重分析結果不可跨設計套用（§5.4）。

**可重現性與制度效度**

11. 「更換模型後判準與帳目不變」未經對照實驗驗證（§8.3）。
12. 制度的不可繞過性沒有技術保障，依靠的是修改留痕（§3.1、§6.8）。
13. 部分制度設計在實務上未完全落實（§4.5）。

## 附錄 A　術語表

> 本表只收本研究的自訂用語與容易誤讀的縮寫。首次閱讀建議先掃一遍。

### A.1 三個命名陷阱（會直接造成誤讀）

| 用語 | 實際所指 |
|---|---|
| **GEN**（前一代文獻中的「梯度估計網路」） | **代理模型**。「梯度估計」指它作為不可微分模擬器的可微替身、提供梯度——**不是生成器** |
| 程式中的 `SigmoidGenerator` | **生成器**。名稱中的 GEN 只是 Generator 的縮寫，與上一列同名異義、角色相反 |
| **ACP**（自適應循環策略） | 一個**排程器**，只調整學習率與二值化溫度，**不含權重回退機制** |

### A.2 度量與判準

| 用語 | 定義 |
|---|---|
| **pattern**（候選、設計） | 一張 25 × 25 的二元金屬佈局圖 |
| **三標** | 三道硬性判準：帶內、方向圖、可製造。**帶外不在其中** |
| **`worst_margin`**（帶內餘裕） | 通帶內每個頻點對 S11 ≤ −10 dB 與 Gain ≥ +4 dB 的餘裕，取最差點。單位 dB，正值＝達標 |
| **`rad_window_margin`**（方向圖餘裕） | 主波束 ±45° 窗內最低點對「峰值 −3 dB」的餘裕，兩切面取較差者 |
| **帶外洩漏 `oob_bad`** | 遠帶外「最高增益 − 最深 S11」，越低越乾淨。**收益軸，非硬判準** |
| **低頻側／高頻側**（`_lo` / `_hi`） | 通帶左側（低於 26.5 GHz）／右側（高於 29.5 GHz）的帶外 |
| **`usable_*`** | 在合格解（餘裕 ≥ +0.15 且方向圖 ≥ 0）之中取的帶外極值；`usable_lo`／`usable_hi` 為分側版本 |
| **粉塵／碎片** | 尺寸小於 4 像素的孤立金屬塊；可製造判準要求其數量為零 |
| **刀鋒解** | 對單像素擾動極度敏感、微擾後即不合格的解 |
| **缺陷存活率** | 注入隨機邊緣缺陷後仍維持合格的比例；製造穩健性的替代指標 |

### A.3 流程與制度

| 用語 | 定義 |
|---|---|
| **批次** | 一次對照實驗，30–75 個候選一起送模擬 |
| **輪次** | 一個假設的生命週期，上限三個批次 |
| **實驗分支**（臂） | 一個批次內共用同一套生成配方的候選子集；批次內比較的基本單位 |
| **認證**（公證） | 紀錄級宣稱的重複量測程序：原測＋兩次重測一致（差 ≤ 0.03 dB）才採信 |
| **重錨** | 以新累積的真值重新訓練代理模型 |
| **判準預註冊** | 判準必須在批次發出前寫定；修訂只能發生在結果回來之前 |
| **結論唯讀** | 輪次收檔後不回改結論，更正以標註方式就地補記 |
| **單一真相源** | 紀錄與門檻以一份機器可讀檔為唯一權威 |
| **查重** | 候選發出前與全部歷史交叉比對，重複即不發出 |
| **對帳** | 版本控制、資料儲存、紀錄帳目三方一致性檢查 |
| **優勢家族**（王朝） | 出現頻率最高、長期佔據紀錄的結構家族；約八成合格解落在其中 |
| **分層 held-out** | 按樣本與優勢家族的距離分近／中／遠三帶分別回報模型誤差 |
| **凍結基準集** | 首次評估時凍結的固定測試集，使跨版本比較不受測試集變動影響 |
