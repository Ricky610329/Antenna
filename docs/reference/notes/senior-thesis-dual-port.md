## 1. 出處與一句話定位

- **出處**：吳維文，《自適應循環策略與圖譜連通度損失函數於貼片天線金屬圖形生成之研究》，國立中正大學電機工程研究所碩士論文，指導教授劉立頌，115 年 6 月（p.i–ii, PDF 1–2）。正文 69 頁 + 33 篇參考文獻。

## 2. 方法管線（dual-port 部分，逐步驟）

### 2.0 與 single 管線的關係
作者的 dual 實驗**完全沿用 single 的訓練骨幹**，只換響應規格與損失（p.61, PDF 74）：

> 「本實驗在**不調整任何超參數**的條件下，直接採用 ACP、熱啟動策略與動態損失過濾機制進行訓練。」（p.61, PDF 74）

骨幹（§3.6.1, p.38–41, PDF 51–54）：
```
目標響應 y* → Generator(MLP 1024×3 → 625) → P̃
  → 可微二值化 P_soft = σ((P̃ − k)/τ)   (τ 由 ACP 排程，p.21 式(5))
  → STE 硬化 P_hard = round(P_soft)      (p.41 表 3-3)
  → 疊加饋入點遮罩 P_full = P_hard ⊕ M_feed
  ├─(a) 代理路徑：SM(P_soft) → ŷ → L_EM (+ w_SC·L_SC) → 反傳更新 G
  ├─(b) 全波路徑：HFSS(P_full) → y_real → L_real → DLF 篩選 → buffer
  └─(c) SM 線上更新：用 DLF 過濾後的 elite 子集重訓 SM
```
（Algorithm 4, p.40, PDF 53）

### 2.2 兩種損失函數（這是 dual 章最有價值的技術內容）

**策略一：雙側邊界點懲罰損失**（p.44, PDF 57，式 19–23）

把 17 個頻點劃成兩個互斥集合：`M_n257`（作者稱「阻帶頻率點集合」）與 `M_other`（「通帶頻率點集合」）。

⚠ **論文這裡的命名與物理相反、疑似筆誤**：正文寫
> 「`M_n257` 為**阻帶**頻率點集合，在此區域內 S11 應維持高反射（趨近 y*_H），S21 應提供強抑制（低於 y*_L）。`M_other` 為**通帶**頻率點集合，在此區域內 S11 應具備良好阻抗匹配（低於 y*_L），S21 應允許訊號順利通過（高於 y*_H）。」（p.44, PDF 57）

但圖 3-15 與 §4.5.3 正文（p.61）都明確說 **n257 頻段（26.5–29.6 GHz）是「通帶」**：
> 「生成的金屬拓樸結構在 n257 頻段（26.5 GHz 至 29.6 GHz）的**通帶**範圍內，S21 曲線能維持高於設定下限閾值的訊號通過量，而在通帶外之阻帶區域則呈現有效的訊號抑制。」（p.61, PDF 74）

→ **引用時以圖 3-15 與 §4.5.3 為準：n257 = 通帶。式 19–22 的下標 `n257`/`other` 是對調的。**（我們自己寫 spec 時別跟著抄錯。）

四項子損失（全部是 **Smooth L1** 且「達標即零、零梯度」的單側懲罰）：
```
L_S11,band  = L_smooth( ŷ[ ŷ > y*_L ] , y*_L )   # 通帶：S11 太高就罰
L_S11,oob   = L_smooth( ŷ[ ŷ < y*_H ] , y*_H )   # 帶外：S11 太低（漏能量）就罰
L_S21,band  = L_smooth( ŷ[ ŷ < y*_H ] , y*_H )   # 通帶：S21 太低就罰
L_S21,oob   = L_smooth( ŷ[ ŷ > y*_L ] , y*_L )   # 阻帶：S21 太高（漏過去）就罰
L_total     = L_S11,band + L_S22,band + L_S11,oob + L_S22,oob + L_S21,band + L_S21,oob   （式 23）
```
S22 與 S11 形式完全一致（作者理由：「本研究所設計之濾波器具備對稱結構」，p.44）。

**策略二：容忍區間損失**（p.45, PDF 58，式 24–25）
```
y_clamp(f) = clamp( ŷ(f), y_L(f), y_H(f) )       # y_L/y_H = 目標 ∓ 容忍偏移（圖 3-15 的 −1 dB / +1 dB）
L_interval = L_smooth( ŷ(f), sg[ y_clamp(f) ] )   # sg = stop-gradient
```
帶內零損失、帶外拉回最近邊界。

**作者的比較結論**（p.45, PDF 58 + 圖 3-16, p.46）：
> 「實驗結果顯示，**雙側邊界損失在本研究之實驗條件下具有較優的收斂表現**，其僅對違規點施加精確梯度之特性，有助於生成器更穩定地收斂至同時滿足 S11 與 S22 雙重頻率規格的天線幾何結構。」

圖 3-16 對照（p.46, PDF 59）：(a) 邊界損失 → S11 在 ~28.5 GHz 深達 −40 dB、S21 通帶平頂貼齊 −3 dB；(b) 容忍區間損失 → S11 僅到 −13 dB、S21 峰位左偏到 ~27 GHz。**(a) 明顯較好。**

## 3. 物理意義（為什麼這組規格在電磁上說得通）

### 3.1 這根本不是「純濾波器」，是**帶輻射的雙埠濾波天線**

這是本篇 dual 最關鍵的物理判讀，決定我們後續怎麼定義判準：

- HFSS 設定用 `CreateOpenRegion(Boundary="Radiation", OpFreq=28GHz)`（`antenna/patch/patch_simulator/dual_port.py:429`）——**開放輻射邊界，不是封閉波導**。結構會往自由空間輻射。
- 論文 §2.1.1 的鋪陳也是**「濾波天線」**（filtering antenna）：
  > 「濾波天線……旨在將頻率選擇性的濾波功能與天線的輻射功能整合於同一結構之中，使天線在工作頻段內具備高輻射效率的同時，對非目標頻段的增益予以抑制。」（p.3, PDF 16）
- **能量帳直接印證**：通帶目標 S11 = −12 dB（|S11|² = 6.3%）、S21 = −3 dB（|S21|² = 50.1%）。兩者相加只有 **56.4%**，缺的 **~44% 功率不在 S 矩陣裡** → 只能是**輻射 + 介質/導體損耗**。一個正常的無輻射微帶濾波器通帶插入損耗應該 < 1 dB（|S21|² > 79%）；**訂 −3 dB 就是承認「有一大半功率被輻射掉了」**。

→ **學長說「那個電路應該叫濾波器」——更精確的說法是「二埠濾波天線 / filtering antenna」**。這個區分不是名詞遊戲：它決定了「S21 通帶只要 −3 dB」是合理規格而不是爛規格，也決定了我們**不能**用一般濾波器的判準（插損 < 1 dB、帶外抑制 40 dB）去套。

### 3.2 帶外 S11 = −1.25 dB 與 S21 阻帶 = −20 dB 是同一件事的兩面

被動網路能量守恆（單埠激發）：`|S11|² + |S21|² + P_rad + P_loss = 1`。
阻帶要求 S21 ≤ −20 dB（|S21|² ≤ 1%）；若同時要求輻射也小，則反射必須接近 1，即 S11 → 0 dB。
論文訂 **S11 帶外目標 −1.25 dB（|S11|² = 75%）**，比「無損耗理想全反射」寬鬆了 25 個百分點——**這 25% 就是留給帶外輻射與損耗的餘裕**。
→ 兩條帶外規格**互相蘊含、不會打架**；真正的硬約束是 S21 阻帶。這也意味著**帶外 S11 這條規格資訊量很低**（幾乎自動達標），我們定判準時不該讓它主導 worst-margin。

### 3.3 S21 通帶比 S11 通帶寬 —— 這是刻意的濾波器形狀

從 `configs/dual_base.yaml` 反推的精確頻界（見 §4）：
- **S11/S22 通帶 = 26.5–29.5 GHz**（n257）
- **S21 通帶 = 25.5–30.5 GHz**（比 S11 各邊多 1 GHz）

物理上合理：S21 的過渡帶（roll-off）需要頻率空間才能從 −3 掉到 −20；把 S21 的平頂訂得比匹配帶寬 1 GHz，等於**只要求「n257 內傳得過去」而把陡峭度需求推到 ±1 GHz 的過渡區**。若把 S21 平頂也縮到 26.5–29.5、阻帶仍從 31 開始，等於要求 1.5 GHz 內掉 17 dB（~11 dB/GHz），對 25×25 / 5 mm 的自由度而言可能是超規格的。

### 3.4 為什麼 dual 不需要（也不能）沿用 SC Loss 的連通性論證

single 的 SC Loss 物理論證是：**孤島 → 無法承載饋入點驅動的相干電流 → 寄生相位隨機的二次輻射 → 遠場場型畸變**（§2.3, p.10–11, PDF 23–24）。這條論證的落腳點是**遠場場型**。

dual 沒有遠場輸出，論證鏈斷掉。作者自己也講明：
> 「由於雙埠濾波器之電磁模擬目前**未輸出遠場輻射場型**，本實驗**暫未引入 SC Loss**，以避免因缺乏場型評估依據而導致對生成結果的誤判。」（p.61, PDF 74）
> 「由於雙埠濾波器之設計本身**不需考慮遠場輻射場型**，因此本實驗並未引入圖譜連通度損失（SC loss）進行孤島抑制，而是專注於滿足 S 參數之頻率響應規範。」（p.61, PDF 74）

**更根本的一點（論文沒說、但我們必須知道）**：在濾波器裡，**「兩埠之間不直流連通」是正常且常見的設計**——耦合諧振腔濾波器（coupled-resonator filter）靠的就是縫隙的容性/感性耦合傳能。圖 4-10 的 R_feed = 0.00% 同時 S21 通帶仍達 −3 dB，正是這個機制在起作用。
→ **single 的「所有 feed 必須同塊」連通性判準，直接搬到 dual 會變成一個幾乎恆為 0 的死指標**（見 §5.3）。

**兩個要小心的 code 差異（`dual_port.py` 自己的註解就標了）**：
1. **Sweep Type**：dual 用 `Fast`，single 用 `Interpolating`（行 478 註解）。兩者重建演算法不同 → **dual/single 的頻率響應數值不能直接混在同一個 SM 訓練集裡當同分佈看**。
2. **無插值補點**：single 會檢查點數並 `np.interp` 補到 17 點；dual 直接 `iloc[0:17]` 截取，而**回傳的 dict 用的是 `iloc[:, 1]` 全長**（行 578–594）。若 HFSS 吐出的點數 ≠ 17，回傳張量長度就會錯，且**不會報錯**。→ **開線第一批必做的 sanity check：assert 每條響應 len == 17。**

## 6. 可移植配方（能直接搬 vs 不能搬）

### ✅ 可以直接搬

1. **目標規格全套**（§4.1 表）。`configs/dual_base.yaml` 已經是論文圖 3-15 的精確數值化，逐點對得上。**dual 線可以直接沿用論文規格，不必自己重新訂頻界。**這一項是本次精讀最大的收穫。
2. **「達標即零梯度」的單側懲罰哲學**。論文 p.43 的論證（避免已達標的 S11 與未達標的 Gain 搶梯度資源）在 dual 上更重要——dual 有 **6 個互相競爭的子目標**（3 條響應 × 2 個頻段），MSE 式的無差別擬合幾乎必然被最容易的那項主導。
3. **雙側邊界懲罰 > 容忍區間**（作者實測結論 + 圖 3-16）。我們 dual 線第一件工程事就是把 §5.2 的 low+high 雙註冊做出來，這是低風險、有作者背書的改動。
4. **S21 通帶比 S11 通帶各寬 1 GHz** 的設計手法（留過渡帶）。
5. **能量守恆自證**：`|S11|² + |S21|² ≤ 1` 逐頻點檢查，任何一筆超過 1 就是資料/模擬壞了。這是 dual 特有的**免費儀器自證**（single 沒有這種閉合檢查），完全符合我們「無因次量 · 儀器自證」的有效做法清單。**建議直接寫進 dedust 的 dual 判讀器。**
6. **ACP / DLF 骨幹不動**：作者已驗證「不調超參直接移植」可行（p.61）。我們也應該先跑 base 對照再動旋鈕。

### ⚠ 需要改寫才能搬

7. **R_feed 不能沿用**。`FeedReachability` 的定義是「全部饋電點**同塊**時回傳連通塊佔比，否則為 0」（`losses.py:173-174`）。dual 的耦合式濾波器**本來就允許兩埠不直流連通**，圖 4-10 的 0.00% 就是這樣來的。直接沿用會得到一個幾乎恆為 0 的死指標。
   **建議的 dual 可製造性代理量（三選或合成）**：
   - (a) `max_component_frac` = 最大連通塊像素 / 總金屬像素（罰碎片化，不預設兩埠必須連通）；
   - (b) `per_feed_reach` = 每個 feed 各自所屬連通塊的像素佔比，取兩者的 **min**（保證兩側都有實體結構承載電流，而非懸空孤島）；
   - (c) 最小特徵尺寸檢查（單像素細絲、對角接觸）——這條與 single 共用，是真正的「可製造」而非「電磁合理」。
   → 三者物理意義不同，別合成一個數就當「可製造」交差。
8. **worst_margin 要新寫 dual 版**。`losses.py:680` 明文擋掉：
   > `"worst_margin 目前只支援 single-port (method) target;{label} 無 'method' (dual interval 未實作)。"`

   **建議定義（六項單側 margin 取 min，單位 dB、正 = 達標）**：
   | 項 | 定義 | 頻點 idx（17 點網格） |
   | --- | --- | --- |
   | m1 | `−12 − max(S11[band])` | 5–11（26.5–29.5） |
   | m2 | `−12 − max(S22[band])` | 5–11 |
   | m3 | `min(S21[pass]) − (−3)` | 3–13（25.5–30.5） |
   | m4 | `(−20) − max(S21[stop])` | 0–2 與 14–16 |
   | m5 | `min(S11[oob]) − (−1.25)` | 0–4 與 12–16 |
   | m6 | `min(S22[oob]) − (−1.25)` | 同 m5 |

   `worst_margin_dual = min(m1..m6)`。
   **但先想清楚 m5/m6 要不要進 min**：由 §3.2 的能量守恆論證，帶外 S11 幾乎自動達標，資訊量低；把它塞進 min 只會讓判準對一個「白送」的量敏感。**建議 m5/m6 只記帳、不進主 min**（比照我們 single 把帶外拆成 usable_lo/hi 獨立紀錄的做法，見 `docs/memory/feedback_value_axis_oob.md`）。
9. **對稱性可以當槓桿**。論文假設「濾波器具備對稱結構故 S11 = S22」（p.44），但**pattern 本身不對稱**時 S11 ≠ S22（`dual_port.py:550` 註解也這麼說）。我們已有 mirror generator（`single_sc_mirror`），若加一條**上下鏡像**（交換兩埠的軸）約束，可讓 S11 ≡ S22 **恆等成立**，直接把六項判準降成四項、自由度從 625 降到約 325。這是 dual 特有、single 沒有的結構性紅利。
   ⚠ 注意 single 的 mirror 是左右軸（feed 在底部中央），dual 需要的是**沿 row 中線的上下鏡像**——**是新的對稱軸，不是改個參數。**

### ❌ 不能搬 / 不能引用

10. **論文沒有 dual 的任何量化基準**。不能說「學長 dual 達到 X dB」——他只給了一張沒有數字的曲線圖。我們自己第一批 HFSS 出來的數就是全場第一個 dual 基準，**必須自己 notarize**（`/notarize` 公證流程）。
11. **不能引用論文為 dual 的「攤提規模」背書**。論文 dual 連 epoch 數都沒給；`harvest_dual` 10,023 筆是我們自己的資產。
12. **SC Loss 的連通性論證不能搬到 dual**（§3.4）。它的落腳點是遠場場型，而 dual 無遠場。若我們要在 dual 上談連通性，必須另外建立論證（例如「碎片化 → 蝕刻公差敏感 → 模擬-實測落差」的**可製造性**論證，而不是場型論證）。
13. **式 (19)–(22) 的 `M_n257` / `M_other` 下標對調**（§2.2）——照抄會寫錯論文。

## 7. 侷限與審稿人視角

### 作者沒做的（＝我們的空間）
- **dual 完全沒有幾何約束**：無 SC Loss、無 TV、無任何連通性 loss。圖 4-10 的 R_feed = 0.00%。
  → **論文最強的方法貢獻（SC Loss）在 dual 上一次都沒用過。**「三件套整合」的協同效應（表 4-4）**只在 single 上驗證過**。
- **dual 沒有消融**：四組消融實驗（表 4-2 / 4-3 / 4-4）全是 single。dual 只有「一組設定跑一次」。
- **dual 沒有基準對照**：沒有 random baseline、沒有 Base 策略對照、沒有跨 seed 重複。
- **dual 沒有量測**：全論文都沒有實體量測，§5.2 未來展望才提「下一階段研究將進行 PCB 製造以及隔離室之遠場輻射場型量測」（p.65, PDF 78）。
- **dual 沒討論可製造性**：連「這個 pattern 印得出來嗎」都沒問。

### 我們引用時必須劃清的界線
1. **「規格無關泛用性」是作者的措辭，不是被嚴格驗證的宣稱**。實際證據只有「換一組 target、跑一次、曲線看起來對」。審稿人會問：跑了幾次？有沒有 seed variance？跟隨機搜尋比呢？**我們引用時應說「作者以單一 dual 案例示範框架可移植」，不要說「已證明泛用」。**
2. **「不調整任何超參數」是優點也是弱點**：dual 的規格複雜度（6 個子目標 vs single 的 2 個）顯著更高，沿用 single 超參**不代表最優，只代表可跑**。我們若在 dual 上調超參並贏，不構成對論文的反駁，只是補了作者沒做的事。
3. **R_feed = 0.00% 這個數字要小心處理**。它不是「學長 dual 失敗了」的證據（耦合式濾波器不連通是合法的），但它**確實證明「論文的 dual 結果未經任何可製造性檢驗」**。我們的定位應該是「補上 dual 的可製造性軸」，而不是「指出學長做錯」——這也與我們既有的敘事一致（見 `docs/memory/project_senior_showcase_vs_f2.md`：學長可合規、我們補可製造 + 系統化）。
4. **術語要統一**：論文在 §2.1.1 講「濾波天線」、在 §3.6.2/§4.5.3 講「濾波器」，圖 2-1 標 `Filter (Dual Port)`。我們的文件建議統一用**「二埠濾波天線（filtering antenna）」**並在首次出現時說明「開放輻射邊界、通帶 S21 目標 −3 dB 即因輻射佔去大半功率」——這樣既精確又預先擋掉審稿人「這插損也太大了吧」的質疑。
