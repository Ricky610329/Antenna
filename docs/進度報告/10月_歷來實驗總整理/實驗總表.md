# 歷來實驗總表：像素化貼片天線與濾波器 AI 設計，2023–2026

> 整理日期 2026-10-23 16:20。素材是同層 `notes/` 的四份世代筆記與 repo 文件，本表只整理、不新跑模擬，數字全部照筆記原文抄。
> 用途：向日月光報告時，跨世代查「某個主題每一代做過什麼」。§1 是世代一覽，§2 按主題索引，§3 是全部實驗的流水帳，§4 是數字不一致與待確認處。

## §0 說明

**範圍與限制：**

- 四代的結果幾乎全是 HFSS 全波電磁模擬。唯一的實作量測是吳維文 2026/03/24 報告的 5 個樣品，以及 2026/05/28 的顯微鏡 pixel 尺寸量測；我們 8/31 交付的 39 個設計還沒有實測。
- 各代 loss 的定義不同，loss 數值不能跨世代比較。跨代比較只看「規格過了沒」，第四代起另有統一的 dB 尺 WM。
- 筆記本身有缺口與互相矛盾處，集中列在 §4，並寫明本表採用哪個值。
- 當年各代的優化目標不同：前三代以 S11 與增益為主，沒有把 radiation pattern 與可製造性放進目標。定義不同，不構成評價。

**白話術語：** 第一次讀到不懂的詞，先查這裡。

| 術語 | 白話 |
|---|---|
| 像素化圖形、pattern | 把金屬區切成網格，每格填金屬或不填，主力是 25×25、每格 0.2 mm、共 5×5 mm |
| HFSS | 業界常用的電磁模擬軟體，四代都拿它當真值；一筆要數分鐘，不能算梯度 |
| 生成器 G、MPGN | 吐出像素圖形的神經網路；第一代叫 MPGN，金屬圖形生成網路 |
| 代理模型 SM、GEN | 用神經網路近似 HFSS，輸入圖形、輸出預測響應；第一代叫 GEN，梯度估計網路。HFSS 不能算梯度，靠它把梯度借回生成器 |
| 線上學習 | 生成器與代理模型邊產生、邊模擬、邊學，不先收大資料集 |
| STE | 直通估計，讓 0/1 階梯函數也能傳梯度的近似技巧 |
| BiScaleNorm | 錢鵬予的雙尺度正規化：正負兩側分別縮放，緩解二值化造成的梯度飽和 |
| 變異、回滾 | 錢鵬予二階段法的兩個零件：週期性隨機翻轉部分像素以跳出局部解；變異前若當下不如歷史最佳，就退回最佳圖再變異 |
| ACP、ACS | 吳維文的自適應循環排程，早期叫 ACS。偵測 loss 停滯就重啟學習率與二值化溫度 τ，取代變異 |
| 熱啟動 Base-1、Base-2 | 用理論公式算出的 28 GHz 初始貼片當起點，不從空白開始 |
| DLF | 吳維文的動態菁英篩選：用累計平均當門檻，挑好樣本給代理模型複習 |
| TV、IS、GC、SC loss | 吳維文依序試過的四種孤島抑制 loss：總變差、孤立像素、閉運算、圖譜連通度。CCU0528 的 KNS 數值與 IS 完全相同，推測是改名 |
| R_feed | 吳維文定義的饋入可達率：與饋入點連成一塊的金屬占總金屬的比率，越高代表孤島越少 |
| 孤島、粉塵 | 孤島是沒接到饋入點的懸浮金屬；粉塵是第四代用語，指 1–3 像素的小碎片 |
| WM | 第四代的帶內最差餘裕：每條規格在每個評分頻點離門檻多少 dB，取最差那一點。正值代表全部通過 |
| radiation pattern | 方向圖，前代多稱場型。第四代要求 28 GHz 的 φ=0°、90° 兩切面在 ±45° 內不低於峰值 −3 dB，簡稱 rad |
| 三標 | 第四代單埠合格門檻：WM ≥0、rad ≥0、可製造三者同時成立；7/12 起合格另要 WM ≥ +0.15 當製造緩衝 |
| 可製造 | 第四代七月定義為每塊金屬 ≥4 像素、沒有粉塵；八月起出圖再一律加菱形橋 |
| 帶外、帶外洩漏、左側 | 帶外是規格頻段以外。帶外洩漏＝帶外最高增益減帶外最深 S11。左側指 24–25.5 GHz 的低頻帶外，是規格之外另加的要求 |
| 款式 | 第四代把結構相近的設計歸成一個款式 |
| 前代資料池 | 第四代承接的前代歷史模擬 34,215 筆，單埠 24,189、雙埠約 10,023 |
| 公證 | 同設定重跑兩次以上、結果一致才承認；HFSS 在固定設定下是位元級決定性的 |
| 批次線上學習 | 第四代的工作方式：判準先寫死、工具產生一批候選、SM 初篩、三台 HFSS 批次量測、判讀後重訓 SM，再出下一批 |
| 爬山、嫁接、區塊移植 | 爬山＝每次只改少數像素、留下變好的；嫁接＝把一個設計的一塊金屬移到另一個設計；區塊移植＝好設計之間互換相異區塊 |

## §2 主題索引

**跨世代觀察：** 先講四條跨世代都看得到的線，細節在各小節。

1. **孤島與對角導通是同一個製造問題的四代解法。** 陳廷茂口試時被指出對角相接的像素實際可能斷，提出擴邊構想；錢鵬予用 Over Unite 把格寬放到 0.21 mm、並決定不刪孤島；吳維文在訓練中加連通 loss，把 R_feed 拉到 61.98%〔學長報告值〕；我們發現 0.01 mm 對角重疊做不出來、懸浮金屬本身在承載共振，改成出圖一律帶 0.10 mm 菱形橋，WM 變化中位只有 −0.07 dB〔我們單次〕。四代一致的發現是：直接刪孤島或補洞都會傷響應，要在生成端內建。
2. **對稱要在生成時就內建。** 錢鵬予 2024/09 試過、圖沒存；吳維文的 Mirror 8 只停在代理模型預測，沒進碩論；我們證實事後把好設計對稱化會毀掉它，WM 變化中位 −17.16 dB〔我們單次〕，生成時就精確鏡射才做出 +0.599 dB〔我們公證〕的對稱天線。
3. **饋入強制放金屬四代都保留，但目的在變。** 第一代證明固定饋入收斂較穩；第三代一度觀察「不固定較好」，條件是只在變異後才套上，之後又把固定區擴到 9×9；到第四代寬頻濾波器，反而發現兩埠的金屬要斷開，低頻阻帶才壓得下去。
4. **代理模型不夠準，是第二代起反覆出現的瓶頸。** 錢鵬予指出代理模型「擬合值對但導數不對」的梯度誤差；吳維文的預訓練出現過擬合；我們量到 SM 在寬頻 v6 好設計之間排序相關只有 0.15–0.18、CNN 為 −0.13〔我們單次〕，因此把 SM 降為粗篩工具，改學「改了哪幾格、曲線變多少」的變化量模型後，上線排序 ρ 由原 SM 的 −0.27～−0.39 轉為 +0.24～+0.50〔我們單次〕。

### §2.4 孤島、連通與導通

**結論：** 這是同一個製造問題的四代解法：對角相接的像素做不做得出來、懸浮金屬能不能刪。四代一致發現直接刪孤島或補洞會傷響應，所以解法一路往生成端移：擴邊構想、Over Unite 0.21 mm、訓練中加連通 loss，到第四代出圖一律帶菱形橋。

**四代一條線：**

- **第一代，發現問題：** 口委指出 90° 對角相接在 HFSS 算連通、實際洗板可能斷；陳廷茂提出內部格子四邊各擴 0.05 mm，讓對角重疊，0.2→0.3 mm，只是構想。
- **第二代，放大格子、不刪孤島：** Over Unite 把格寬 0.2→0.21 mm 保證對角導通；試過開閉運算與直接刪除，發現刪了會「劇烈引響天線特性」，決定不刪。
- **第三代，訓練中抑制：** TV→IS→GC→SC 四種 loss，定義 R_feed 來量；碩論三機制合用把 R_feed 拉到 61.98%〔學長報告值〕，也確認拿掉孤島響應會變差。
- **第四代，承認懸浮金屬在承載、改從幾何補橋：** 除塵 5 筆崩 4 筆、搭橋崩 5 dB 以上〔我們單次〕，證實粉塵與懸浮翼是共振的一部分；0.21 mm 格子的對角重疊只有 0.01 mm，做不出來，於是出圖一律加 0.10 mm 菱形橋，WM 變化中位 −0.07 dB〔我們單次〕；濾波器還查出舊模擬幾何把零厚度對角點接觸當成導通。
