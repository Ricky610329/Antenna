# 九月份進度報告

- `九月份進度報告.pptx`：共 23 頁：原有九月內容及交付目錄 17 頁，七月、八月成果回顧各 3 頁，可用 PowerPoint 編輯。
- `九月份進度報告.pdf`：與簡報內容相同，適合閱讀與分享。
- `九月份進度報告.html`：較完整的文字報告，可直接用瀏覽器開啟。分享時請連同本資料夾中的 PNG 圖檔保留。
- `九月份進度報告.md`：文字報告原始稿。
- `dual_wm_mfg_history.csv`：17 筆 dual 歷史紀錄。第 5 頁曲線由可編輯線段、標記與文字組成，沒有內嵌 Excel 資料表。

架構圖、七月研究流程與表格可直接在 PowerPoint 中修改。歷史曲線、代表圖樣及交付目錄保留來源圖片；新增的菱形橋示意圖另附 SVG 原始檔。

七、八月回顧的內容與版面來源為 `docs/report/monthly_recap_2026.json`；`docs/report/build_monthly_recap.ps1` 使用 PowerPoint 產生待審查副本，不直接覆寫交付版。

本次內容截至 2026-09-13。三機初步驗收、9/12 本機修正版測試與尚待設定的模型登入，分別標示各自範圍。

改版前的原稿與圖檔保留於 `備份_20260913_改版前`。原有 `make_pptx.py` 仍是舊版產生器，請勿用它覆寫新版簡報。新版可直接編輯 PPTX，文字稿則編輯 Markdown。
