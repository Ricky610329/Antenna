diffsim（`script/diffsim/`）在 2026-08-03 從「已收線的失敗路線」翻成**有價值的資產**。
完整證據在 `docs/log/analysis-10-sm-vs-physics.md` §37–§38（只指向、不複製）。

**Why:** 之前的結論是「MoM 路線依判準收線，證據顯示是離散化天花板不是 bug」——
**那個結論錯了**，而錯的方式（見 [[feedback_failure_modes]] 第①類）值得記住。

**How to apply:**

- **真根因＝埠模型**：delta-gap 直接壓在貼片邊 0.2mm 一格上，對同一模態振幅注入 **2.2 倍**電流。
  HFSS 的埠在 22.5mm 饋線的**遠端**（`DoDeembed=True` 只搬參考面）⇒ **兩邊的埠物理從一開始就不同**。
- ❌ **舊的「rooftop 表達不出邊緣奇異性、`1/√N`、要 629 格」已撤回**（統計假象：那組掃描是
  固定 dx 改貼片尺寸）。引用舊結論前先看 §37.1。
- **求解器設定用登記表 `l2.SOLVERS` 取**（`dcim`/`l3`/`l3fl`/**`l3fld`**），不要在呼叫端拼旗標
  （本輪為此踩過四次「設定散在呼叫端 ⇒ 研究路徑與出貨路徑悄悄分岔」）。
  ⚠ **`l3` 不可當排序器**（eta 修正後正片命中率 18.3% → 3.3%，因為它的 eta 有集總埠的假頻率斜率）。
- **出貨組態＝`l3fld` + `a_quad=1`**（真饋線 + 駐波 wave port + eta 修正 + 饋線不進遠場 + 對角連通）。
  §49.5 那個「ρ 暴漲而命中率崩掉」已用 `a_quad` 2×2 消融**歸因完畢（§51）：不是對角的錯，是
  `a_quad=4` 的錯**。四組態同批 fit clean n=680：
  `l3fl` q1 命中 26.7%／`l3fl` q4 **31.7%**（無對角時「更準的求積」如預期更好，三指標全同向）
  ／**`l3fld` q1 命中 55.0%、ρ +0.8918（最好）**／`l3fld` q4 **15.0%**。
  ⇒ **交互作用專屬於「準求積 × 對角基底」。**
  ⚠ **代價要講明**：`a_quad=1` 有一個**直接數值積分證實的錯誤**——「對角 × 軸向共用 `cell_a`」
  互耦**高估 69%**（共用格 ⇒ 距離 0 ⇒ 拿到 `G(0)`；`l3fl` 裡 x–y 的 `same`=0 把它歸零
  ⇒ **從不發生，加了對角才會**）。
  ★ **假說（§51.4，未驗）**：互耦高估 = 對角路徑等效被加串聯阻抗 ⇒ 橋變弱
  ——**而真實的橋本來就弱（10µm 頸縮）** ⇒ **這個數值錯誤可能剛好在模擬我沒建模的物理**。
  決定性檢驗＝`a_quad=4` + 顯式頸縮阻抗（掃 25–500 pH）能否重現 55%。
  ⇒ ⚠ **在檢驗完成前：可以說「排序有用」，不能說「對角物理是對的」。**
  ⚠ `b_reg=0.4dx` 是**自由參數且在 `a_quad=1` 世界裡調的**；為 `a_quad=4` 重校準得
  **0.3151dx**（與 agent 獨立量的 `b_eff=0.3363dx` 差 7%），近場誤差 −15%→±2–5%，
  **但選批沒救回來**（15.0%）。
- ★★ **第四個規格不符＝對角連通**（§45/§47）：HFSS 的像素盒是 `pixel+0.01mm`
  ⇒ **對角相鄰在角落重疊 0.01×0.01mm、Unite 後導通**，而 rooftop 只有邊相鄰
  ⇒ **全史 57.1% 的樣本幾何與 HFSS 不符**。修法＝電流矩向量 + 對角只在唯一通路時啟用。
- ★★ **誤差已從「結構性有害」翻成「結構性有利」**：實際 ρ 超過自己的純噪音版、
  命中率贏純噪音 10 點（§36 當時輸 10 點）。
- ★★ **與 SM 的同池對照（§51.6；先前所有跨池比較作廢——fit 分割比評估池容易）**：
  正片 `clean_OOS` n=817 命中率／`P(勝隨機)`／ρ(wm)——
  隨機 10.0%；`l3`（08-03 前）10.0%／17.9%／+0.30；**`l3fld` 41.7%／61.7%／+0.8248**；
  SM-cnn 41.7%／80.0%／+0.84；SM-two 45.0%／86.4%／+0.86；SM-mlp 51.7%／87.5%／+0.84。
  負片 n=1200：`l3` 50.0% → **`l3fld` 83.3%**（ρ +0.46→+0.65）。
  ⇒ ★ **ρ 已追平 SM，差距在 `P(勝隨機)`（61.7% vs 80–87.5%）**。兩指標問不同的事：
  **命中率＝整批品質（已追平 SM-cnn）／`P(勝隨機)`＝能不能出一個王（明顯落後）**
  ⇒ **對「推紀錄」這個用途，落後的正是要緊的那一半。**
- ★★ **唯一在兩池都一致、且與模型對錯無關的結構性結論**：
  **真值 top-60 裡 Gain 邊界主宰的比例 —— 正片 97%、負片 12–15%**
  ⇒ **正片的好 pattern 被「增益」卡住、負片的被「匹配」卡住。剩餘空間在 Gain 半邊。**
- ❌ **兩條機制敘事只在評估池成立、已收回**：「`min()` 被 Gain 通道毒死」與
  「換讀出 `−mean(S11[5:12])` 更好」（fit 分割上四格全輸）⇒ **結果重現、解釋不重現**。
  ⚠ 引用 analysis-10 §38 的機制段落前先看 §42。
- **還開著的**：**Gain 通道仍系統性太樂觀**（真值 top-60 有 **97%** 由 Gain 決定、模型只有 22%）
  ⇒ 剩餘空間幾乎全在這裡；`gamma_from_line` 強制 `|w|=1` 有 ~19% `Re(Zin)` 敏感度。
- ⚠⚠ **與 diffsim 無關但影響全專案**：HFSS 掃頻是 `Interpolating` ⇒ 遠場只在真正解過的頻點存在
  ⇒ **26.1% 的樣本至少一個 Gain 值是 `np.interp` 捏的、5.0% 的 `worst_margin` 由捏的點決定**
  （改用最近真解點 margin 中位動 **2.28 dB**）⇒ 污染 SM 標籤與公證判定。
- ★ **方法論**：08-03/04 三個最大進展——埠模型、Gain 漏乘輻射效率、對角連通——
  **兩個是「規格不符」、一個是「實作 bug」，沒有一個是物理更精深**。
  ⇒ **先審「有沒有在模擬 HFSS 實際做的事」，再談物理深度。**
