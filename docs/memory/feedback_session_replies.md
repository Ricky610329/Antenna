Ricky 問「為什麼很多時候你都不會在這 session 做回覆,是不是你太多工了?」(2026-08-05)。
自主迴圈的靜默 tick+一行狀態註記讓他覺得 session 沒在跟他說話;詳帳都落在 round 檔/scratch,
對話裡反而稀疏。

**Why:** 使用者的體感=對話是主介面;檔案是歸檔不是溝通。多線並行時尤其需要在對話裡
保持「人話能見度」,否則像黑箱。

**How to apply:** ①每個重要節點(判定/發現/事故/發車/收輪)在對話裡給 2-4 句人話摘要,
不只寫檔;②安靜 tick 照舊一行,但一天至少一次主動彙整(晨報已有,傍晚可加一段);
③他問「現在怎樣」時=訊號,表示能見度又掉了,回答後檢討當下溝通密度。
