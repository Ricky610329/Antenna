# 消融方法論 — 對已量測 pattern 做受控幾何變體並歸因

> **定位**：single-port 收尾交付物之一（`decisions.md`「Single-port 收尾期程」②）。
> 把 R54（菱形橋）／R55（對稱化）／R56（塊歸因）三輪發展出的作法收攏成可複用的操作手冊，
> 讓後人拿到**任何一張已量測的 pattern**，都能照同一套流程做消融、歸因、產出設計規則。
> **本檔只連結、不複製** round 檔內容；所有數字皆引自已收檔的 round 檔與閉帳統計。

---

## 0. Scope 與 Limitations（先講）

**適用域**：Ansys HFSS · RO4003C 0.508 mm · 5×5 mm 輻射體離散為 **25×25 像素（0.2 mm/px）** ·
單埠集總埠 · 目標 26.5–29.5 GHz · 判準尺＝`worst_margin`（帶內）＋`rad_window_margin`（±45°/3 dB）。
量測基準為 **S0 網格**（HFSS 預設求解設定）。

**四條硬限制，引用本檔任何規則前先讀**：

1. **這裡的規則是「本域經驗規則」，不是電磁定理。** 全部由 25×25／單基板／單一頻段的實測差分歸納而來；
   換基板、換頻段、換解析度（如 50×50）都要重測。
2. **S0 網格對「幾何微變」自帶 ±0.3 dB 抖動。** 同一幾何重測是 bit 級一致（跨機重現，雜訊地板 ≈ 0），
   但幾何一動就重網格 → 差分自帶 ±0.3 dB 級抖動（[round-54](../log/round-54-diamond-bridge.md) §4）。
   **單筆 |Δ| < 0.3 dB 一律不判**。
3. **S0 本身未收斂。** S0→S1 的 |Δf_res| 中位 ~1 GHz、|Δwm| 中位 0.81 dB
   （[round-52](../log/round-52-anchor-assault.md) §4 網格定讞）。本檔所有絕對值都是「S0 尺語義」——
   尺內自洽、可比較，但**不是最終電性**。跨尺（S0 vs S1）的數字絕不可混算。
4. **消融結論不可跨設計套用。** 一張歸因圖只屬於一個 pattern；規則的普適性以「樣本量＋適用域」逐條標註（§5）。

**與既有文件的分工**：碩論方法章的歸因總論在 [`docs/methodology.md`](../methodology.md) §5.2（承重分析／消融／雙向因果／公差掃描）；
本檔是它的**操作層展開**，只管「pattern 幾何消融」這一支。

## 1. 這是什麼

▍**一句話重點**：對一張**已經有量測值**的 pattern 施加**受控的幾何變體**，用**同一把尺**重測，
把 Δ 歸因到被動的結構元素上，最後收斂成可寫進生成器／製造規範的設計規則。

為什麼要這樣做，而不是直接搜尋更好的解：

- **方法級 A/B 在本問題上做不起來**：軌跡級雜訊 σ ≈ 1.5 dB，確認一項 1 dB 的改良需要每組 ~35 條
  500-sim 軌跡＝數個月機時（`methodology.md` §2）。相對地，**消融是配對比較**——同一張 pattern 的
  自我對照，雜訊地板從 σ 1.5 dB 掉到 ±0.3 dB，**訊噪比改善一個量級**。這是消融在本專案有效的根本原因。
- **625-bit 黑箱需要解剖工具**：pattern 是離散二元圖，沒有連續參數可微。要知道「哪裡承重、哪裡可動」，
  唯一負擔得起的辦法就是逐一拿掉／改動結構元素，看分數掉多少。
- **消融的產物有三種，都算數**：①設計規則（寫進選解／製造規範）②危險步偵測器（出招前擋掉高風險編輯）
  ③負結果（判死一條路，省下後續機時）。R55 的「事後對稱化判死」與 R56 的「c8 系收穫＝無」都是後者。

## 2. 三類消融算子

▍**一句話重點**：按**編輯尺度**分三類——接點級（亞像素）／塊級（結構單元）／全域變換（半場級）；
破壞力隨尺度陡升，所以掃描設計與判準也要按類分開。

三輪實測出的**容忍度階梯**（[round-55](../log/round-55-finetune.md) §4 定版）：

| 尺度 | 代表算子 | 典型 Δwm |
|---|---|---|
| 亞像素（<1 px） | 菱形橋 w_d 掃描 | −0.2 級（≲ 噪音） |
| 單像素 | 改組塊拓撲的 1 px 翻轉 | ±6 dB（懸崖） |
| 塊級（1–193 px） | 塊移除／平移／膨脹 | −0.06 ~ −20.6 |
| 半場（30–100 px） | Y 鏡像對稱化 | −10 ~ −30（全滅） |

### 2.1 接點級：對角接點的三態消融

**物理背景**：HFSS 的像素盒在對角處有 +0.01 mm 角落重疊＝**真導體微橋**，但實體蝕刻做不出 0.01 mm
→ 模擬-實物落差。三態＝**挖空（斷開）／現況 0.01 mm 點橋／顯式 45° 菱形橋（可製造尺寸）**。

**怎麼生成**：

```bash
# 探針版（一尺寸一夾，掃橋寬曲線）
python -m script.dedust select-diagbridge --round 54 \
    --ids-file tmp/diagbridge_ids.txt --sizes 50,75,100,140
```

- `diag_bridge_w` 編碼：**正值＝菱形橋（Unite）／負值＝挖空槽（Subtract，實體淨距 |w|）／None＝不變／0 拒絕**。
  三態共用同一個站點集 `diag_bridge_sites`（`antenna/patch/patch_simulator/single_port.py`）＝**尺完全同源、乾淨可比**。
- **關鍵：pattern 的 625 bits 沒有變**，幾何差異走輸入夾的 `hfss_setup.json`（白名單鍵）。
  這決定了它的查重與入鍋語義（§3）。
- 碰撞規則：同空格多菱形間隙 < 0.05 mm → 同步縮至淨距，縮不下就跳過並記進 manifest。
- 大規模版不需要 select 子命令：直接複製親本 `.pt` + 一個 `hfss_setup.json`，id 掛 `~db100`／`~sl100`。

**姊妹算子（改 bits 的版本，R52 `dedust_r52dx`，kind=diagfix）**：**斷角**（移除對角接觸）／
**補角**（填實對角空格讓 diagb 歸零）。這兩個是菱形橋的前傳，端點結論見 [round-52](../log/round-52-anchor-assault.md) §4。

### 2.2 塊級：以 8-連通真組塊為單元

**為什麼是 8-連通**：R54 挖空 13/13 全滅證實對角接觸是真電氣連接 → 正確的組塊定義含對角
（[analysis-11](../log/analysis-11-true-blocks.md)）。4-連通口徑只是電學檢視用，不是操作單元。

**算子集（R56 定版，7 個）**：`remove` / `shift`×4（N/S/W/E, 1 px）/ `dilate`（+1 圈）/ `erode`（−1 圈）。

**生成要點**：`scipy.ndimage.label(8-conn)` → per-block 套算子 → **feed (24,12) 永遠保留** → 批內去重
→ manifest 預算 `d_n8` / `d_ndiag` / `hamming` 三個結構標籤（歸因時當解釋變數，見 §4）。
R56 用一次性腳本 `scratchpad/gen_r56blk.py`（**尚未工具化**；照 `script/CLAUDE.md`「用過兩次才工具化」，
再用一次就該進 `dedust.py`）。

**歷史前例（都在 `script/dedust.py`，可直接重跑）**：`select-ablate`（元件消融：逐一移除非饋電組件＋累積組合）／
`select-occlude`（5×5 網格逐塊清空＝空間重要度圖）／`select-tolerance`（erode/dilate/隨機邊緣翻＝公差掃描）／
`select-blocks`（組數階梯）。R56 的塊級消融＝把 occlude 的「幾何網格」換成「真結構單元」。

### 2.3 全域變換：鏡像／對稱化

**三式**：`L`（左半鏡到右）／`R`（右半鏡到左）／`O`（左右聯集 OR）。
Y 鏡像對稱 ⇒ φ90 場型**物理保證對稱**，所以這一類同時是**儀器自證**工具
（量到的 |cen90| 若不趨近 0，表示建模或量測有破缺）。

**生成要點**：13 親 × 3 式 = 39，扣掉**本來就對稱的摺疊重複** 5 筆 → 34 筆
（[round-55](../log/round-55-finetune.md) §1④）。發車前跑**拓撲預計算**（每式的塊數變化／改動像素比）
當作押注依據——R55 事前就預測到 O 式會把 8–12 塊全熔成 1 塊。

### 2.4 變體空間紀律（四條）

1. **一維掃描優先，不開組合爆炸**。R54 = 橋寬一維（6 點）；R56 = 塊 × 算子二維但規模受控（9×7 = 54 筆）。
   **組合只在「單步已證溫和」的旋鈕帶裡開**（R56 探針二只取 4 個正向單步的 6 對＋4 三元＋1 四元 = 13 筆）。
2. **端點先行**。先量兩個極端（如 0.01 mm 現況 vs 全邊橋、完全斷開 vs 完整），確認有沒有轉折，
   再補中間點。R54 的六點曲線＝2 個既有端點 + 4 個新點，只燒 4 個尺寸的機時。
3. **命名＝親代綁定**。id 一律 `{parent_id}~{tag}`（`~db100`／`~sl100`／`~cmb3W9S`…），
   manifest 必帶 `parent_id` / `src_folder` / 算子參數 / `kind` / `family=XXX_r{NN}` / `gen_ver`。
   沒有 parent_id 就沒有配對比較，整批作廢。
4. **round 號貫穿命名**（夾／id／store 一路同號），不用跨 round 的全域批次計數。

## 3. 量測紀律（七條）

▍**一句話重點**：消融的價值全靠「除了那一個改動以外什麼都沒變」——這七條就是在守住這個前提。

| # | 紀律 | 為什麼 |
|---|---|---|
| 1 | **同一把尺** | 全部走 `worst_margin` + `rad_window_margin`（±45°/3 dB）+ `usable_lo`，config 同一份。換鍵＝換問題。 |
| 2 | **同求解設定的親本原值** | 親本值必須跟變體同尺。R54 為此另開 `s1base` 夾補 4 親的 S1 基線——**沒有同尺基線就不要算 Δ**。 |
| 3 | **配對雙生** | 同批、同機、同尺、同一次派工。跨批比較會混進機器與時間因素。 |
| 4 | **顯著性門檻 ±0.3 dB** | 幾何微變下的 S0 重網格抖動。單筆 \|Δ\| < 0.3 不判；主要訊號看 **\|Δ\| ≥ 1 dB** 級。要判小效果就 n ≥ 2 平均或升到族群統計。 |
| 5 | **查重豁免看「bits 有沒有變」** | `.pt` 與親本 bit 相同（幾何差異在 `hfss_setup.json`）→ 必撞查重 → 用 kind 豁免（`meshconv`/`diagbridge`）。**真的改了 bits 的變體（塊消融／對稱化）不豁免，`check-dup` 必跑**（R56 kind=`blockprobe`）。`check-dup` 單獨跑，**不接管線**（接管線 exit code 會被吃掉＝安全閘靜默失效）。 |
| 6 | **資料語義隔離** | **變體是否落在訓練資料的表示域內**＝入不入鍋的判準。菱形／挖空／網格變體＝同一張 625-bit 圖配不同求解幾何 → **永不入鍋**（不進 `clean_stores.txt`、重錨不 `--add`；漏一次就污染 SM 訓練集）。塊消融／對稱化＝真 625-bit 新 pattern → 正常入鍋域。 |
| 7 | **判準發車前寫死** | 判準（含「什麼算成立／什麼算判死」）在 §1 寫完才發車；發車後只能在**任何結果回來之前**修訂，且要留日期＋理由＋「發生在結果前」聲明。**押注制**同理：機制假說可在零結果窗口內補押，收檔時逐條結帳（R55／R56 各兩例）。 |

## 4. 歸因框架

▍**一句話重點**：Δ 表 → 轉移曲線 → 個體／母體拆帳 → 毀因假說用**反例法與對照組**驗證 → 找到能寫進規範的**解釋變數**。

### 4.1 第一層：單變體 Δ 表

把結果排成矩陣，一眼看非均勻性：

- **塊 × 算子**（R56：9 塊 × 7 算子）→ 效應譜 −0.06 ~ −20.6 dB。關鍵塊（主體 193 px：remove −9.04）
  與旋鈕塊（1 px 小塊：remove −0.14 ~ −0.69）直接分層。
- **親 × 尺寸**（R54：13 親 × 4 橋寬）→ 逐親曲線。

判讀第一問**永遠是「分佈均勻嗎」**：均勻＝這個算子沒有結構選擇性（如 R56 的 `dilate`，全域皆害）；
非均勻＝找到了功能單元。

### 4.2 第二層：轉移曲線（端點 + 中間點）

把一維掃描畫成曲線，判**懸崖 vs 平坦稅**。R54 橋寬中位曲線 50/75/100/140 = −0.16/−0.16/−0.25/−0.32
＝**平坦小稅、無懸崖**（曲線圖 `docs/log/assets/round-54/bridge_width_curve.png`）。

⚠ **陷阱**：逐親曲線在 ±0.3 抖動下**非單調**（振幅 ±0.3–0.5，看起來像物理響應其實是重網格抖動）。
所以曲線只在**母體／中位層**判讀，不對單一親本的曲線形狀下結論。

### 4.3 第三層：個體層 vs 母體層拆帳

這是 R54 最重要的方法論產出：

- **個體層**（13 親探針）：逐親嚴格判定「不可得」——效應量與噪音同級。
- **母體層**（3,319 親 × 固定 w=0.10）：中位 −0.07、|Δ| ≤ 0.3 帶內 86.5%、sd 0.27 ——**結論穩固**。
- 兩層**不是誰對誰錯**：探針 13 親偏悲觀（Δ@100 −0.25 vs 母體 −0.07）是**選樣偏誤**
  （探針刻意挑對角重明星 n_sites 12–30，母體中位 10），用同一個解釋變數就對得上＝自洽。

**操作結論：小探針只用來定端點與可行性，量化規則一律要母體級樣本。**

### 4.4 第四層：毀因假說的驗證法

歸因不能停在「動了 X 就掉 Y dB」，要問**為什麼**。兩個已驗證好用的手法：

- **反例法**：假說「斷開對角＝毀在拓撲斷路」→ 找反例：**89.3% 的親本切掉全部對角後直流連通完好，
  中位仍 −4.06 dB** → 假說推翻，改寫為「對角**承載電流**，拿掉低阻抗捷徑後電流被迫重繞」。
  這條把 r52dx 的「斷角全滅」從現象升級成機制。
- **對照組法**：假說「Δn8≠0（改組塊數）＝危險」→ 刻意構造 12 個 Δn8 = −1/−2 的**合併型**組合，
  結果全數溫和（最慘 −0.96）→ 危險軸是**中位性質、不是鐵律**，只能當偵測器不能當放大器。

### 4.5 第五層：找解釋變數

把逐筆 Δ 迴歸／分層到結構量上，找出**能寫進規範的**那一個。R54 掃了家族、n_sites、金屬量等，
結論是 **n_sites 是門檻型解釋變數**（<17：中位 −0.06／帶內 91.4%；≥17：−0.37／38.6%；5–16 之間完全平坦），
家族切法只解釋 40.8% 的變異且碎片化 → 規範寫 `n_sites < 17`，不寫家族。

**判準：能寫進規範的解釋變數要滿足①門檻或單調可讀②跨家族成立③可在生成時零成本算出。**

## 5. 三輪產出的設計規則（14 條）

▍**一句話重點**：每條規則後面都掛著它的樣本量與適用域——**沒有一條可以無條件外推**。

| # | 規則 | 樣本量／適用域 | 出處 |
|---|---|---|---|
| 1 | **選解留 wm ≥ 0.3 dB buffer**（原 wm ≥ 0.55 者菱形化後雙閘存活 97.8%；[0.15,0.3) 只有 48.3%） | 母體級，合格層 n=1,208（S0 單次） | [R54](../log/round-54-diamond-bridge.md) §4 |
| 2 | **控 n_sites < 17**（門檻型：<17 帶內 91.4% / ≥17 掉到 38.6%） | 母體級 n=3,318 | [R54](../log/round-54-diamond-bridge.md) §4 |
| 3 | **對外出圖／送製造一律菱形版 w = 0.10 mm** | 母體級（w=0.10 單點；0.075 未達母體級證據） | [R54](../log/round-54-diamond-bridge.md) §5、[decisions](../discuss/decisions.md)「對角＝顯式菱形橋規範」 |
| 4 | **左側票倉可整批菱形化**（Δrad 中位 +0.02、53% 反升；Δlo 中位 −0.02、~60% 改善） | 母體級 n=3,318 | [R54](../log/round-54-diamond-bridge.md) §4 |
| 5 | **不得斷開對角**（母體 Δwm 中位 −4.84、P10 −12.38；13 親探針 −6.96 ~ −21.73 全滅） | 母體級；⚠「零例外」只在 13 親（對角重明星）成立，母體有 20.5% wm > −1 | [R54](../log/round-54-diamond-bridge.md) §4 ★修正 |
| 6 | **毀因＝對角承載電流，非維持連通** | 母體級（89.3% 直流連通完好仍 −4.06） | [R54](../log/round-54-diamond-bridge.md) §5 |

## 6. 可複製流程（checklist）

▍**一句話重點**：十步，每步都有一個「不做就整批作廢」的閘門。

1. **選親本**。要求：①已有同尺量測值（沒有就先補基線）②結構有代表性（別只挑極端值，否則得到選樣偏誤）
   ③如果要推母體級規則，親本數要夠——13 親只能定端點。
2. **定算子與掃描維度**。按 §2 選類別；一維優先；端點先行；組合只在已證溫和的旋鈕帶開。
3. **判準寫死**（round 檔 §1）：什麼叫「成立」、什麼叫「判死」、顯著性門檻、樣本量、kind、prio、入不入鍋。
   有機制假說就在這裡押注。**這一步沒做完不准生成輸入夾。**
4. **開 round 檔**（`/new-round`）：`docs/log/round-NN-<slug>.md` + `configs/ONGOING.md` 加 🔵 一行。
5. **生成輸入**：`select-*` 子命令或一次性腳本；決定性 seed；manifest 帶 `parent_id`／算子參數／結構標籤；
   幾何變體批附 `hfss_setup.json`（白名單鍵）。
6. **`check-dup --input X_input` 單獨跑**（改 bits 的變體必跑，exit 1 就別發車；bits 不變的用 kind 豁免）。
7. **發車**：`jobs-add --input X_input --store X --prio N`。
   新 COM 動詞（Rotate／Subtract 級）**首筆當 smoke ＋幾何渲染目檢**；改了 worker 端 code 就三台
   `git pull` **＋重啟 worker**（只 pull 不重啟＝舊 code 陷阱，已兩犯）。
8. **收檔判讀**：照 §4 五層走（Δ 表 → 轉移曲線 → 個體/母體拆帳 → 毀因驗證 → 解釋變數）；
   數字貼進 round 檔 §4；押注逐條結帳；未公證的一律標「單次」。
9. **設計規則入帳**：規則寫進 [`docs/discuss/decisions.md`](../discuss/decisions.md)（附樣本量與適用域），
   紀錄級宣稱先走 `/notarize`。
10. **收輪**（`/close-round`）：§5 結論／§7 歸檔、`docs/log/README.md` 索引 +1、ONGOING 移出 🔵；
    本檔（§5 表格）同步 +1 行。

## 7. 已知矛盾與存疑（誠實條款）

收攏三輪檔案時發現的不一致，逐條列出，**不硬圓**：

1. **`script/CLAUDE.md` 鐵則 7 把 `symprobe` 列為 check-dup 豁免 kind，但 code 的豁免集合只有
   `("repeat", "notarize", "meshconv", "diagbridge")`**（`script/dedust.py` `check-dup`）。
   ——`symprobe` 實際上**不豁免**；R55 §1④ 也記載「check-dup 綠」＝確實有跑且通過。
   文件比 code 寬鬆＝危險方向（照文件會以為可跳過安全閘）。**以 code 為準**；文件待修。
2. **入鍋語義在 R55 沒有明說**。R54 明寫「資料永不入鍋」、R56 明寫「正常入鍋域」，R55 的 34 筆
   對稱化變體是真 625-bit pattern（性質同 R56）卻兩邊都沒寫。另外 `configs/clean_stores.txt`
   截至 v108（`dedust_r53b3a`）**尚未含 `dedust_r55sym` / `dedust_r56blk`**——
   戰役期間探索暫停、沒有重錨，所以「正常入鍋」目前是**宣告未落地**。恢復重錨時要明確決定收不收。
3. **R54「挖空全滅，零例外」與閉帳母體統計字面衝突**。round 檔已用 ★修正原地補註
   （母體 20.5% wm > −1、8.9% wm ≥ 0）＝ append-only 紀律的正確用法，但**引用時很容易只讀到前半**。
   正確講法：「對角重 ⇒ 毀滅級；對角輕 ⇒ 重擊但未必致命」。
4. **R54 判準②的雙點公差條款從未在母體驗證**。原判準要求「0.075 與 0.10 兩點同時保帶」，
   母體只跑了 0.10 單點；雙點證據只有 13 親探針，而該尺度已被判「逐親精判不可得」。
   → 規則 3 的正確表述是「**0.10 單點母體成立**」，雙點是遺留條款。
5. **危險軸 Δn8≠0 的倍率數字不穩**：回溯 2.75×（判準 3× **未過**）vs 前瞻 6.8×（過），
   且前瞻樣本極不均（47 vs 7，round 檔自己標明「只做方向判定」）。
   → **「Δn8≠0 是危險步」這個方向可信；6.8× 這個量化倍率不該被引用為規則。**
6. **R55 有一個押注沒有結帳**：§1 押注補記押了「對稱化把 c8trip 拉出深 lo 島 → lo 從 −2.63
   回淺至島 B 水位（≳ +3.5）；若 lo 反而保住＝左側-置中同軸結論被否證」。
   §4／§5 只報了 wm 代價與 cen90，**沒有回報這個 lo 的驗證結果**。
   資料應該還在 `dedust_r55sym`，可離線補判——這是三輪裡唯一一條懸空的機制假說。
7. **R54 檔內同一組數字前後不一致（小）**：db100 的 13 親中位在 §4「三點曲線」節記 −0.21、
   在「四點曲線收齊」節記 −0.25（閉帳統計採 −0.25）。兩者都在 ±0.3 抖動帶內、不影響結論，
   但引用時應採 −0.25（與閉帳分析一致）。
8. **規則 10–12 全部只有一個親本**（c8trip03_01）。R56 判準①原本要求「方法論成立就擴到 c8 系其他成員
   ＋第二親本」，因為收穫線未過而沒有執行 → **塊級歸因圖的跨設計普適性完全未驗**。
