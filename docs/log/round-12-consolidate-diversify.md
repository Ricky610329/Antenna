## 1. 假設 (Propose)
- 背景（R11 產出）：去重後 50 個互異三標過 pattern,但 **Hamming>60 聚類=1 家族**（全 w17 高原）、
  中位 wm 僅 +0.07、只 8 個公證過。→ 瓶頸已從「找到任何三標解」轉為「收斂＋破單一化」。
- 假設 A（收斂）：top 候選間的差異不在 margin（已逼近雜訊）而在**局部缺陷存活率**（tol:c21 10/18 vs 薄冠軍 1-2/18）;
  公證＋缺陷掃描能選出唯一該送製造的穩健冠軍。
- 假設 B（破單一化）：pool 非 w17 家族（F0 wm+0.38/34 員、F1/F4/F6,對 w17 Hamming>230）R9 每族只試 leader
  一個就放棄;用「除塵＋對稱化{10,12}＋鄰域擾動＋SM 篩」深掘,測第二座山頭存不存在。

## 4. 分析 (Analyze)

### crown（48/48）——8 候選全公證✓（零假象）
- **c25 新王轉正**：wm +0.22（S11 +1.19 全場最寬、Gain +0.22）、rad +0.34、5 組件零粉塵——公證兩次一致。
- **穩健性（局部缺陷 k1 存活）**：n=4 偏薄、候選間多在抽樣雜訊內;唯一硬訊號=c28 有致命點（缺陷後 −5.00）。
  跨批合計最有數據者：**c21 = 11/22 = 50%（穩健王）** vs a15 系 = 2/18 = 11%。c25 是 a15 血統+加塊,
  crown 僅 2/4=薄,穩健性未定 → 需 bake-off（top 3 × 多缺陷樣本）才能加冕製造冠軍。
- pc18_full（c18 全對稱）wm +0.09/rad +0.53=rad 保單,一併 certified。

### family2（42/45）——第二山頭**不存在**
- 非 w17 家族 F0（pool +0.38/34員）/F1/F4/F6 深掘（除塵+對稱化{10,12}+鄰域擾動+SM 篩）**全數 0 三標過**。
- 最接近=F6 clean wm −1.45（S11 −0.96/Gain −1.45）、rad −2.18——距 spec 遠。
- **裁決：w17/F2 家族特殊性確立**——探索過的最大非 w17 pool 家族都到不了 spec,可製造三標解只住 w17 這片高原。
  ＝分布≫策略的最強版本（不是找到好策略,是只有一個區域有解）。

## 5. 結論 (Conclude)
- **收斂**：**製造冠軍＝x00**（bake-off 缺陷 k1×18 定案:存活 72% vs c25 56% vs c21 28%,公證✓ wm +0.19/rad +0.19）。
  關鍵教訓:x00=c21 翻 2px,穩健性卻 28%→72%——2px 避開脆弱邊緣像素即大幅改變公差容忍;**margin 相近時穩健性才是製造判準**。
  c25 仍是 margin/rad 展示王(+0.22/+0.34),但穩健性輸 x00。
- **破單一化**：**否決**——第二山頭在 pool 內不存在,停止找第二家族,承認 w17 特殊性（碩論素材:分布≫策略最強版）。
- **教訓/含義**：組數階梯（Ricky）是 R11 最大結構突破——c25 用「加塊」離開 3 塊構型還奪冠,是唯一「換了結構仍過三標」
  的方向 → R13 候選=組數階梯系統對比（3/4/5/6 塊 × 穩健性）,比找新家族務實。
