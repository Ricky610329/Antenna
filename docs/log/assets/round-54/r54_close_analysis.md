## 0. 結論摘要(七條)

1. **戰役 100% 收檔、零缺筆**:6,638 input / 6,635 成功 / 3 error(全為機器型瞬態:1 筆 COM
   例外 + 2 筆 HFSS 行程死亡)/ 0 缺筆。四層 70 夾全數對得上。

2. **判準③「全尺寸毀」= 明確否定**。菱形(w_d=0.10)母體 Δwm 中位 **−0.07dB**、
   |Δwm|≤0.3 帶內 **86.5%**(合格層 89.6%)、Δ<−1dB 只有 51 筆(1.5%)。
   **0.01mm 微橋不是特有效應**——可設計的 45° 菱形橋在母體尺度上是「近乎免稅」的替代品。

3. **判準②「可製造對角成立」= 母體層成立(0.10 單點)**:合格層 1,208 筆中
   **①|Δwm|≤0.3 ∧ ②rad_margin≥0 ∧ ③Δlo≤+0.3 三閘全保 = 956 筆 = 79.1%**。
   逐條:①89.6% / ②88.7% / ③98.6%。**⚠ 但判準②原文要求「0.075 與 0.10 兩點同時保帶」,
   母體只跑了 0.10 一個點;雙點證據仍只有 13 親探針(S0 6/13、S1 3/7),
   且該尺度已被判定「逐親精判不可得」。→ 誠實表述是「0.10 單點母體成立、雙點公差條款未達母體級證據」。**

4. **稅的唯一強解釋變數 = 橋座數 n_sites**:`n_sites < 17` 的 3,012 筆 → Δ 中位 −0.06、
   帶內率 **91.4%**;`n_sites ≥ 17` 的 306 筆 → Δ 中位 −0.37、帶內率 **38.6%**。
   家族(id 前綴)只解釋 40.8% 的變異且家族切法碎片化;**「橋座少 ⇒ 免稅」是可直接寫進設計規範的規則**。

5. **rad 幾乎不動、lo 略改善**(13 親觀察在母體層完全成立):
   Δrad 中位 **+0.02**、|Δrad|≤0.3 佔 86.6%、53.3% 反升;
   Δlo 中位 **−0.02~−0.03**(越低越好)、|Δlo|≤0.3 佔 99%+、約 60% 改善。
   **菱形橋不吃帶外票倉,左側戰果可以整批帶著走。**

6. **挖空(斷開)= 毀滅級,但「毀滅機制」要改寫**:母體 Δwm 中位 **−4.84dB**、P10 −12.38。
   然而 **89.3% 的親本切掉全部對角接點後饋線元件一格都沒少**(直流完全不斷路)
   —— 毀滅不是拓撲斷路,是**角接觸這條低阻抗捷徑被拿掉後的電流重繞**。
   r52dx「斷角全滅」的解釋應由「維持連通」改為「**承載電流**」。
   零對角依賴族群(挖空 |Δwm|≤0.3)有 355 筆(10.7%),但挖空同時吃 rad(Δrad 中位 −0.81),
   **挖空後雙閘仍合格者只有 3 筆(0.09%)**——存在但不是可依賴的產線來源。
   **★ 同時要修正 round-54 §4「挖空全滅,零例外」**:那是 13 親(全為對角重明星)的結論;
   母體有 681 筆(20.5%)wm>−1、294 筆(8.9%)wm≥0。正確講法=
   「對角重 ⇒ 毀滅級;對角輕 ⇒ 重擊但未必致命」。

7. **交付面:菱形後仍合格(wm≥0.15 ∧ rad≥0)= 943 筆**(合格層存活 599 + 近合格層升格 344),
   佔母體 28.4%;最好的一批 wm 達 +0.69。這就是**可交給日月光的可製造合格集**
   ——全部只含 0.10mm 級可蝕刻特徵,沒有一顆 0.01mm 微橋。

### 附帶的兩個操作結論

- **合格線穿越 42.4% 主要是「離線太近」不是「菱形毀滅」**:原 wm∈[0.15,0.3) 存活率 48.3%、

## 8. 方法與限制(誠實欄)

**方法**
- 母體值取自各 store `results.json`;`wm` 取 `wm[2]`(=worst_margin,同一把尺)、
  `rad` = `rad_margin`、`lo` = `oob_gain_max_lo`。
- 親本原值:`wm_orig`/`rad_orig` 直接讀各 `_input/manifest.json`(select 端寫入,與 `val_final.json` 同源);
  `lo_orig` 由 `res_index.json`(全史 S0 帳)補。3,319 親全數對得上,零缺親。
- `n_sites` = manifest 記錄的真對角接點數(填空/挖空同一站點集,`diag_bridge_sites`)。
- 拓撲欄:自 25×25 bit 圖重算。挖空=切掉全部真對角接點 ⇒ 連通性由 8-連通退化為 4-連通;
  「饋線元件質量」自矩陣第一索引 `i=24` 那排(= HFSS X=5mm 饋線邊)出發做 flood fill。

**限制**
1. **母體只有 w_d=0.10 一個點**。判準②的「0.075∧0.10 雙點保帶(±0.02 蝕刻公差)」條款
   在母體層**沒有證據**;13 親探針的雙點通過率 S0 6/13、S1 3/7,而該尺度的逐親判定
   已因 S0 重網格抖動被降級。**要把「公差內無懸崖」講死,需要母體級的 0.075 批(未跑)。**
2. **全部母體數字是 S0 網格**。S0→S1 有系統性掉幅(s1base:王 +0.79→−0.25)。
   本檔所有絕對 wm 是 S0 尺,**不是可直接對外宣稱的最終電性**;跨尺比較只能看差分。
3. **±0.3dB 抖動地板**。母體 Δwm 的 sd=0.27、|Δ|≤0.1 佔 48.9%——
   菱形稅的中位值(−0.07)與量測地板同量級。正確講法是「**稅 ≲ 網格噪音**」,
   不是「稅精確等於 −0.07dB」。左尾(Δ<−1,51 筆)才是真訊號。
4. **交付集未公證**。943 筆全部是單次 S0;紀錄級/對外宣稱要走公證鐵則(重測 ×2)。
   本檔的 Top20 是**候選清單**,不是紀錄。
5. **家族切法**:id 前綴切法碎片化(799 個家族、只有 2 個 n≥30),
   來源夾切法也只有 2 個 n≥40 —— 家族相關性的結論**證據力弱**,不要當定論引用;
   n_sites 的相關性才是站得住的那條。
6. 3 筆 error 未重測;佔比 0.045%,對任何母體統計量都無影響。
