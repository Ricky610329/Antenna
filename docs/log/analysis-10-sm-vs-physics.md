## 4. 結論

### 4.1 主結論：**物理的價值只在資料沒有覆蓋的域**

| 域 | 誰贏 | 差距 |
|---|---|---|
| 正片（SM 的主場，即使 out-of-sample） | **SM 壓倒性** | +0.61（P=100%） |
| 負片（SM 從未訓練） | **物理（L3）** | +0.36（P=100%） |
| 負片（two 吃過負片之後） | **SM-two** | +0.92 vs L3 的 +0.43 |

⇒ analysis-08 §1 的「物理天生無 OOD 所以會全面勝過資料驅動」**確實不成立**，
但反過來的「資料驅動全面勝過物理」**也不成立**。精確版本是：

> **一旦資料覆蓋了那個域，物理就沒有優勢**（two 吃負片後 +0.92 ≫ L3 的 +0.43）；
> **在資料還沒覆蓋的域，物理是有用的先驗**（mlp/cnn 在負片只有 +0.07，L3 有 +0.43）。

### 4.2 對「要不要接進管線」的回答：**不接進主管線，但保留為冷啟動工具**

- ❌ **不該接進主管線**：正片域是所有變現活動的所在，那裡 SM 領先 0.6，物理接進去只會拖慢。
- ✅ **有一個明確的用途——新域的冷啟動排序器**：
  R50 已經量到「負片冷啟動 4 點非單調」。在一個全新域上，SM 需要資料才會準
  （mlp/cnn 在負片 ρ ≈ 0.07 ＝**幾乎無排序能力**），而 L3 零訓練就有 +0.43。
  ⇒ 開新域的**第一批**可以用 L3 排序候選，不必靠隨機。
  這條可直接接上 `configs/ONGOING.md` 的 R50 雙外軸產線。
- ⚠ 成本要誠實：L3 是 **~690 ms/筆**（本次實測 2617 筆 1799 秒），SM 是 **~1 ms/筆**。
  只有在「SM 對該域完全無知」時這個代價才划算。

### 4.3 方法論產出（可能比結果更值錢）

**`_load_clean_stores()` 會自動納入 `dedust_auto*` 與 `dedust_c*`** ⇒ SM 的訓練集是 587 店
而非 `clean_stores.txt` 的 513 行，**clean 層 97% 是 SM 見過的**。
任何「SM vs 其他方法」的比較若沒扣掉這一層，都會系統性高估 SM。
本檔的 clean_OOS（817 筆）是目前唯一乾淨的正片比較場。

### 4.4 未做／限制

- **`val` 未用**：本檔全在 `fit` 上量。若要當正式對外數字，該在 `val` 複核一次
  ——但 val 的 clean_OOS 只有 **2 筆**（見 §1.1 表），**沒有判別力**。
  ⇒ 真要做，得先擴大 val 或改分割規則。
- **只比 rank，沒比誤差**：SM 的主 KPI（五軸①）是 held-out 誤差 + 前瞻 ρ；本檔只做 ρ。
- **L1 的參數在 dev 選過**，clean_OOS/neg_OOS 對它是 out-of-sample，但 dev 與 fit
  同源，不算完全獨立。
- **η 的能量缺口仍未解**（analysis-09 §5.6）。饋電稽核順帶發現「現況模型 Re(Zin) 90 百分位
  只有 17 Ω，而 min-S11 = −12.4 dB 反推的純電阻解是 30.7 或 81.6 Ω」——
  兩個獨立方法都指向**低估阻抗量級**，可能與 η 缺口同源，未追。

## 5. ★★ 收檔後修正（2026-08-03 05:1x，收檔 20 分鐘後）：**§4.2 的建議證據不足，撤回**

append-only：原文不改，在此原地說明。

### 5.1 為什麼回頭查

§4.2 寫「開新域的第一批可以用 L3 排序候選」，依據是 neg_OOS 的 ρ = +0.433。
但**選批不是全域排序問題，是 top-K 問題**——批次線一批只有 30–60 席，
只關心「選中的那幾筆有多好」，不關心全域順序對不對。
ρ 高不必然代表 top 端好（analysis-08 已引過 Lambert L4DC 2020 的 objective mismatch，
我卻在自己的建議裡又犯了一次）。

### 5.3 結論修正

1. ❌ **§4.2「用 L3 當新域冷啟動排序器」撤回** —— 沒有任何方法在 top-K 選批上顯著勝出，
   且 L3 在 K=30 只有 **30% 機率勝過隨機**（K=60 才 69%），**不穩定**。
   全域 ρ = +0.433 **沒有兌現成選批效益**。
2. ⭐ **但有一個站得住的實用警告**：**`SM-mlp` 在完全未見過的域選批比隨機還差**
   （P(勝隨機) = 21–26%，兩個 K 都是）。⇒ **開新域時不要用主 SM 挑候選**，
   那比隨機挑更糟。這條對批次線直接有用（R50 雙外軸產線正在做的就是開新域）。
3. ⭐ 值得注意：**全域 ρ 僅 +0.078 的 SM-cnn（影子）在 K=30 的選批表現最好（71%）**，
   而 ρ = +0.433 的 L3 最差（30%）—— **rank ρ 與 top-K 效益不但不等價，這裡甚至反向**。

### 5.4 這件事的一般教訓（已升 `docs/discuss/decisions.md`）

**驗收指標必須是「使用方式」的指標，不是「看起來合理」的指標。**
本輪 diffsim 全程用層內 ρ 當 gate（analysis-08/09/10），
但這條線最終若要有用，用途是**選批**——而 §5.2 顯示兩者可以反向。
⇒ 早該在 analysis-08 訂 gate 時就用 top-K 效益，而不是等到收檔後才發現。

⚠ dev 上量到 **+0.239**、fit 的 clean_OOS 只有 **+0.040** —— 同一個修正、同一個指標，
差 6 倍。**改善幅度強烈依賴樣本子集**，單一數字沒有代表性。
（dev 的 clean 97% 是 SM 見過的那類，分布接近 `clean_INSAMPLE`；後者量到 +0.140，居中。）

### 7.2 ★★★ 但 top-K 幾乎完全沒動

| P(勝過隨機批)，K=60 | Stage 1 前 | Stage 1 後 |
|---|---|---|
| **clean_OOS，L3** | 18% | **17%** |
| clean_INSAMPLE，L3 | 10% | 39% |
| neg_OOS，L3 | 69% | **70%** |

top10% 命中率（clean_OOS, K=60）：**8% → 8%**（隨機是 10%）。

⇒ **修了一個真正的物理 bug（饋電模型錯得離譜：0.2mm 死端代表 22.5mm 傳輸線），
gate 指標改善 +124%（dev：+0.194→+0.434），而實用指標紋風不動。**

### 7.3 這是 §6.4 論點的直接證據

§6.4 說「錯的是『ρ 高 ⇒ 有用』這個沒說出口的前提」——那是從**橫向比較**推的
（不同模型之間 ρ 與 top-K 排序不一致）。
§7.2 是**縱向**的、更強的證據：**同一個模型、修同一個 bug、ρ 大幅上升、top-K 不動。**

⇒ 兩者不只是「不等價」，而是**在這個問題上幾乎正交**。
全域 ρ 量的是「整體順序」，而選批只取決於**分布頂端那幾十筆的相對位置**——
一個把中後段排得更對的修正，對前者貢獻很大，對後者毫無貢獻。

### 7.4 結論（§4/§6 的最終版本）

| | 正片域 | 負片域 |
|---|---|---|
| **層內 ρ** | SM +0.84 ≫ L3 +0.295 ≫ L1 +0.188 | **L3 +0.430** ≫ SM-mlp/cnn +0.07 |
| **top-K（P 勝隨機）** | SM 80–88% ≫ L1 39% > L3 17% | L3 70% ≈ SM-cnn 59% > 隨機 > SM-mlp 21% |

- **正片域（主戰場）：diffsim 兩個模型都比隨機差，Stage 1 也沒救**。結論不變。
- **負片域**：L3 有 70%，是唯一勝過隨機的物理模型，但 §5.2 的兩兩配對 CI 仍跨 0
  ⇒ **不足以宣稱它比影子 CNN 好**。
- ⭐ **「主 SM 在未見過的域選批比隨機差（21%）」這條完全不受影響**，仍是本輪最實用的產出。

## 10. 殘差 head 的 A/B/C（2026-08-03 06:4x）：**物理當特徵也沒有價值** —— 原鏈的最後一步完成

`docs/diffsim.md` 原鏈的最後一步是「殘差 head + 最終 SM 比較」。
§6 已證明**裸物理**在選批上沒價值，但那沒回答「物理當**特徵**呢」。

### 10.1 正確的測法是學習曲線，不是單點

若物理是有用的先驗，它應該讓學習曲線**左移**（用更少資料達到同樣效果），
而不只是在某個資料量上高一點。三臂同容量（625→256→128→1）、同 120 epoch、同 3 seed 取中位：

| 臂 | 輸入 |
|---|---|
| **A** | pattern (625) ＝ 純資料基線 |
| **B** | pattern (625) ＋ L3 響應 (34) ＝ 物理輔助 |
| **C** | L3 響應 (34) only ＝ 物理特徵本身的資訊量 |

訓練池＝`fit` clean **in-sample** 區（3000 筆），評估＝`clean_OOS` 817 筆，**兩者零重疊**。

### 10.2 結果（top10% 命中率，K=60）

| n_train | **A 純資料** | **B 資料+物理** | C 只有物理 |
|---|---|---|---|
| 250 | **25%** | 17% | 22% |
| 500 | 23% | 22% | 18% |
| 1000 | **30%** | 23% | 23% |
| 2000 | 35% | **37%** | 25% |
| 3000 | 33% | **35%** | 22% |

| 對照 | 命中率 | P(勝隨機) | ρ |
|---|---|---|---|
| **SM-mlp v100**（幾萬筆訓練） | **52%** | 87% | +0.843 |
| L3 裸物理（`worst_margin` 直讀） | 8% | 15% | +0.295 |
| 隨機 | 10% | 50% | — |

### 10.3 三個結論

1. ❌ **物理特徵沒有讓學習曲線左移。** B 相對 A 沒有一致優勢——
   **小樣本時反而更差**（n=250：25% → 17%；n=1000：30% → 23%），
   大樣本時的 +2% 落在 seed 雜訊內。⇒ **「物理當先驗」在這個問題上不成立。**
2. ⭐ **但 L3 的響應不是沒有資訊**：同一個 L3 輸出，
   用 `worst_margin` 直讀只有 **8%**，用學習節重讀有 **22%**（**×2.75**）。
   ⇒ L3 的問題不是「什麼都沒算對」，而是**它算出的響應到真值的映射不是恆等**——
   這與 §7 的能量缺口（表面波高估 2–3 倍，analysis-09 §7.2）方向一致：
   系統性偏差可以被學習節部分吸收，但**吸收完仍輸給直接看 pattern（33%）**。
3. ⇒ **物理特徵的資訊量 < 原始 pattern 的資訊量**。
   diffsim 作為**特徵提取器**同樣沒有價值 —— 這是原鏈最後一個未答的問題，答案是否定的。

### 10.4 限制（誠實）

- 固定 120 epoch、無 early stopping、單一 MLP 容量、單一 K（=60）。
  **絕對值不可當基準**；但 A/B/C 是同設定下的**相對**比較，這部分是公平的。
- n_train 上限 3000（成本：L3 要 690 ms/筆，3000 筆＝22 分鐘）。
  SM v100 用的是幾萬筆 ⇒ **52% vs 33% 不是公平比較**，只說明「現役 SM 的水準在那裡」。
- 只在 `clean_OOS` 評估。負片域沒做（L3 在那裡的裸物理 ρ 較高，結論可能不同）。

### 10.5 ⇒ `docs/diffsim.md` 的鏈到此全部走完

| 階段 0 幾何 | ✅ `.sab` 二進位直解，零 HFSS 清掉「待確認」 |

## 11. ★ 追 §10.2 的線索到底：**L3 的病是「共振頻率完全抓不到」，不是可校正的系統偏差**

§10.2 觀察到「同一個 L3 輸出，直讀 8%、學習節重讀 22%（×2.75）」，
我當時解讀成「**響應到真值的映射不是恆等**，系統性偏差被學習節吸收」。
**那個解讀不完整**——如果只是系統偏差，簡單校正就該有效。實測（`scratchpad/l3_bias.py`，n=3000）：

### 11.1 偏差的結構

| | 預測中位 | 真值中位 | 逐點 ρ |
|---|---|---|---|
| S11 | −0.59 dB | −4.60 dB | +0.300 |
| Gain | −1.37 dB | +1.43 dB | +0.321 |

| S11 的谷 | |
|---|---|
| **谷深** | 預測 **−5.47 dB** vs 真值 **−15.04 dB**（ρ +0.338） |
| **谷位置** | **\|Δ格\| 中位 5.0（共 17 格）**、**同格比例 6%**（≈ 隨機）、**ρ +0.078** |

⇒ ★ **共振頻率幾乎完全抓不到**（ρ = +0.078）。而**共振位置就是 S11 的核心資訊**。

逐頻點偏差不是常數（+1.43 … +7.56 dB），且**與真值深度相關**（真值越深、偏差越大）
——那不是可加性偏差，是「谷根本沒對齊」的必然後果。

### 11.2 簡單校正全都無效（在同一批上擬合＝上界，仍無效）

| 校正 | 命中率 | ρ |
|---|---|---|
| 原樣 | 8% | +0.295 |
| ＋每通道常數（−3.70／+2.04 dB） | 8% | +0.268 |
| ＋每通道線性（a=0.13／0.20） | 10% | +0.213 |
| ＋逐頻點線性（34 組係數） | **2%** | +0.296 |
| （對照：學習節 MLP 22%／純資料 pattern 33%／SM v100 52%／隨機 10%） | | |

**逐頻點線性反而掉到 2%** —— 34 組係數在 3000 筆上就過擬合了，而且它「修」的是錯的東西。

### 11.3 ⇒ 修正 §10.3 第 2 點的解讀

- ❌ 原解讀：「響應到真值的映射不是恆等，系統偏差可被學習節吸收」
- ✅ 正確：**頻率軸錯位**。學習節能到 22% **不是**因為校正了偏差，
  而是它從 34 維響應裡撈到了**別的**訊號（整體形狀／量級），繞開了沒用的頻率資訊。
  這也解釋了為什麼它仍輸給直接看 pattern（33%）——pattern 裡有完整資訊，L3 的響應反而是有損壓縮。

## 17. ★★ 最終修正：**差距是 ~3.3 倍不是 14 倍** —— 我的對照式漏了互導納 G₁₂

### 17.1 兩件事一起解釋了 §16.3 的「可疑現象」

**(a) 「Zin 幾乎不隨驅動寬度變」其實是對的物理。**
那 25 個「驅動屋頂」不是 25 個獨立的埠——它們是**同一個 gap（x=5.0 mm 接面）的 25 個切片**。
在同一個 gap 上加 V=1，切成幾片電壓都還是 1 V ⇒ **Zin 本來就該相同**。
電流分佈實測也吻合：總 |I| 幾乎不變（4.98e−3 → 5.42e−3，+9%），每格 |I| 隨 N 下降。
⇒ **§16.3 標的「可疑入口」撤回，那不是 bug。**

**(b) 我的閉式對照漏了互導納。** Balanis 的完整式是 `R_in = 1/(2(G₁ ± G₁₂))`，
我一路只用 `1/(2G₁)`。`G₁₂ = (1/120π²)∫[sin(k₀W cosθ/2)/cosθ]² J₀(k₀L sinθ) sin³θ dθ`
在這個尺寸上與 `G₁` **同量級**（5.80e−4 vs 3.57e−4）：

## 19. ★★★ 根因確認：**rooftop 基底表達不出邊緣奇異性**，收斂率 `1/√N`

### 19.1 先修正 §18 的一個方法錯誤

§18 用 `argmax(Re)` 當共振點，但那裡實測 `Im(Zin) = +76.5 Ω` **不是 0** ⇒ **比錯了點**。
Balanis 的 `R_in` 是**共振時**（Zin 純實）的值。用細頻率格點（0.2 GHz）找真正的 `Im` 過零重量：

| 格數 | 7 | 9 | 11 | 13 | 15 | 17 | 19 | 21 | 23 |
|---|---|---|---|---|---|---|---|---|---|
| **比值** | 0.192 | 0.241 | 0.281 | 0.318 | 0.352 | 0.372 | 0.391 | 0.398 | **0.406** |

⇒ ★ **完美單調、而且沒有飽和**（§18 的「15 格飽和在 0.33」是用錯的共振點量出來的假象）。

### 19.2 收斂形式：**`1/√N`**

| 擬合 `比值 = 1 − C/N^p` | C | RMS | 到 0.9 需要 |
|---|---|---|---|
| **p = 0.5** | **2.508** | **0.0639** | **N = 629 格（dx = 0.005 mm）** |
| p = 1.0 | 9.714 | 0.2431 | N = 97 |
| p = 2.0 | 145.7 | 0.8349 | N = 38 |

**`1/√N` 是「基底表達不出奇異性」的指紋。** 導體邊緣的表面電流有 edge condition
`J ∝ 1/√d`，而 **rooftop 是線性基底**。實測橫向剖面也吻合：模型的「邊緣/中央」峰值比是
**2.40**，解析 `1/√(d(1−d))` 要求 **2.96**，而中央的相對吻合度（0.417）**高於**邊緣（0.255–0.338）
⇒ **邊緣被系統性低估**。

⇒ ★ **這是模型類別的限制，不是 bug。** 25×25 格對這個問題根本不夠，
而加密到夠（629 格 ≈ 79 萬未知數）完全不可行。

### 19.3 ❌ 方案 A（解析加權基底）失敗 —— 我的數學錯誤

想用 Galerkin 加權基底 `f_j = w_j·rooftop_j`（最外層 `w = √2`，由「格內平均/格心取樣」算出）：
`Z' = WZW`、`V' = WV`。**實測改善 +0.0%，因為那是恆等變換**：

```
I' = (WZW)⁻¹(WV) = W⁻¹Z⁻¹W⁻¹·WV = W⁻¹I    →    J = W·I' = I
```

**換基底的「振幅」不改變函數空間**，只是換了展開係數的定義。
要真的表達 `1/√d`，必須改**格內的形狀函數** ⇒ Z 的積分核要重算，不是加權能解決的。
⚠ 這個錯誤我應該在動手前就用兩行代數看出來。

### 19.4 ✅ 但「有物理意義的 grid search」給出了驗證（Ricky 的提議）

從 `1/√N` 擬合**獨立預測**：典型貼片 N≈17 ⇒ `1 − 2.508/√17 = 0.392` ⇒ **校正因子 k ≈ 2.55**。
掃 `Re(Zin) × k`（`clean_OOS` n=400）：

| k | 層內 ρ(wm) | **命中率** | min-S11 中位 |
|---|---|---|---|
| 1.00（現況） | +0.366 | 12% | −10.31 dB |
| 1.50 | **+0.389** | 13% | −13.13 |
| **2.00** | +0.263 | **20%** | −15.01 |
| 2.50 | +0.077 | 15% | −15.89 |
| **2.55（物理預測）** | +0.066 | 13% | **−15.88** |
| 3.00 | −0.042 | 13% | −17.33 |

**真值 min-S11 中位 = −16.38 dB。**

⇒ ★ **物理預測 k=2.55 與「讓絕對量級對上真值」的 k（2.5–3.0）吻合** ——
兩條互不相干的路對上，**驗證了 `1/√N` 的解釋**。
（與 `b_reg` 的實測最佳 0.30 對上真積分 0.3363 是同一個模式。）

### 19.5 ⚠ 但修對絕對量級之後，**rank 反而崩了**——這本身是重要發現

`ρ` 從 +0.366（k=1）掉到 +0.066（k=2.55）。原因是物理的：
`Re(Zin)` 中位 **21 Ω**，×2.5 就是 52.5 Ω **≈ Z₀ = 50 Ω**。
**在匹配點附近 `|Γ|` 對 `Re` 的微小誤差極度敏感** ⇒ 殘餘誤差被放大。
現況之所以 rank 還可以，是因為 `|Γ|≈1` 的平台區把誤差**壓平**了。

⇒ **「量級對」與「排序對」在這個問題上是衝突的**，而衝突的來源是
**比值不是常數**（四個尺寸 0.24–0.41）——乘一個全域 k 只能修中位、修不了分散。

### 19.6 ⭐ 但 k=2 有真實改善：**命中率 12% → 20%**（隨機 10%）

**這是 diffsim 在正片域第一次真正勝過隨機。** 雖然仍遠低於 SM 的 52%，但方向是對的，
而且**它指出了 ML 的正確用武之地**：需要的是 **pattern-specific 的 k**，不是全域常數。

| | §10 失敗的做法 | 這條 |
|---|---|---|
| 學什麼 | L3 的 34 維輸出 → wm | **一個純量 k** |
| 物理先驗 | 無 | `k ≈ 1/(1 − C/√N_eff)`，`N_eff` 與**邊緣幾何**相關 |
| 容量需求 | 高 | 低（低維、形式明確） |
| 可驗證 | 難 | **k 的分布該落在 2–3，且與邊緣密度相關** |

## 20. ❌ pattern-specific 的 `k` 學不起來 —— 目標本身就定義不清

§19.6 提議學一個 pattern-specific 的校正因子 `k`。先看**目標值的分布**（訓練池 1500 筆，
L3 核 ＋ `half_port`）：

| 目標 k 的定義 | 中位 | IQR | p5–p95 | 撞上界(k=6) |
|---|---|---|---|---|
| 讓整條 S11 曲線 MSE 最小 | **1.50** | 1.05–2.55 | **1.00–6.00** | 9% |
| 讓 `worst_margin` 對齊 | 1.45 | 1.00–2.40 | — | 6% |
| **兩者的 Spearman** | **+0.152** | | | |

**三個獨立的壞消息**：

1. **兩種目標定義幾乎不相關（+0.152）** —— 這是致命的：
   優化「曲線對得上」**不會**改善「wm 對得上」，而 **wm 才是用途**。
2. **分散極大**（p5–p95 涵蓋 1.0–6.0 的整個掃描範圍）⇒ 沒有一個穩定的目標可學。
3. **中位 1.50 ≠ 物理預測的 2.55**，也 ≠ §19.4 讓 min-S11 對上真值的 2.5–3.0。
   原因：曲線 MSE 是對**整條 17 點曲線**，而模型的**谷**比整體更淺
   ⇒ 「讓整條曲線最貼」與「讓谷對上」要的 k 不同。

⇒ **單參數校正這條路不成立。** 不是「學不好」，是**目標本身沒有良好定義**。

### 20.1 這也回答了「哪裡該用 ML」

§19.6 我以為找到了 ML 的乾淨用武之地（低維、有物理先驗）。**錯了**——
低維且有物理先驗**不足以**讓一個學習任務成立，還需要**目標值本身是良好定義的**。
這裡不是。

⇒ 連同 §10（物理當特徵沒有讓學習曲線左移）、§11（學習節重讀 L3 只到 22%、輸給
直接看 pattern 的 33%），**三次嘗試從三個不同角度都失敗**。
**共同原因**：物理節有一個 ~2.5 倍、且**不是常數**的系統誤差
（比值 0.19–0.41 隨尺寸變）。**在這個基底上，任何形式的學習節都在追一個移動的目標。**

### 20.2 ⇒ 剩下的唯一正路：改基底

`1/√d` 的奇異性必須進到**基底本身**。但完整的邊緣基底會破壞平移不變性
（＝L2/L3 便宜的唯一原因）。**有一個折衷值得算**：

> 邊緣格的電流不是均勻的，而是集中在邊緣。
> `1/√d` 在 `[0,1]` 的**重心**是 `∫d·d^(-1/2) / ∫d^(-1/2) = (2/3)/2 = **1/3**`，
> 而均勻分佈是 `1/2` ⇒ **有效位置偏向邊緣 1/6 格**。
> 若只改「查表用的等效距離」，**平移不變性完全不受影響**（還是查同一張表，只是查不同距離）。

同理，**自項**（`∫∫ f f G`）在 `1/√d` 加權下與均勻加權不同，
而自項的修正**只動對角元素**，也不破壞查表。

⇒ **下一步：算 `1/√d` 加權下的自項與等效距離，看能補回多少。**
這是本輪唯一還沒試、且**不破壞架構**的路。

## 21. ❌ §20.2 的折衷也不夠 —— **不破壞平移不變性就救不了**

§20.2 提了兩個「不動架構」的修正：等效距離偏移、自項在 `1/√d` 加權下重算。
用重要性抽樣算（`y = u²` 的變數變換讓權重被**完全吸收**，奇異性消失，MC 誤差 0.2%）：

| 加權 | 自項 `<1/R>` | 相對均勻 | 等效 `b_reg` |
|---|---|---|---|
| 均勻（現況） | 2.9780 | 1.000 | 0.3358（對上解析 0.3363 ✓） |
| 單側 `1/√y` | 3.1933 | **×1.072** | 0.3132（×0.933） |
| 兩側 `1/√(y(1−y))` | 2.8639 | ×0.962 | 0.3492（×1.040） |

**電流重心**：均勻 0.500、單側 `1/√y` 是 **1/3** ⇒ 偏向邊緣僅 **0.167 格**；兩側對稱不偏移。

⇒ ❌ **修正只有 ±4–7%，而需要的是 2.5 倍。**

### 21.1 為什麼不夠 —— 一個清楚的物理理解

邊緣奇異性的效應**不在「單一格內的分佈形狀」**，而在**「邊緣格應該承載的電流總量」**。
`1/√d` 讓電流在邊緣**堆積**，而 rooftop 基底把每個格的電流限制成一個自由度
⇒ 它能表達「哪一格電流大」，**表達不出「電流在格內往邊緣堆」**。
修自項或等效距離只是在調整**同一個自由度的權重**，
而缺的是**額外的自由度**（＝更豐富的函數空間）。

⇒ ★ **這在不破壞平移不變性的前提下無解。** 而平移不變性正是 L2/L3 便宜的唯一原因
（一張 293 個相異距離的表 ⇒ 每筆 0.7 秒）。**準度與成本在這裡是綁死的。**

### 21.2 若真要修，成本評估

| 方案 | 做法 | 成本 | 風險 |
|---|---|---|---|
| **A** | 非均勻網格（邊緣加密）＋**直接組裝 Z**（放棄查表） | Z 組裝從 O(1) 查表變 O(n²) 積分 ⇒ **約慢 40 倍**（0.7 s → ~27 s/筆） | 準度提升幅度**未知**；且即使修好，仍要對上 SM 的 52% |
| B | 加邊緣基底（保留 rooftop，額外加 `1/√d` 的自由度） | 未知數 +~6%，但**互阻抗要重算**（破壞平移不變） | 同上 |
| **C** | **接受不準，用全域 `k≈2` 校正** | 零 | 只是 fudge factor，但命中率 12%→20% 是真的 |

### 21.3 ⇒ 本輪的技術終點

**所有「不破壞架構」的修法都試過了**：
解析加權基底（§19.3，恆等變換）／pattern-specific `k`（§20，目標定義不清）／
自項與等效距離修正（本節，±7%）。
⇒ 問題從**「還沒找到方法」變成「已知需要多大的投入」**——這是有價值的收斂，
下一個人不必再試這三條。

## 25. ❌ `Re/η` 修正失敗 —— **用模型算出的量去修模型是循環的**

§24 定位到「表面波被高估」。有一個**有物理依據**的修法：
模型假設**橫向無限**基板 ⇒ 表面波傳到無限遠＝純損耗；
但實際板只有 **35×20 mm**，表面波往返 ~2.8λ₀ ⇒ **大部分反射回來、不損耗能量**。
若如此，真實的 `Re` 應該是「扣掉表面波」的 **`Re/η`**。
而 §24.2 顯示那正好讓兩個獨立對照都吻合（21→49 Ω vs 真值 37–68；195→455 vs Balanis 525）。

**實測（250 筆 `clean_OOS`）**：

| | ρ | 命中率 | P(勝隨機) | min-S11 中位 |
|---|---|---|---|---|
| 原樣 | **+0.380** | **18%** | 26% | −10.43 dB |
| **`Re/η`** | **−0.086** | **7%** | 50% | −14.53 |
| `Re/η` 且 `Im/η` | +0.217 | 17% | 60% | −10.31 |
| 對照 `Re×2.5` | +0.121 | 15% | 56% | −15.71 |
| **真值** | | | | **−16.67** |

⇒ ❌ **絕對量級確實往真值走（−10.4 → −14.5），但排序全毀**（命中率 7% < 隨機的 10%）。

**原因**：η 的分散極大（中位 **0.203**、IQR 0.129–0.281）。
**除以 η 等於把 η 自己的誤差放大進 `Re`**，而 η 也是同一個模型算出來的。

⇒ ★ **教訓：用模型算出的量去修模型是循環的。**
修正引入的噪音大過它修掉的偏差。這與 §19.3（加權基底是恆等變換）、
§20（目標定義不清）是同一類——**看似有物理依據的修正，落地時被自身的誤差吃掉**。

⚠ 另外注意：**真實 pattern 的 η 中位只有 0.203**，比 §24 用矩形貼片量的 0.43 低得多
⇒ 複雜幾何的表面波佔比更高（或者說模型認為更高）。

- empymod 的驗證**明確標註**其範圍是「源與觀察點都在**上方空氣區**」；
- 而症狀（損耗 ∝ (εr−1)¹ 而非 (εr−1)³）指向 **TM₀ 極點的留數權重**，
  它在 εr→1 時退化消失（所以金標準完美）。

**下一個人只需要看一個式子**：
`gtilde` 回傳的 `(jωε₀/k_ρ²)(Ṽ^e − Ṽ^h)`，在 `z=h` 的正確形式是否需要額外的介面項。

## 29. ★★★★★ 譜域分段：**假損耗的主要來源是 `k_ρ < k₀` 的輻射區，不是表面波區**

把 Sommerfeld 積分按 `k_ρ` 分段，各段單獨算 G_V 的貢獻（ρ=1mm, f=20.8GHz）：

| 區間 | εr = 1.00 | εr = 3.55 | Δ(Im) |
|---|---|---|---|
| **① 輻射區 `k_ρ < k₀`** | 0.911 **− 0.885j** | 0.307 **+ 1.307j** | **+2.19** |
| ② 表面波區 `k₀ < k_ρ < k₀√εr` | 0（不存在） | −1.460 **+ 0.687j** | +0.69 |
| ③ 凋落區 `k₀√εr < k_ρ < 4k₀` | 2.256 − 0.195j | −0.511 + 0.075j | +0.27 |
| ④ 遠尾 `4k₀ < k_ρ < 200k₀` | −0.172 + 0j | −0.142 + 0j | 0 |
| 靜態加回 | 23.756 | 6.440 | — |
| **總 G_V** | 26.751 **− 1.080j** | 4.634 **+ 2.069j** | **+3.15** |

### 29.1 為什麼看 `Im(G_V)`

`Z_V = (dx²/jωε₀)·G_VV` ⇒ `Re(Z_V) = (dx²/ωε₀)·Im(G_V)` ⇒ **`Im(G_V)` 直接就是損耗**。
對照 §28.2 的分解：`P_V` 在 εr=1 是 **−9.21e−07**（負）、εr=3.55 是 **+3.34e−06**（正）
—— 與這裡的 `Im(G_V)` 由 −1.080 變 +2.069 **完全一致**（符號與量級都對得上）。

### 29.2 ⇒ 三個關鍵事實

1. **εr=1 時 `Im(G_V)` 是負的**（−1.080）⇒ `Re(Z_V) < 0`。
   那本身不是錯——它與 `Re(Z_A) > 0` 相消，**總和恰好等於 `P_sp`（η=1.0000）**。
   ⇒ **兩項的相消是設計的一部分**，不能單看其中一項。
2. **主要的變化在 ① 輻射區（+2.19），不是 ② 表面波區（+0.69）。**
   ⇒ **假損耗不是表面波** —— 這推翻了 analysis-09 §7.2 與本檔 §24.3 的說法（**兩次都錯**）。
3. **遠場算出的 `P_sp` 對所有 εr 完全不變**（3.7321e−06，因為測試電流固定）。
   而 `Z` 的輻射區貢獻卻隨 εr 劇變 ⇒ **兩者不一致，就是 bug 的所在**。

### 29.3 ⇒ 問題被縮到「`k_ρ < k₀` 區間的 `G̃_V`」

這個區間裡 `k_z0` 是**實數**（傳播波），`k_z1` 也是實數（若 `k_ρ < k₀√εr`）。
所有波阻抗都是實的，而 `t = tan(k_z1 h)` 也是實的
⇒ `Ṽ^e`、`Ṽ^h` 的虛部**完全來自 `Z₀ ∥ Z_dn` 這個並聯結構**。

**下一步要檢查的就是這一件事**：在 `k_ρ < k₀`、源位於 `z=h` 時，
`Ṽ = Z₀·(jZ₁tan)/(Z₀ + jZ₁tan)` 是否為正確的電壓 Green's function，
還是需要別的組合（例如含 `Ĩ` 的項、或不同的歸一化）。

## 30. ★★★ 定位到「遠場與 Z 不一致」—— 但正確的遠場形式我還沒推出來

### 30.1 一個確鑿的事實

`l2.farfield()` 的鏡像因子：

```python
img = 2j * torch.sin(k0 * H * cosT)        # ← 完全不含 εr
```

**那是「PEC 地平面上方 h 的自由空間電流」的公式**——而 Z 矩陣的核（L3）**含**介質層。
**兩者用的是不同的物理。**

這**解釋了本檔所有的症狀**：

| 觀察 | 解釋 |
|---|---|
| εr=1 時 η = 1.0000（五位數） | 介質＝空氣，遠場公式**正好正確** ⇒ 兩者一致 |
| εr>1 時 η 掉到 0.44 | 遠場少了介質效應 ⇒ 與 Z 不一致 |
| 假損耗 **∝ (εr−1)¹** | 不一致的程度線性於介質對比度 |
| **P_sp 對所有 εr 完全不變**（3.7321e−06） | 公式裡根本沒有 εr（測試電流固定） |
| 假損耗主要在 `k_ρ < k₀` 輻射區（§29） | 那正是遠場對應的區間 |
| 與電流分佈、基底、b_reg、路徑、收斂性全都無關 | 它們都不影響「遠場公式含不含 εr」 |

⇒ ★★★ **這是一個確鑿的不一致，而且它是 bug 的位置。**

### 30.2 ❌ 但我試的三種修正都沒有消除 εr 依賴

正確的遠場角度因子應該是譜域在 `k_ρ = k₀sinθ` 的取樣（與 Z 同核 ⇒ 自洽）。試了：

|---|---|---|
| **現況**（`2j·sin(k₀h cosθ)`） | 1.0000 → 0.4441 | **2.25×** |
| `et~Ṽ^e, ep~Ṽ^h` | 0.5450 → 0.3385 | 1.61× |
| `et~Ṽ^e, ep~Ṽ^h·cosθ` | 0.2500 → 0.1958 | **1.28×**（最好） |
| `et~Ṽ^e·cosθ, ep~Ṽ^h` | 0.5182 → 0.2752 | 1.88× |
| A+V 分解（與 Z 同結構） | 0.7651 → 0.3185 | 2.40×（更差） |

**目標是散布 → 1.00（絕對值可差一個歸一化常數）。沒有一個做到。**

⇒ ❌ **我知道問題在哪，但推不出正確的形式。** 誠實記錄，不硬湊。

### 30.3 一個有用的檢查點（給下一個人）

在 εr=1、h→∞（拿掉地平面）時：
`Ṽ^e → Z₀^e = k_z0/(ωε₀) = k₀cosθ/(ωε₀) = η₀cosθ` —— **正好是自由空間的 TM 角度因子**。
所以 `E_θ ∝ Ṽ^e` 時**不該再乘 cosθ**（我一開始多乘了）。
同理 `Ṽ^h → Z₀^h = ωμ₀/k_z0 = η₀/cosθ`，而自由空間的 TE 因子是 `η₀`
⇒ **TE 這一支需要一個 `cosθ`，TM 不需要**——兩支不對稱，這是最容易搞錯的地方。

⚠ 但即使照這個做（`et~Ṽ^e, ep~Ṽ^h·cosθ`），散布也只降到 1.28×，**仍不是 1.00**
⇒ **還缺別的東西**（可能是電流/電荷的分離處理、或介面上的額外項）。
