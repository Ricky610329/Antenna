## 2.5 mfg 探針:kn_16 可製造化(Ricky 提議 2026-08-13;判準發車前寫死)

體檢:真對角接點 **47 個**;4-conn(蝕刻語義)碎成 29 塊 vs 8-conn(模擬)4 塊;
微塵(≤2px)15 個。變體=**fill 版**(每接點補一顆正交像素→全部變真 0.2mm 連接,
補位規則=額外鄰接最少者,決定性)+**fill+trim 版**(再清 8-conn 孤立 ≤3px 碎片)。

- 判準:①fill 版 |Δwm_r2| ≤ 0.3 → **可製造版≈免費**,出圖版=fill 版,家族綠燈
  (50×50 上採樣親本也改用 fill 版——上採樣不解決點接觸);②Δ > 1.0 →
  **性能依賴點接觸=模擬-實物落差紅旗**,家族紅旗+此後出圖/50×50 親本必過 fill 檢;
  ③0.3~1.0 → granular 歸因(二分找命脈接點)。bits 語言=正常入鍋。

## 4. 分析 (Analyze)

### mfg 探針判讀(2026-08-13 13:3x;2/2 零 error)——★紅旗判定

**fill 版 wm_r2 −23.83(Δ −20.78)/fill+trim −23.54**:把 47 個點接觸補成真 0.2mm 連接
後性能完全蒸發(m3 −3.05→−23.8)——**kn_16 的濾波行為活在點接觸上**,判準②紅旗觸發
(門檻 1.0,實測 20.8)。

族群審計:v2 榜前段全部 46-49 接點(kd_24 48/0093 46/n24 49/0252 47/0549 48)=
**全榜通病,「隨機塵埃濾波器」物種特徵**;唯一例外=wireO 家族 **2 個接點**(手畫導線,
天然近可製造)。

### 煙測判讀(2026-08-13 13:0x;2/2 零 error)——★括號自證失敗

上採樣 kn_16(幾何物理全同):m1 Δ+0.51 / m2 Δ−0.40 / **m3 Δ−2.93 / m4 Δ−3.50**;
0252 更慘(m3 Δ−5.01)。遠超判準①(0.3)與②(1.0)→ 判準③幾何/機理狩獵。

### ★三線匯流假說(2026-08-13 13:5x;對照組發車前寫死)

fill 探針(接點=命脈)+族群審計(全榜 46-49 接點)+煙測(同幾何換離散度=崩)
→ **「點接觸導通=求解器在像素角奇異點的數值縫合,強度隨網格/離散度改變」**。
若成立:對角湯物種的性能=數值幻影(實物蝕不出、換離散度也不重現);
r59dx 當時只證了「有導通」,沒證「導通強度尺度不變」。

**對照組判準(r69s50c,發車前寫死)**:乾淨結構的括號應成立——
① wireO 上採樣(2 接點)六軸 |Δ| ≤ 1.0 ∧ fill 版上採樣(0 接點)|Δ| ≤ 1.0 →
假說確認:50×50 儀器本身沒問題,崩的只是接點幻影 → 戰略重置(搜尋域=4-conn 乾淨子空間);
② 兩對照也崩 >2 → 崩因=一般網格/離散化問題,50×50 儀器凍結,假說降級。
