## 1. 假設 (Propose)

**假設**:p00 湯榜排序半保留(存活地圖 ρ+0.60)→ 舊榜前段家族帶標準橋重測後仍居
mfg 榜前段;乾淨生成語言(生成時消對角)以「免橋簡潔」競爭。

- **判準(發車前寫死,2026-08-13)**:
  1. **奠基判定**:三臂各自 best 比較——A(舊榜帶橋)領先 B/C 逾 1dB → 繼承路線
     (舊家族+標準橋=主力);B(乾淨生成)進 A 的 1dB 內 → 乾淨語言升主力(免橋);
     C(帶橋隨機)出頂 → 湯語言在誠實儀器下重新有效。
  2. **新紀錄鍵 `wm_mfg`**:批 best 公證 3/3 後開帳(首帳即基準;已知參考=
     kn_16+0.075 = −5.96 單次)。
  3. B 臂生成器自證:30 筆接點全=0(生成端消對角演算法的括號)。
  4. 臂:A 30(p00 榜前段多樣 30 家族代表,帶橋)/B 30(乾淨生成,裸 p01)/
     C 30(symr 湯,帶橋);≤3 批必收輪;節奏=慢(Ricky 裁定,不衝批)。
- 修訂紀律:結果回來前+日期註記。
