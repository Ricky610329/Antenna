## 5. 結論 (Conclude)
1. **§1 假設答案**：champ 可信半徑機制**不能**直接轉移中繼帶——「近錨梯度變現」在中繼帶
   連兩批 0 命中判死（密度不足以支撐梯度）;但**鄰域變異（L 臂）能**——同框帳 1→4→7 遞增,
   同框紀錄推進兩次（−4.21→−5.02→wm+0.15∧lo−4.50）。低側戰役的可走路線=翻 bit 不是反傳。
2. **SM 利用率元年成果**（工具三連勝）：std 校準完美單調（0.94/4.00/10.05）→LCB 進鍵常駐;
   rad_head 同期制度合訓→前瞻連兩批 ≥0.4 進鍵常駐（b3 −0.474 警訊,退鍵帳 1/2 帶進 R32）;
   gen 漏斗（3× 挑 top）+誤差錨點池（錯哪補哪）上線。
3. **王系凍結審計全過**：近王 3%/1%/3%、血統根 ≤9%、d_dyn 中位 253-261——增量歸零達成;
   低側資料佔比上升,中繼帶 89→100+ 筆成第二大陸。
4. **殘閘定位**：同框 7 筆全數 rad 負（−1.5~−4.1)∧wm 差最後一哩（−0.17~−1.84)——
   R32 的問題=「同框且 wm/rad 同時修回」,深水實體已在（oob_bad 3.10/5.11）。
5. 凍結尺兩連 bug（切分位移/雜湊口徑）當批修復,v42 起凍結基準 1,772 筆全程有效。
