## 1. 方案菜單

### Tier-1 零部署(現有機台 code 直接吃,pattern 級)
- **P1 對稱化探針**(已備料 `dedust_r55sym_input`,13 親×L/R/O 鏡像=**34 筆,check-dup 綠**
  〔5 筆摺疊重複已剔;附帶發現:t07 產線系左半全同,演化集中右半場〕,S0):
  Y 鏡像對稱 ⇒ φ90 場型**物理保證對稱(置中)**;量的是 wm/lo 的代價分布。
  判準骨架:置中達成率(\|峰\|≤10°)∧ wm 掉幅中位;代價 ≤0.3=「對稱化=可行置中術」。
- **P2 微調爬山新鍵**(恢復探索後):lo-primary key、rad-centered key(峰位/質心入鍵)——
  chain 判讀在開發機,零部署;掛在既有 chain/手術機器上。
- **P3 診斷儀器化**:φ90 峰位+Y 質心進 `analyze`/KPI(傾斜已量兩次,達工具化門檻)。

### Tier-2 一行部署(`allowed += "pixel_count"`+機台 pull)
- **P4 50×50 精修域**:學長內建 50 分支(0.1mm)。上採樣精英(2×2 複製=等幾何)→
  **半像素輪廓微調**(邊緣 dilate/erode/補缺口/去尖角=設計式變體套餐,非自由搜尋)。
  第一用途=**Y 質心精平衡**(0.1mm 質量步階=4× 細,對付刀鋒)。
  規則:**禁新對角**(0.1mm 像素的對角橋 <蝕刻下限——可製造性 by construction)。
  資料域=2500-bit 新域,獨立 store 零入鍋,SM 後補(資料遊戲延伸)。
  先 smoke 1-3 筆量成本(建模 2500 盒+0.1mm 網格,估 2-5× S0)。

### Tier-3 突破 pixel 化(參數化幾何;菱形橋已驗證此路線工程可行)
- **P6 參數化元件庫**:625 backbone 上疊參數化元件——chamfer/stub/slot/邊緣延伸,
  每種=一段 CreateBox/Rotate/Subtract 程序(菱形+挖空=前兩個成員)。agent 提案+HFSS 驗證。
- **P8 波束舵**:參數化 **Y 向邊緣連續延伸**調質心=把 +46° 舵回 0 的**最小干預**
  (對稱化=最大干預,舵=保留不對稱共振只調質量矩)。載體=P4 半像素或 P6 參數化。
- P7 全自由輪廓(CreatePolyline,遠期):表示/查重/資料域全新,本輪不排程。

## 2. 量測策略(±0.3 抖動下怎麼量微調)

配對雙生(同批同機同尺)為唯一合法比較;單筆效果 <0.3 dB=不可信,要嘛 n=2 平均、
要嘛族群統計(如戰役模式 n>100 看分布位移);S1 只做終選公證。

## 3. 建議路徑

1. **P1 對稱探針先發**(~35 筆 ≈1.5 機時,零部署;答「置中的代價」)。
2. **P3 診斷進 analyze**(開發機,立即)。
3. **P4 smoke**(下次 pull 後 1-3 筆)→ 成本落地才設計輪廓套餐。
4. **P8 波束舵**=P4/P6 的第一個應用實驗(對照 P1:最大 vs 最小干預,同一目標)。
5. P2 新鍵=探索恢復後的批線臂形式。

## 4. 與現行軸的關係

低對角左側軸不變;微調=在合格解上加特性(lo/rad)=左側戰役續章。
菱形規則(對角帶 w=0.10 出圖+選解留 0.3 稅 buffer)為一切微調的製造性前提;
挖空 13/13 全滅=「微調不得斷開角」的硬約束。
