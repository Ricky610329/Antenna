# Round 7 — 除塵驗證（de-dust）：達標 pattern 的粉塵是不是 load-bearing？

- **狀態**: archived（2026-07-03 當日完成，15/15、~45 分）

- **一句話問題**: harvest 池達標 pattern 拔掉 1-3px 粉塵後，S11/Gain margin 撐不撐得住？順帶：它們的 radiation ±45° 覆蓋過不過？

## 1. 假設 (Propose)

- **問題 / 假設**: lab 真目標＝S11＋Gain＋rad ±45° 覆蓋＋**可製造**（裁切製程：允許不連通、不要很多 1×1）四約束。離線交叉分析實錘：池內 18 筆達標 pattern 全是「3-8 塊大銅片＋10-18 顆 1-3px 粉塵」（Hamming≤100 下實為 **2 個家族**）、整池零筆「無 1px 碎片」達標——乾淨子空間學長沒踩過。**假設：粉塵不是 load-bearing**（1-3px 孤島電尺寸小、耦合弱；analysis-01 說細碎度是雙邊最強負因子）→ 拔掉後 margin 大致撐住 → 可製造達標 pattern 直接到手。
- **為何現在做**: R6 說「達標 pattern 已在池內」但那 18 筆不可製造——這是「歷史資料直接用」路線的最後一哩；且每次 solve 順帶方向圖＝rad ±45° 首次驗證＋Stage-3 `harvest_single_rad` 冷啟動資料（一魚三吃）。R5 D 臂提早收（墊底 -7.66@34、D-only 隔離問題 R3/R4 已答過）讓出 .37。
- **預期結果與判準**:
  - (a) 存在「d1/d3 版 wm≥0 且 rad_margin≥0」→ **lab 終極目標到手**（零搜尋、純資料分析）；
  - (b) 除塵版掉 ≤~1dB → 粉塵貢獻小 → 從除塵版 warm-start 局部精修（analysis-01：局部半徑數十翻轉可導、配方已知）；
  - (c) 掉很多（>2dB）→ 粉塵在這些設計上是共振的一部分 → 「乾淨可製造」需要在乾淨子空間內重新搜尋（DIP sigmoid 天生住那裡）。
  - 副判準：原版重驗 vs 池 margin（舊 HFSS response 重算）之差＝**R6 oracle 的真偽檢驗**；rad ±45°/floor 3dB 覆蓋首次有真數字。
- **依據**: [round-06](round-06-offline-expected-best.md)（分布≫策略、oracle +0.38）· [analysis-01](analysis-01-pattern-anatomy.md)（結構配方/細碎負因子）· scratch 2026-07-03 戰略討論塊（碎片尺寸分布數字）· decisions「可製造性定義」（2026-07-03）

三標全過（wm≥0 且 rad≥0）：**0 筆**。四待答逐一回：

1. **主假設否決（4/5）**：拔粉塵崩 **-4.7 ~ -16.9 dB**——碎片雲設計的「粉塵」是分佈式共振負載，不是雜訊。**唯一例外 p03**（主件 243px 最整塊、2-3px 件只有 1 個）：d3 拔 19px 後 Δ **-0.02**、rad 反升 +0.24——「**本來就整塊的設計，粉塵才真的是粉塵**」。
2. **R6 oracle 為真**：p00_orig 重驗 **+0.44 達標**（池 +0.38，漂移 +0.06）；其餘 orig 漂移 -0.2 ~ -2.5（S11 側偏大，p02/p03 掉 1.4-2.5）→ 池 margin 排序可信、絕對值有 ~1-2dB 不確定帶，薄冰級（+0.0x）的達標要打折。
3. **rad ±45° 這關獨立且會刷人**：orig 五筆 rad 餘裕 -2.71 ~ +0.26（p01/p04 過、**史上最佳 S11/Gain 的 p00 反而最差 -2.71**）→「S11/Gain 好 rad 自動過」不成立，但差距都在 0-3dB 帶內。二階觀察：**除塵傾向改善 rad**（p00/p03/p04 皆升，與 analysis-01「口徑乾淨利 beam」一致）——rad 與可製造性是**同向**約束，衝突的是 S11 共振。
4. **SM 對乾淨區不可信**：方向對（預測會掉）、幅度嚴重低估（預測 -0.2~-1.6 vs 實際 -5~-17）——池分佈外的外插失效實錘；15 筆乾淨區真值已入庫 `dedust_r7`（正好是 SM 最盲區的重錨資料）。

## 5. 結論 (Conclude)

- **學到什麼**:
  1. 「可製造達標 pattern 直接從池裡撿」此路不通（判準分岔 **(c)**）——達標設計的細碎不是可去除的雜訊，是共振方式本身 → 乾淨可製造解必須在乾淨子空間**搜**出來，不能從碎解**修**出來。
  2. 但「乾淨子空間」的入場券已到手：**p03_d3 = 可製造世界目前最佳已知點**（全碎片≥4px、n_comp 5、wm -2.68、rad +0.24）——與 spec 差 2.7dB，正好落在線上精修的射程（analysis-01 局部半徑）。
  3. rad 首驗定調：獨立的第三關、0-3dB 帶內、與可製造同向 → 「rad 弱推力」課程化（ONGOING 走 a 案）必要性 +1。
  4. 批次驗證 3 分/筆 → 「離線篩→批次驗」模式的成本比想像低一個量級,可常規化。
- **決策**: 主線轉「**乾淨子空間 warm-start 精修**」：起點 = p03_d3 ＋ 池內乾淨前緣（main_frac≥0.9 best -0.81 那批,結構與 p03 同型、除塵代價可能同樣小）;候選生成端掛 `strip_small` 無粉塵修復。
- **促成候選**（回寫 ONGOING 🔜）: ① **R7.5 乾淨前緣重驗+除塵**（main_frac≥0.9 top-K,~20 筆 ≈1hr,把「可製造世界起點」的 -0.81 驗真）② **乾淨 warm-start 精修 round**（湊齊起點後發）③ rad head pretrain 資料已入袋（Stage-3 解鎖）④ SM 乾淨區重錨（dedust_r7 15 筆併訓練）。
