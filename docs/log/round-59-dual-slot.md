## 4. 分析 (Analyze)

### b1 判讀(2026-08-11 09:36 收檔;84/84 零 error;全部單次)

1. **判準① 嚴格命中=0,但「開縫=有效旋鈕」方向確立**(判死分支明確不成立):
   全切縫把 m4 從冰凍帶(−18.9±0.09)撬到**中位 −8.00**(Δ≈+11 dB!)——代價=m3 中位 −15
   (斷線=通阻雙死);半切縫 m3 保 +1.58 但 m4 只動 0.3。b1 只採了兩個極端深度,
   **中間耦合帶沒採到**——這是 b2 的細掃對象。
2. **中間態已見雛形**:sl2_r6r12 全切 m3 −4.82/m4 −13.46;sl1_r12(中線縫)m3 −5.53/m4 −14.09;
   sl3_r7 殘橋@col16(邊耦合)m3 −6.05/m4 −14.84——trade 曲線是連續的,耦合線理論圖像成立。
   sel 前緣 −18.9 → **−11.77**(sl1_r11 全切),向 −7.01 推進 7 dB 但未破。
3. **判準③ 劑量反應=單調成立**(full:縫 1→2 m4 −8.00→−6.70↑、m3 −15→−20↓)=可設計✓。
4. **wctl 對照完美**:路徑外擾動 m4 全卡 −18.96~−18.77=效應 100% 路徑特異✓。
5. 縫位規律:近中線(r11/r12)最保 m3;殘橋位置 col16(邊)優於 col10/12(中)——邊耦合構型。

### b2 判讀(2026-08-11 10:13 收檔;36/36 零 error;全部單次)

   是有效構型;判準① 嚴格命中仍 0。
2. **★ 守恆帶發現**:前緣樣本 m3+m4 全落 −17~−18(f12b7 −17.9/f12b8 −16.8/dp_Rr7w1 −17.8)
   ——trade 曲線沿「總量守恆線」滑動,**1-2 段端耦合諧振器的裙擺總量有上限**,
   要同時 m3>−3∧m4>−15(總量 >−18 且分佈均衡)需要更強耦合構型或更多段。

   不是連續劑量尺,劑量作用只在「全切+輔縫」組合層。
4. 縫位效應:輔助殘橋越靠饋墊(r7>r8>r9)m4 越好;全切放中線(r12)最保 m3——
   「中線全切+近墊殘橋」=b2 定版構型。
