## 1. 假設 (Propose)

**假設**:①鍋 3.4× 擴充後 v2 引導 > 盲選;②細排力=真考題,只能在引導批頂端窄帶量;
③高分歧(ensemble std)樣本=資訊量高的探索標的。

- **判準(發車前寫死,2026-08-11 18:2x)**:
  1. **臂設計=防馬太三件套**:g 臂 50(v2 ensemble top)/c 臂 25(同池均勻對照——沒有它
     連馬太都量不到)/d 臂 25(池 top-1000 內 ensemble std 最高=高分歧探索)。
  2. **引導有效**:g 中位 > c 中位(mann-whitney P<0.05);盆地拆帳照 R58 口徑
     (g vs c[同池種] 分開報)。
  3. **細排考卷(主判準)**:g 臂 50 筆內 pred vs true spearman ρ——**≥ +0.3 = 線上學習
     系統重啟觸發線**(對 Ricky 的承諾);< 0 = v2 仍純粗篩,SM 引導降頻(每 2-3 輪一批)。
  4. **d 臂判讀**:高分歧組的 true wm 散佈應顯著寬於 g 臂(資訊量證據);出黑馬(>c best)
     記帳。
  5. 王(−6.04)/m4(+5.92)紀錄照 records_dual;破=公證 ×2;m5/m6 觸發照舊;≤3 批必收輪。
  6. 資料紅利:本批 100 筆全數 bits 忠實 → 入鍋(v3 素材)。
