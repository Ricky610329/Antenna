## 1. 假設

**現行 2 鏡像近似把表面波整段丟掉了，而表面波在這個 stackup 上不是小修正。**

證據（analysis-08 §10 + 本輪 fan-out）：

| | |
|---|---|
| 能量守恆 | η = P_rad/P_in = **0.872**，且**對三個不同尺寸貼片完全一致** → 系統性缺口非雜訊 |
| 核的直接比對（精確 vs 現行 2 鏡像，28GHz） | `G_A` 只差 8–18% 振幅、相位幾乎全對；**`G_V` 在 ρ=6.93mm 差 7.55× 且相位錯 77°** |
| 表面波佔 `G_V` 的比例 | ρ=1mm 時 31–53%，ρ=6.93mm 時 **64–84%** |
| 結構性理由 | DCIM 的函數族 `Σa·e^{−jknR}/4πR` 衰減不慢於 1/r，**表達不出**柱面波 `e^{−jβρ}/√ρ`（Şimşek 2006：球面波湊不出柱面波） |
| ⭐ 且只在 G_V | formulation C 下 `G̃_A = Ṽ_i^h/(jωμ₀)` 只含 TE 線，帶內無極點（TE₁ 截止 92.4GHz）→ **TM₀ 完全由 G_V 攜帶** |

→ 這解決了 analysis-08 §10 說的「正確的 residue 在 G_A 與 G_V 有不同權重與相位」：
**G_A 的 TM₀ 權重是 0。**

## 3. 實作計畫

### 3.1 ★ 順序刻意不照文獻階段走：**先做最小可證偽版**

方案研究給的六階段裡，**S1（r=0 自項與近格的雙面積分）佔一半以上工作量，且是唯一沒有原型的**。
按順序做會在最貴、最不確定的地方卡住，卻還沒回答「L3 值不值得」。

**所以先跳過 S1**：自項繼續用現行的 `b_reg = 0.4·dx` 頂著（它本來就在扮演這個角色）。
依據是診斷本身就指向遠距離——`G_A` 在 ρ→0 只差 11%、`G_V` 差 2%，**錯的全在遠端，而遠端不需要 S1**。

| 階段 | 做什麼 | 出口 |
|---|---|---|
| **A（最小可證偽）** | spectral 核 + 靜態扣除 + 上偏折 GL 積分 → 293 個相異距離的表；自項沿用 b_reg | dev 上量 G-L3a/b。**不過就停，不做 S1** |
| B（僅當 A 過） | r=0 自項與近格的雙面積分（奇異性抽取 + 解析/Duffy） | Re(Zin) 對矩形貼片的量級 |
| C | empymod 獨立對帳（**已派 agent 進行中**） | 相對誤差 <1% |
| D | delta-gap 假電容（**已派 agent 進行中**；與 L3 同為一階，缺它到不了真值） | 中位 min-S11 −1.33 → ~−3.3 |
| E（選） | 精確表上疊零初始化可微殘差 | 記帳：物理節 vs 學習節 |

### 3.2 可微性（Ricky 的硬約束）

**核可不可微，對 ∂L/∂ρ 完全沒有影響** —— 已用 gradient check 實測確認：
梯度鏈是 `ρ → wgt → load → (Z + diag(load)) → solve → S11`，**Z（含核）在這條鏈上是常數**。
8 個抽樣像素 7 個相對誤差 <1%，625/625 像素有非零梯度（`test_l2_gradient_check_vs_finite_difference`）。

⇒ 離線算 Sommerfeld（哪怕完全用 scipy、完全不可微）**零損失**。
代價只有「對 stackup（h、εr）與核參數不可微」——而 h/εr 只有 2 個純量、離線重算全表 6 秒，
有限差分就夠；核的可置換性由階段 E 的殘差層保留。

### 3.3 為什麼連內插都不需要
25×25 的格心偏移 `r² = gi² + gj²` 是整數 → **只有 293 個相異距離**。
全表 2 核 × 17 頻 × 2499 偏移 complex128 = **156 KiB**，離線 ~6 秒。
`l2.py` 現成的 `self.off` 索引直接用 → **精確查表、零內插誤差、比現在還快**（省掉 2499×3 次 exp/sqrt）。

- G-L3b（neg 不退步）：**過**（+0.442 → +0.563，且 CI 不含 0）
- ⚠ **診斷指標反而變差**——正是 §2.2 預警的「只有 wm 好＝可疑」。

⚠ 能量守恆：η 從 0.876 掉到 **0.37–0.40**。依 §2.3 這方向是對的（表面波是真實損耗管道），

### 4.3 ★ 但「未過」的原因已定位：**是我刻意跳過的自項，不是核**

§3.1 跳過 S1 時的理由是「錯的全在遠端」。掃 `b_reg`（自項正則化半徑，dev 小樣本 35/層）：

| b_reg/dx | clean ρ(wm) | neg ρ | 帶內S11逐頻ρ | 谷底頻率ρ |
|---|---|---|---|---|
| **0.2** | **+0.343** | +0.461 | **+0.277** | +0.186 |
| 0.3 | +0.321 | +0.464 | +0.222 | +0.248 |
| 0.4（階段 A 用的） | +0.259 | +0.509 | +0.178 | +0.330 |
| 0.55 | +0.100 | +0.421 | +0.153 | +0.049 |
| 0.8 | +0.049 | +0.311 | +0.138 | +0.138 |

**clean ρ 變化 7 倍（+0.049 → +0.343），單調「越小越好」⇒ 自項是主導因素。**
而 `b_reg = 0.4·dx` 是**為舊 DCIM 核調的**，對精確核不是最佳值。

⇒ §3.1 那句「錯的全在遠端」**只對了一半**：遠端確實錯（G_V 差 7.55×、相位 77°），
但把遠端修對之後，**近端/自項的相對誤差就變成新的主導項**。這是可預期的、也是好消息——
它把 S1 從「可能白做的 1–2 天」變成「已定位的瓶頸」。

### 4.4 ✅ 階段 C：empymod 獨立對帳 —— **核是對的**（2026-08-03 03:2x）

派獨立 agent 用**四條互相獨立的管道**驗 `l3.py` 的公式（它拿到的是公式轉錄，不是我的結論）：

| 管道 | 驗到什麼 | 結果 |
|---|---|---|
| **εr=1 精確鏡像法** | 分支選擇／`Z₀^{e,h}`／短路 stub／`V_i`／**兩行係數的前因子** | **1.5e−13 ~ 2.2e−12** |
| **TM₀ 極點 vs 教科書色散式** | εr 擺放（最銳利的檢驗） | **1.0181707/1.0254101/1.0342279** — 我的 1.0182/1.0254/1.0342 對到 7 位 |
| **Fresnel 多次反射幾何級數**（完全不同的推導路線，不用傳輸線） | `Z_dn = jZ₁tan(k_z1 h)` | TE **1.0e−15**／TM **6.0e−11** |
| **empymod 場層級 @εr=3.55** | 整體 | 相對差 1e−6 ~ 1.6e−1，**全部 40 點都落在 empymod 自己的方法散布內** |

★ **關鍵是它做了鑑別力測試**：故意把公式弄錯再跑同一套比較 —— `Z₁^e` 漏 εr → 誤差 1.07；
`n=√εr` 塞進 `k_z0`（**我們專案的歷史 bug**）→ G_A 1.43；連「G_V 只錯 10%」都有 **16× 分離**。
⇒ 這個對帳能把 G_V 釘在 **±1%**、G_A 在 **±2–3%**，**不是「湊得出來就算過」**。

⚠ 誠實的限制（agent 自己標的，我照抄不美化）：
- empymod 在我們這個波段（k₀h ≈ 0.26–0.34）**自己就有 1e−2…1e−1 的地板**（它是地球物理擴散區的碼），
  所以 εr=3.55 的**場層級**對帳**不能**單獨認證到 1e−3。εr 相依性的高精度證據來自
  極點（7 位）＋Fresnel（1e−11）＋εr=1 前因子（1e−12），**三者合起來才成立**。
- 「極點留數振幅」那條交叉檢驗**沒做成**（用無損極點套含損核，比值差 1e13）——**不算通過**，
  agent 明說沒有調參去湊它。
- 全部驗證都在「源與觀察點都在上方空氣區」；**不涉及垂直電流 / `G_A^{zx}`**。

順手抓到兩件（都不在公式，在周邊）：
1. **我的 `G_V` 數值精度是 ~3e−4（3.5 位有效），不是我以為的 1.5e−4** ——
   那 1.5e−4 是 quadrature 殘差不是理論極限。改用「直達項閉式剝離」取代靜態抽取，
   **成本一樣、精度 3e−4 → 7e−7**。（是否值得做見 §4.5 的敏感度測試。）
2. `l3_probe4/5` 的**遠場診斷是壞的**（上偏折的代價 e^{+δk₀ρ} 在 ρ=60mm 放大 67×，
   報出 n_eff = −0.128）。**核本身沒問題**，且我實際只用到 ρ ≤ 6.93mm，**不受影響**。

⇒ **「停」的一個主要前提被排除了**：不是核錯。

### 4.5 誠實的處置

依 §3.1 寫死的規則，階段 A 不過**就該停、不做 S1**。但那條規則的**理由**是
「代表精確核救不了正片域」——而 §4.3 的證據顯示這個推論**不成立**：
失敗有一個具體、已定位、可修的原因。

**我不自行放寬判準**（那正是 Goodhart 護欄要防的）。現況據實記錄，是否進 S1 交 Ricky 裁定。
兩個未決因素也一併列入判斷：
- **empymod 獨立對帳未回**——若核本身有錯，「停」的結論會建立在錯的實作上。
- **delta-gap 假電容未修**——它與 L3 同為一階（值 ~2 dB），缺它到不了真值。
