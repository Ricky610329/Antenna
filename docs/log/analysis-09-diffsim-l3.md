## 1. 假設

**現行 2 鏡像近似把表面波整段丟掉了，而表面波在這個 stackup 上不是小修正。**

證據（analysis-08 §10 + 本輪 fan-out）：

| | |
|---|---|
| 能量守恆 | η = P_rad/P_in = **0.872**，且**對三個不同尺寸貼片完全一致** → 系統性缺口非雜訊 |
| 核的直接比對（精確 vs 現行 2 鏡像，28GHz） | `G_A` 只差 8–18% 振幅、相位幾乎全對；**`G_V` 在 ρ=6.93mm 差 7.55× 且相位錯 77°** |
| 表面波佔 `G_V` 的比例 | ρ=1mm 時 31–53%，ρ=6.93mm 時 **64–84%** |
| 結構性理由 | DCIM 的函數族 `Σa·e^{−jknR}/4πR` 衰減不慢於 1/r，**表達不出**柱面波 `e^{−jβρ}/√ρ`（Şimşek 2006：球面波湊不出柱面波） |
| ⭐ 且只在 G_V | formulation C 下 `G̃_A = Ṽ_i^h/(jωμ₀)` 只含 TE 線，帶內無極點（TE₁ 截止 92.4GHz）→ **TM₀ 完全由 G_V 攜帶** |

→ 這解決了 analysis-08 §10 說的「正確的 residue 在 G_A 與 G_V 有不同權重與相位」：
**G_A 的 TM₀ 權重是 0。**

### 2.3 ⚠ 能量守恆判準**必須反過來讀**（最容易誤判的一條）

L3 之後表面波是**真實的損耗管道**，而 `farfield()` 只算空間波

## 3. 實作計畫

### 3.1 ★ 順序刻意不照文獻階段走：**先做最小可證偽版**

方案研究給的六階段裡，**S1（r=0 自項與近格的雙面積分）佔一半以上工作量，且是唯一沒有原型的**。
按順序做會在最貴、最不確定的地方卡住，卻還沒回答「L3 值不值得」。

**所以先跳過 S1**：自項繼續用現行的 `b_reg = 0.4·dx` 頂著（它本來就在扮演這個角色）。
依據是診斷本身就指向遠距離——`G_A` 在 ρ→0 只差 11%、`G_V` 差 2%，**錯的全在遠端，而遠端不需要 S1**。

| 階段 | 做什麼 | 出口 |
|---|---|---|
| **A（最小可證偽）** | spectral 核 + 靜態扣除 + 上偏折 GL 積分 → 293 個相異距離的表；自項沿用 b_reg | dev 上量 G-L3a/b。**不過就停，不做 S1** |
| B（僅當 A 過） | r=0 自項與近格的雙面積分（奇異性抽取 + 解析/Duffy） | Re(Zin) 對矩形貼片的量級 |
| C | empymod 獨立對帳（**已派 agent 進行中**） | 相對誤差 <1% |
| D | delta-gap 假電容（**已派 agent 進行中**；與 L3 同為一階，缺它到不了真值） | 中位 min-S11 −1.33 → ~−3.3 |
| E（選） | 精確表上疊零初始化可微殘差 | 記帳：物理節 vs 學習節 |

### 3.2 可微性（Ricky 的硬約束）

**核可不可微，對 ∂L/∂ρ 完全沒有影響** —— 已用 gradient check 實測確認：
梯度鏈是 `ρ → wgt → load → (Z + diag(load)) → solve → S11`，**Z（含核）在這條鏈上是常數**。
8 個抽樣像素 7 個相對誤差 <1%，625/625 像素有非零梯度（`test_l2_gradient_check_vs_finite_difference`）。

⇒ 離線算 Sommerfeld（哪怕完全用 scipy、完全不可微）**零損失**。
代價只有「對 stackup（h、εr）與核參數不可微」——而 h/εr 只有 2 個純量、離線重算全表 6 秒，
有限差分就夠；核的可置換性由階段 E 的殘差層保留。

### 3.3 為什麼連內插都不需要
25×25 的格心偏移 `r² = gi² + gj²` 是整數 → **只有 293 個相異距離**。
全表 2 核 × 17 頻 × 2499 偏移 complex128 = **156 KiB**，離線 ~6 秒。
`l2.py` 現成的 `self.off` 索引直接用 → **精確查表、零內插誤差、比現在還快**（省掉 2499×3 次 exp/sqrt）。
