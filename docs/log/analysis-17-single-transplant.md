## 0. 資料衛生(先修的坑)

single 的 pot **同一 id 在不同儀器店有不同值**(例:c48nq1p05_16 在 `c48nq1_p05` 為
wm +0.79,在 `r54s1base`(S1 網格)為 −0.25)。故本分析**先排除儀器變體店**
(店內有 `hfss_setup.json`,或 manifest kind ∈ {meshconv, diagbridge, slotw})——
314 個店被排除,剩 **37,006 筆標準儀器條目**。對帳:三標合格內 oob 最佳 = **7.78**
= records.json 的 usable_oob 紀錄,逐位吻合 ✓(管線自證)。

## 1. 單一栽培診斷

| 對象 | 兩兩 Hamming | 家族結構 |
|---|---|---|
| 七位冠軍(各軸) | 中位 **143** / min 26 / max 292 | 分散(各軸冠軍本就不同結構) |
| **合格解 top300(按 oob 價值軸)** | 中位 **43**;<60 配對 **80%** | **2 族:299 + 1** |

⇒ **冠軍分散不代表前緣分散**:single 的「可用解價值前緣」與 dual 一樣是**單一家族**。
(dual 對照:十五代王互距中位 10、top300 零外族。)

## 2. 守恆結構(同型)

wm × oob_bad 的 spearman ρ = **+0.326**(wm 越高,oob_bad 越大=越差)。按 wm 分箱的
**可達最佳 oob_bad**:

| wm 區間 | n | 最佳 oob_bad |
|---|---|---|
| [+0.60, +2.00) | 32 | +11.63 |
| [+0.40, +0.60) | 198 | +8.44 |
| [+0.15, +0.40) | 1,551 | **+5.99** |
| [+0.00, +0.15) | 1,808 | +1.46 |

⇒ 與 dual 的 (和,失衡) 同構:**閘門餘裕與價值軸互相扣抵**。wm 王 +0.79 的 oob 是
+22.79、usable 王 c8trip03_01 的 wm 恰好卡在 buffer 0.15——**兩位冠軍各站在同一條
取捨曲線的兩端**,不是兩個獨立成就。

## 3. ★rad 閘封鎖(本分析最可行動的發現)

**wm 過標 ∧ oob 優於現紀錄 7.78 ∧ 被 rad<0 擋下:13 筆**;rad 缺口中位 **−0.25**,
**12/13 缺口 <0.5 dB**:

| oob_bad | wm | **rad 缺口** | id |
|---|---|---|---|
| **+5.99** | +0.17 | −2.06 | c2radp02_11 |
| +6.16 | +0.16 | **−0.25** | c10trip05_17 |
| +6.82 | +0.17 | **−0.14** | s38s1_18 |
| +6.92 | +0.18 | **−0.12** | c11trip01_08 |
| +7.53 | +0.21 | **−0.10** | c8trip01_24 |
| … | | 最好者 **−0.02** | |

對照:全池 **rad ≥ 0 佔 37.1%**、rad 冠軍 +1.00 ⇒ **rad 不是難軸**,這些只是差臨門一腳。
**若把 rad 修過標,usable_oob 紀錄可從 7.78 推到 5.99(1.79 dB)**。

**為何從未被開採**:選拔用 `sel_score = oob + κ·max(0, −rad)`(κ=10)——rad 差 0.25
就被罰 2.5 分,這些個體在排序中被埋在後段,**從來沒進過任何批次的親本池**。
(與 dual 的教訓同型:獲取函數的盲區製造未開採區。)

## 4. 建議行動(single 首個主動輪:R79「rad 修復戰役」)

親本=上表 13 顆(優先 rad 缺口 <0.5 的 12 顆);算子=rad 定向鄰域(既有 rad head 引導)
+ 小步 d1-3;判準草案:①任一子代 三標全過 ∧ oob < 7.78 → **usable_oob 破紀錄**
(照公證鐵則)②修 rad 是否賠 oob(守恆是否在 rad 軸也成立)=本輪的機制問題。
⚠前提:這些 oob 值皆為**單次、標準儀器(隱式 0.01mm 橋)**;若之後 single 走儀器換代
(ONGOING「single 線儀器問題」),需重測。
