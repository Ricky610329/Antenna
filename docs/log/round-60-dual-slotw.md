- **判準(開檔時寫死,2026-08-11 14:27;發車前如修訂照紀律)**:

     「天花板=像素量子化」因果證明。
  3. **前緣判準**:sel=min(m3,m4) > **−7.01**(harvest 選擇性前緣)→ 公證(同機 3/3+跨機保守)。
  4. **判死分支**:全寬掃(0.03–0.15)完成仍 m3+m4 ≤ −17 帶=天花板另有物理(誠實記帳;
     下一步=50×50 提案或規格彈性問學長——照升級門檻裁定走)。

## 4. 分析 (Analyze)

### smoke(2026-08-11 15:33)+b1 判讀(16:3x 收檔;18 店+smoke 全零 error;S1 尺;全部單次)

   swc_cut(S1 全切)−6.40/−13.67 ≈ S0(−5.53/−14.09)——幾何鏈+求解尺全驗;
   **順帶:S0↔S1 對此結構差 <0.9 dB=網格不是問題**(smoke 檢核③的擔憂解除)。
2. **判準② 連續旋鈕=成立,教科書級單調**:r12 縫寬 0.03→0.15,m3 −2.25→−5.45 單調降、
   m4 −17.25→−14.51 單調升,平滑插滿無縫↔全切之間;r11 對稱雙縫同型。
   **亞像素縫=已驗證儀器**,任何拓撲皆可掛。
3. **★ 判準④ 判死分支觸發:守恆帶不是像素量子化**:全批 18 筆 m3+m4 ∈ −17.4~−22.6,
   **最大值=無縫端點本身(−17.4)**——連續旋鈕只沿同一條 trade 線滑動,總量與縫的實作方式
   無關。R59「天花板=量子化」假說被本批否證(這正是花一批的價值)。

   多縫者 energy_max 掉到 0.73-0.78=**輻射損上升**(線索,見 §5)。

## 5. 結論 (Conclude)

**TL;DR:亞像素縫寬機制一次到位(括號自證+教科書級單調=可掛任何拓撲的已驗證儀器),
但它把 R59 的天花板假說否證了——m3+m4≈−17~−20 守恆帶與耦合實作無關,是 wireO 母體
在這塊 5×5mm 板上的結構極限。兩個新假說浮出:①段太少裝不下——λg/2@28GHz≈3.2mm,
饋墊間只有 ~3.0mm=只裝得下約一節半波諧振器,而 17dB/0.5GHz 裙擺需要 3-4 節(~10mm);
②輻射損——縫越多 energy_max 越低(0.83→0.73),像素貼片段=會漏的諧振器,Q 不夠。**

1. 方法論資產:slot_spec 儀器驗證完畢(掛任何拓撲、S1 尺、括號協定)——留給後續任何
   幾何精修用;S0/S1 在此結構近同=網格憂慮解除。
2. R59→R60 的假說鏈誠實記帳:量子化假說(R59 §5)被否證;守恆帶=更深的物理
   (尺寸/輻射損),單靠 25×25 域內的耦合工程救不動。
3. **對規格可行性的含義(要跟學長對齊的證據)**:5×5mm 像素板 @28GHz 裝不下多節
   耦合諧振鏈;harvest 一萬筆 min(m3,m4) 全史最佳也只有 −7.01——「17dB/0.5GHz 裙擺」
   對這塊板可能是物理過嚴,規格彈性(通帶窗寬/裙擺斜率/阻帶深度)值得問。
4. 王線(wm_dual −6.04)與 m4 軸(+5.92)紀錄本輪未動。
