## 1. 假設 (Propose)

**假設**:R59 的守恆帶是像素量子化天花板(0.2mm 格距下耦合縫只有直通/斷路兩態);
連續縫寬 w_s 能插出中間耦合態 → 耦合強度變連續旋鈕 → 守恆帶可破。

- **判準(開檔時寫死,2026-08-11 14:27;發車前如修訂照紀律)**:
  1. **縫寬-耦合單調性**:同構型下 m3 隨 w_s 單調降、m4 單調升(w_s→0 收斂到無縫 wireO 已知值、
     w_s→0.2 收斂到全切已知值=**括號自證**,兼當幾何正確性檢核)→「連續旋鈕成立」。
  2. **守恆帶判準**:任一樣本 **m3+m4 > −16**(R59 全 153 筆 max −16.6)=守恆帶破=
     「天花板=像素量子化」因果證明。
  3. **前緣判準**:sel=min(m3,m4) > **−7.01**(harvest 選擇性前緣)→ 公證(同機 3/3+跨機保守)。
  4. **判死分支**:全寬掃(0.03–0.15)完成仍 m3+m4 ≤ −17 帶=天花板另有物理(誠實記帳;
     下一步=50×50 提案或規格彈性問學長——照升級門檻裁定走)。
  5. 主指標=records_dual(引檔不抄死);m5/m6 重議觸發照舊;≤3 批必收輪。
- **資料語義(鐵律)**:bits 不變幾何變體 → kind=`slotw` 查重豁免、`hfss_setup.json` 白名單鍵、
  id=`{parent}~sw{寬µm}` 親代綁定、**資料永不入鍋**(不進 dual SM 鍋、autod 掃描排除)。
- **施工(Opus 包,發車前)**:dual_port.py 加 `slot_spec` 建構參數+Subtract 幾何(新 COM 動詞
  → 首筆 smoke+括號自證);dedust run dual 分支白名單加 `slot_spec`;部署=三台 pull+重啟(鐵則 8)。
