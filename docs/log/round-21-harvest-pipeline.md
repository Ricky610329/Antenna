- R20 終審：SM 有效維度＝帶外（③19:10）、margin 大獎全出自隨機（+0.39/+0.36 皆 d1）、GA 選代拆除。

    連兩批 < 6%（R20 隨機臂基準）＝配方失效，停批回檢。
