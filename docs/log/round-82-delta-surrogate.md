# Round 82 — 變化量代理模型：學「翻幾格 → 曲線怎麼變」

- **狀態**: running（離線建模；上線試用掛在 R81 v6 批次內）
- **提出 / 開跑 / 結論**: 2026-10-19 / 2026-10-19 / —
- **一句話問題**: 直接用實測配對學「父代 pattern＋翻轉位置＋父代實測曲線 → 曲線變化量」，能否比現行絕對曲線 SM 在好設計之間排得更準？
- **一句話結論 (TL;DR)**: 待分析
- **指向**: R81 停滯診斷與回測（[round-81](round-81-wide-filter.md) 10/19 16:20、18:32 兩節）· 選樣程式 `script/r81_curve_sm.py` · 批次線 [ONGOING](../../configs/ONGOING.md)

## 1. 假設 (Propose)

- **問題 / 假設**：R81 v6 從 b72 起卡在約 −4.3。選樣時 SM 預測前半段 ρ 只有 0.15–0.18，且平均偏樂觀約 3 dB；零成本錨定（父代實測＋SM(子)−SM(父)）只小幅改善，錨定後仍偏樂觀 2.3 dB。推測 SM 學的是絕對曲線，「翻幾格的變化量」只是兩次預測相減的殘差，本身不準。直接以變化量為訓練目標應能改善。
- **為何現在做**：Ricky 10/19 提議以已知 pattern＋signal 為上下文、預測變化；同意第 1（錨定，已做）、第 2（變化量模型）步，第 3 步上下文接龍（Transformer）待第 2 步成立。
- **設計決定（Ricky 10/19）**：配對距離 **1–50 格內均勻取樣**；第 3 步上下文 3–4 筆、挑法多樣（最近、半徑內隨機、接龍、同區域）。
- **依據**：R81 回測數字見 round-81 2026-10-19 18:32 節。

## 2. 實驗設計 (Design)

| 步驟 | 內容 | 判準（發車前寫死） |
|---|---|---|
| S1 變化量模型（離線） | 輸入父代 pattern、翻轉遮罩、父代實測曲線（含遮罩）、距離；輸出三條曲線變化量。配對來源：寬頻真值＋24–32 GHz 歷史，距離 1–50 均勻；驗證 = 按設計整筆留出＋按時間切（b72–b78 每批只用該批之前資料） | 在 b72–b78 有實測父代的候選上（同 R81 錨定回測集）：預測前半段 ρ **≥ 0.30**（原始 0.15）且每批取預測前 5 的實測平均 **優於原始 SM −7.46**；另報翻 ≤3／4–12／13–50 格分組 |
| S2 上線試用 | 下一批 v6 的 climb 臂一半名額改由變化量模型挑，另一半照舊（同批對照） | 新模型那半的實測最佳與中位數皆不輸同批對照；連 2 批成立 → 全面接手 climb 臂 |
| S3 上下文接龍 | Transformer，上下文 3–4 筆鄰居、多種挑法混訓 | S1 成立才做；判準同 S1，且須優於 S1 |

- **停止 / 回報線**：S1 判準不過 → 回報原因與調整方向，不硬上線；S2 連 2 批輸對照 → 撤回。
- **硬上限**：S2 上線最多 3 批即判讀收輪（每輪 ≤3 批）。
- **紀錄**：任何 v6 紀錄級設計照 R81 公證鐵則（`/notarize`）。
- 判準若要修訂：只能在結果回來前，並留日期註記。

### 2026-10-19 22:04：方案驗證改用「舊資料模擬頻段稀缺」（Ricky 10/19 建議），第一版設計有缺陷

- 做法（`scarcesim`）：歷史資料的 S21 24–25.5 GHz 只留給一群相近的 436 筆設計（＝v6 11–40 完整量），其餘遮掉；群內留出約 170 筆當查詢，比較照抄、絕對 SM、變化量（一段式）、變化量＋微調。同時上線：每 epoch 重抽配對（鄰居庫，距離 1–50 每格存 12 個）、重點子集兩段式微調。
- 第一版結果（3 群平均）：該段 MAE 照抄 4.95、絕對 SM **3.61**、變化量 4.15、＋微調 4.28；整體 ρ 0.03／0.24／0.26／0.28；組內 ρ —／0.38／0.20／0.21。
- 缺陷：群 1 挑到稀疏區，查詢到最近已量設計的距離中位 225 格（遠超訓練的 50 格），該群變化量 MAE 9.5 dB 拉低平均；組內排序只湊到 2–7 組，雜訊大。兩個密集群（距離中位 1）中變化量 MAE 1.13／1.80 優於絕對 SM 1.35／1.93。

- 部署規則備忘：查詢離最近實測 > 50 格時應退回絕對 SM（變化量模型訓練範圍外）。
