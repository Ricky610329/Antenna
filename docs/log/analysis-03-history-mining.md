- 它們被放棄的原因:**rad 全滅（−2.3~−4.4）＋不可製造**（粉塵 5-12、組數 21-26）。
  → 三標張力的正確拓撲:不是 wm↔帶外,是 **(wm＋低側帶外) ↔ rad**。
- ⚠ 舊救援白撿數據潑冷水（R18 §1 引用）:t07/p00 的對稱化變體**保低側殺帶內**（wm −15~−25）,
