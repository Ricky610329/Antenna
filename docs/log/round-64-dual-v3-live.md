### b1 判讀(2026-08-12 09:43 收檔;100/100 零 error;單次)

1. **主考=不過**:g 臂 pred-true ρ **+0.118(P=0.41)**——離線補考的 +0.48/+0.73 是
   「跨家族寬帶」排序力,家族內窄帶實戰=零。發車時觀察的解讀①+②同時成立:
   v3 對均衡王朝系統性低估(c 臂王家族樣本 −4.69=全批頂,v3 卻押 wm2 家族),
   且家族內細排無力。**照預註冊判準:線上學習維持不開,SM 退回粗篩+分歧探測定位。**
2. 引導有效(g>c P=7e-08)照舊=粗篩沒壞;黑馬斷(d −6.73 < c −4.69)。
3. **m4 七連破:+7.39**(c 臂 m4_king 鄰域;公證 r64n1 在途)。
