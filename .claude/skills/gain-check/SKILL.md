# 性能期望儀表 $ARGUMENTS

> 設計本意（Ricky 2026-07-12）：**避免 agent 對整個算法的期望過早悲觀**——收效好壞用實測數字說話，
> 不用「連 N 批沒紀錄」的體感。同時擋過早樂觀：**不做尾巴外推**（小樣本 EVT＝偽精確禁區）。

## 執行

1. 直接跑（門檻**自動讀 `docs/records.json`**,不用人肉抄;旗標僅供覆蓋）：
   ```
   python -m script.analyze gain --line <線前綴>
   ```
2. 三層各自判讀（**各管各的，不混算**）：
   - **L1 階梯**：看「近門檻列」（≥+0.20/+0.30）**跨批趨勢**——連兩批下滑＝礦脈枯竭早警
     （比零紀錄靈敏）；穩定＝井還出水，別悲觀。
   - **L2 曲線**：邊際增益 b/N＝「每百筆期望 dB」。遞減是常態不是失敗；
     判斷點＝**邊際增益 × 可負擔預算 < 想要的提升** 時才轉移分布，不是感覺累了就轉。
   - **L3 轉換**：近王級→紀錄推進的歷史轉換率＝樂透的真實賠率。近王還在產＝紀錄只是時間問題；
     近王斷產＝該擔心的是上游（階梯），不是運氣。
3. **新臂／零歷史分布**：儀表會標「資訊帳」——只走 round 檔預註冊存活測試（三標率 vs 6% 隨機基準、
   劑量反應重現），**不給 dB 期望**。禁止用 L2/L3 否決還沒有數據的探索臂。

## 何時跑

- **每批收檔判讀時**（與臂別統計同回合）；
- **/close-round 輪結算 step 3**（拉數據）的一部分——三層帳一行摘要貼 round 檔 §4；
- 使用者問「現在收效如何/還要不要繼續」時，先跑這個再回答。

## 判讀紀律

- **前瞻 ρ 波動的主因＝範圍限制＋分布漂移，不是模型能力**（analysis-04 實測:同一模型
  held-out 混批 ρ 0.7+ vs 新批前瞻 0.1-0.5）——單批前瞻 ρ 低別急著判模型死,看連續趨勢。
- **★ 擴散型探索介入（根稅/de novo/novelty/資訊臂）用 L2 效率評,不用單批命中判因果**
  （Ricky 2026-07-13）：它們改的是抽樣分布不是瞄準某指標——**不對它下 per-batch「有沒有效」判決**;
  正法=L2 學習曲線 介入線 vs baseline 線比斜率,**≥5 round 後**才比。單批破紀錄≠介入成功。
  詳 decisions「探索型介入的評估法」。（定向介入如 O 帶外選鍵/H 劑量掃描才可較短視窗因果判讀。）

- 輸出貼 round 檔時標日期與 `--record` 取值（紀錄會換人，儀表數字有時效）。
- L2 擬合是**全程 log 曲線＝樂觀上界**，末段通常更平——引用時要帶這個限定詞。
- 三層都綠卻零紀錄 ≠ 失敗；三層都紅才升級「停批/轉移分布」討論（帶數字回報使用者）。
