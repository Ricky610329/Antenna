# 停滯協議 $ARGUMENTS

> 戰略背景（Ricky 定調 2026-07-12）：停滯=暫時；常升目標=探索範圍×資料量（L0）；
> 資料飛輪在轉,未來更強模型會解鎖（碎片區信念）。本協議防兩件事：靠慣性燒批次、偷偷降門檻。

## 第一層：驗屍（是真停滯嗎）
1. `python -m script.analyze gain --line r<NN>`——**分線分軸**看：單軸停滯常是注意力放錯軸
   （wm 卡死時帶外/rad 可能在動）；L0 資料量永遠在漲=飛輪沒停。
2. `python -m script.analyze credit`——血統貢獻分：有臂在蓋祖先梯嗎？（教訓：oobharv 當批效率
   最爛時貢獻分全場最高——帳面停滯期可能是梯子施工期）。
3. L3 近王轉換：近王還在產＝不是停滯是延遲。
→ 三道有任一綠＝不是真停滯，回報一句後照常續產。三道全紅 → 第二層。

## 第二層：換分布（歷史勝率 100% 的槓桿）
候選庫（ONGOING 🔜 常備）：**d1 殼層窮舉**（把破紀錄降維成有限驗證）、**de novo/D 臂加碼**、
**碎片區回訪**（Ricky 信念區,配更強 SM）、還沒試過的結構家族。
→ 選一個開 pilot 臂（新臂協議:證據+先導 ≤15+判準寫死+宣告）或開新輪。還有沒試過的分布＝不升級。

## 第三層：證天花板（把「找不到」變「證明沒有」）
所有分布都平了 → 科學產出換型：d1/d2 窮舉現任王鄰域 → 「可製造鄰域內局部最優,公證」＝
證明形狀的結果（論文成果,不是失敗）。量測誠信體系讓「沒有」也算數。

## 第四層：帶帳本升級給使用者（固定格式）
以下決定不代做，帶數據回報：
- 換物理框架（更大網格/不同饋電/雙頻）——動論文邊界；
- 「停止搜尋、開始寫公證報告」——動研究敘事。
回報包固定四件：①各線 gain 儀表 ②credit 血統帳 ③窮舉/枯竭證據 ④2-3 個算好成本的選項＋推薦。

## 禁止事項
- 不靠慣性續燒批次（機器不空轉 ≠ 帳本不空轉——worker 自產會顧好機器,你顧帳本）。
- 不降門檻製造假進度（records.json 只能因公證而動）。
- 不用 L2/L3 否決零歷史的探索臂（資訊帳原則）。
